- **一套主题全局生效。** Element UI 必须换深色变量（或覆盖），禁止默认白底表格/白弹窗/蓝主色出现在登录后任何页。

## 4. DRF 是什么（给选型用，不是授权照抄业务）

**DRF = Django REST framework**，给 Django 加 REST API 的一套库。旧项目 `requirements.txt` 里有 `djangorestframework==3.15.1`，控制器普遍：

```python
from rest_framework.decorators import api_view
from rest_framework.response import Response

@api_view(["GET"])
def project_list(request):
    ...
    return Response(...)
```

它能做的很多，本项目**只用其中一层**：

| 用 | 不用 |
|---|---|
| `@api_view` 标明 GET/POST | `ViewSet` / `ModelViewSet` |
| `Response` 返回 JSON | `DefaultRouter` 自动挂 `/list` `/create` |
| 需要时的 `parser`（上传文件） | Serializer 自动生成字段（未在方案出现就不写） |
| | `dj-rest-auth` / 社交登录（旧项目有，第一版不用） |

结论：旧项目已经用了 DRF 的函数视图，新项目**继续用这一种**，满足「一条路由一个方法」。不用 DRF 的自动 CRUD。
