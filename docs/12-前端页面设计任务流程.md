### 3.5 翻译规则：复刻页（Tailwind）→ 本项目（Vue2 + Element UI）

**做画面 = 把复刻页的 template 翻译成 Element UI，不是重新设计。** 下面是逐类对照，左列是复刻页里真实出现的写法，右列是本项目的落地方式。

**色值（一律换成 `06` 2.1，不要沿用复刻页的字面色）**

| 复刻页 | 本项目 |
|---|---|
| `bg-[#0b1120]`（页面底） | `#0a0f1a` |
| `bg-[#111827]`（卡片） | `#151e32` |
| `bg-[#1e293b]`（次按钮 / 未选中 tab / 输入底） | `#1e293b` |
| `border-gray-800` | `#1e293b` |
| `border-gray-700`（hover 边框） | 比 `#1e293b` 亮一档 |
| `bg-green-600` / `bg-green-500` / `text-green-400` | 统一 `#22c55e` |
| `text-white` | `#ffffff`（仅标题、当前项） |
| `text-gray-300` / `text-gray-400` / `text-gray-500` | `#d1d5db` / 次级灰 / 辅助灰 |

**尺寸与形状**

| 复刻页 | 本项目 |
|---|---|
| `rounded-xl`（卡片） | `border-radius: 12px` |
| `rounded-lg`（按钮） | `8px` |
| `rounded-full`（筛选 chips、进度条） | `9999px` |
| `p-5`（卡片内距） | `20px` |
| `gap-4`（网格） | `16px` |
| `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` | CSS grid，断点 640 / 1024 |
| 进度条 `h-1` + 内层 `bg-green-500` | 4px 高，`#1e293b` 底 + `#22c55e` 填充 |
| `text-lg / text-sm / text-xs` | 18 / 14 / 12px |

**组件对照**

| 复刻页写法 | 本项目 |
|---|---|
| 顶栏 `<header>` + `<nav>` + 手写 `<a>` | **不套用** —— 我们有自己的壳（左侧栏），这部分只学色值与高度，不搬结构 |
| 筛选 chips（一排 `rounded-full` 按钮，选中 `bg-green-600`） | 自写 chips 组件，或 `el-radio-group` + `el-radio-button` 改样式 |
| 卡片网格 `grid` + `bg-[#111827] rounded-xl` | 自写卡片 CSS（Element 无对应），不放 `el-card` 默认白底 |
| 按钮 `bg-green-600 text-white rounded-lg` | `el-button type="primary"` + 覆盖成 `#22c55e` |
| 次按钮 `bg-[#1e293b]` | `el-button` 默认 + 覆盖底 `#1e293b` |
| 进度条 | `el-progress` 改色，或自写 4px 条（`el-progress` 高度不好压到 4px 时自写） |
| 内联 `<svg>` 图标 | Element UI 自带图标优先；没有的保留内联 svg |
| Tab 一排（`创作方案 / 人物设定 / …`） | `el-tabs` 改深色样式 |
| 表格型列表（资产清单、分镜） | `el-table` + 深色主题覆盖 |
| `<script setup>`（多为空） | 逻辑全部落到 `index.js`（Options API） |

## 5. 画面规格（沿用 `06` 2.1 色板 + xjf 节奏）

xjf 实测给出的节奏参数：

| 项 | 规格 |
|---|---|
| 内容区内距 | 上 32px（大屏 40），下 56px |
| 页面标题区 | 标题 24px 粗白 + 副标题 14px 灰 + 下方 1px 分割线，区底留 24px |
| 卡片 | 底 `#151e32`，边框 1px `rgba(255,255,255,0.08)`，圆角 12px，内距 16px |
| 卡片网格 | gap 16px；列数 1 → 2（≥640）→ 3（≥1280）→ 4（≥1536） |
| 筛选 chips | 高 32px，圆角 999px，底 `#1e293b`，选中 = 强调色描边 + 微底 |
| 字号 | 页面标题 24 / 卡片标题 18 / 正文 14（行高 1.5–1.6）/ 辅助 12 |
| 按钮 | 主按钮实心 `#22c55e` 前景深色、高 40–44px、圆角 8px |
| 项目卡片（梦想剧场） | 左右布局：封面约 40% + 右侧信息列 |

技术栈不变：**Vue2 + Element UI，无 TS，不用 Tailwind**。xjf 是 Tailwind + oklch，只学观感，不迁技术栈。
