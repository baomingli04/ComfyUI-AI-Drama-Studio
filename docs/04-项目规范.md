## 2. 前后端职责与怎么跑

- 后端（Django 3.9 + DRF 函数视图）：数据、权限、文件、任务、外部模型/ComfyUI 调用。一条 URL 只干一件事。生成能力必须放在可复用模块，路由只调入口函数。
- 前端（Vue2 + Element UI）：页面、路由、弹窗、调用 API。一个页面只干一种功能。不要 TS。
- **始终分端口。** 后端 `8001`，前端开发 `8080`（`8000` 是用户另一项目，aicg 不使用）。生产也不把 dist 塞进 Django 托管（除非以后你另批）。
- 前端用 **`config.js`** 配后端地址。字段只写 `主机:端口`，**禁止写 `http://` / `https://`**。按当前 mode 取对应后端，再用当前页面协议拼接。

`config.js`（示意，未确认开发前不要当代码落地）：

```js
var AICG_CONFIG = {
  mode: 'dev', // 或 'prod'
  dev: {
    backend: '127.0.0.1:8001'
  },
  prod: {
    backend: '127.0.0.1:8001'
  }
}
```

请求基址：

```js
var 后端 = window.location.protocol + '//' + AICG_CONFIG[AICG_CONFIG.mode].backend
```

本机管理员、始终本机后端，故 prod 与 dev 暂同一地址。以后换主机只改 prod 的 `主机:端口`。

请求封装只读 `config.js`，禁止在每个页面再写一套后端地址。

## 3. 开发流程（强制）

```
用户提出需求
  → AI 只复述范围并出方案（文档或对话）
  → 用户确认
  → 按方案改（代码或文档）
  → 发现不一致：停，提问，再确认
  → 交付：改动文件列表 + 时间戳；不扩范围
```

顺序再加一条：**先库表文档定稿，再写 py，再写页面。** 跳过任何一格都算出规。  
改库、插管理员：先给 SQL 文本，确认后再执行。

## 10. 生成任务前端约定

- 提交接口立刻返回任务 id。
- 前端轮询任务详情刷新状态。
- 必须能取消：单独取消接口，只取消这一条。
- 上传个数：平台上限 **9 图 / 3 视频 / 3 音频**；再与当前工作流 JSON 取更严者。禁止超过平台上限。
- 产物：1 张图片或 2 个视频。
- Comfy 同时只跑一条。列表必须展示创建时间、开始时间（Comfy 真正开跑）、结束时间。
