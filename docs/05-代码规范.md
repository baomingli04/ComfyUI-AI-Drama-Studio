## 2.1 前端：中文事件名必须带括号（强制，2026-09-21 加）

Vue2 模板编译器对**中文标识符**不匹配 simplePath 正则，`@已新增="已新增分类"` 会被编译成
`function($event){_vm.已新增分类}` —— **只取值、不调用**，回调静默失效（弹窗不关、列表不刷新、翻页没反应）。

- 事件值是中文方法名时**必须写括号**：`@已新增="已新增分类()"`。
- 需要接参数的写 `$event`：`@切换="预览切换($event)"`、`@current-change="翻页($event)"`。
- 赋值型写法不受影响：`@关闭="日志弹窗显示 = false"`。
- 已按此规则修过的地方：技能管理页三个弹窗回调、`共用/媒体预览弹窗` 的 `@切换`（18 个测试页）、`提示词资源库弹窗` 的 `@采用` / `@current-change`。

## 7. 后端：一条路由一个方法（强制）

- URL 在 `urls.py` **显式** `path(...)` 声明。
- 每个 path 绑定一个函数。`@api_view(["GET"])` 或 `@api_view(["POST"])` 等，**一种 HTTP 方法一个函数**。
- **禁止** `DefaultRouter` / `ViewSet` / `ModelViewSet`。
- 取消任务必须是独立路由、独立函数。

## 8. 后端：每个方法必须有 try（强制）

```python
@api_view(["POST"])
def xxx(request, ...):
    try:
        ...
        return Response(...)
    except Exception as e:
        # 取最后一帧真实文件路径和行号，返回给前端
        ...
```

禁止指望全局 handler 代替方法内 try；禁止空 except；禁止吞掉行号。

## 9. 报错必须到前端行号（强制，生产同样）

| 字段 | 含义 |
|---|---|
| `ok` | false |
| `error` | 异常类型 + 信息 |
| `file` | 出错文件的**真实路径**（开发、生产都要真实路径） |
| `line` | 出错行号 |
| `func` | 出错函数 |

前端必须展示 `file:line`。字段名若 D3 要改，改文档后再改代码。
