## 1. 项目是什么

用 Django 后端 + Vue2 前端，重做一套**仅本机管理员**使用的 ComfyUI 漫剧制作平台。

旧项目 `D:\SC\web4\django` 只作功能清单与反面教材，不是模板仓库。旧项目的问题已明确：

1. 功能堆在一起，边界不清（尤其测试：多个菜单共用一个 `workflowtest`，靠 `mode` 分支）。
2. 数据库表职责重叠；测试后来加功能，库结构已经对不上真实参数。
3. 生成过程的等待、生成后的返回经常出问题，旧 py 不能当脚手架复制。

**完全照抄旧项目会被视为失败交付。旧数据一律不迁。**

## 5. 技术栈与本机约定（已锁定）

| 项 | 结论 |
|---|---|
| 后端 | Django + Python 3.9 |
| API | DRF：`@api_view` 函数视图 + `Response`；禁止 ViewSet / Router 自动挂 CRUD |
| 数据库 | MySQL utf8mb4；`127.0.0.1:3306`；账号 `root` / 密码 `root`；库名建议 `aicg`（建库前仍先给你 SQL） |
| 前端 | Vue2 + Element UI；不要 TS |
| 运行方式 | 始终分端口。后端 `8001`，前端开发 `8080`（`8000` 是用户另一项目，aicg 不使用） |
| config.js | 见下，不写协议 |
| 用户范围 | 仅本机管理员；无注册；管理员 `zhsw` |
| 旧数据 | 不迁 |
| 媒体根目录 | `backend/资源/` |

`config.js`（示意，未授权写代码前不要当落地文件）：

```js
var AICG_CONFIG = {
  mode: 'dev', // 或 'prod'
  dev: {
    backend: '127.0.0.1:8001'
  },
  prod: {
    backend: '127.0.0.1:8001'
  }
}
```

请求基址：`window.location.protocol + '//' + AICG_CONFIG[AICG_CONFIG.mode].backend`  
禁止在 `backend` 字段里写 `http://` 或 `https://`。本机管理员、始终本机后端，故 prod 与 dev 暂同一地址；以后若生产换主机，只改 prod 的 `主机:端口`。

媒体子目录约定（都在 `backend/资源/` 下）：

```
backend/资源/上传/     # 测试页上传的图/视频/音频
backend/资源/产物/     # 从 Comfy 拷回的结果
backend/资源/技能/     # 解压后的技能目录
backend/资源/日志/     # 每次任务一份日志文件
```
