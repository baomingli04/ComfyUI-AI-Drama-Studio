# 剧本产物模板集

## 一、原始创意模板

```markdown
# 《剧名》原始创意

## 1. 核心概念
一句话概括这个故事讲的是什么：

> 【一句话概念】

## 2. 故事卖点
- **卖点1**：XXX
- **卖点2**：XXX
- **卖点3**：XXX

## 3. 目标受众
- **核心受众**：年龄/性别/兴趣
- **潜在受众**：XXX
- **受众痛点**：这个故事满足了观众的什么需求

## 4. 差异化定位
- 与同类作品的区别是什么？
- 独特的看点在哪里？
- 为什么观众要选择这个故事？

## 5. 核心主题
- 主题1：XXX
- 主题2：XXX

## 6. 情感基调
整体情感风格：XXX
（热血/治愈/虐心/悬疑/搞笑/甜宠/权谋...）

## 7. 核心人物
- **主角**：姓名 + 一句话人设
- **核心配角1**：姓名 + 一句话人设
- **核心配角2**：姓名 + 一句话人设
- **反派/对手**：姓名 + 一句话人设

## 8. 故事亮点
- 亮点1：XXX
- 亮点2：XXX
- 亮点3：XXX
```

## 四、分集剧本模板（标准格式）

```markdown
# 《剧名》第X集 剧本

## 本集信息
- 集数：第X集
- 标题：
- 时长：约XX分钟
- 核心事件：一句话概括本集主要内容
- 重点场面：本集名场面列表
- 出场人物：本集出场的主要角色

---

## 正文

### 【第X集-第1场】场景名称  日/夜  内/外

【环境描写】
场景的环境、氛围、时间、地点的具体描述。

【人物状态】
在场人物的位置、状态、动作。

人物动作描写……

**角色A**
（动作/表情/语气）
对话内容……

**角色B**
（动作/表情/语气）
对话内容……

【旁白】
旁白内容……

△ 转场：转场说明

---

### 【第X集-第2场】场景名称  日/夜  内/外

……

---

## 本集小结
- **剧情推进**：本集推进了什么剧情，留下了什么悬念
- **人物变化**：本集中人物有什么成长或变化
- **关键信息**：本集释放了哪些重要信息
- **下集预告**：下一集的大致内容和看点
```
