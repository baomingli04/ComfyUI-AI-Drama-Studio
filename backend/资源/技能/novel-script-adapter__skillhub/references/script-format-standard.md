# 剧本格式标准

## 一、通用格式规范

### 1.1 基本排版规则

- 场景标题：加粗，左对齐，独占一行
- 动作描写：常规字体，段落形式
- 角色名：加粗，居中或左对齐（根据格式类型）
- 对话内容：常规字体，在角色名下方
- 旁白/内心独白：斜体或用【】标注
- 转场提示：右对齐，大写或特殊标注

### 1.2 场景编号规则

- 按集编号：第X集-第Y场
- 连续编号：全剧统一编号（第001场）
- 建议使用按集编号，便于分集管理

## 二、标准剧本格式（影视/舞台剧风格）

### 2.1 场景标题格式

```
【第X集-第Y场】场景名称  时间  地点
```

示例：
```
【第1集-第3场】长平之战·赵军大营  日  内
```

时间标注：日 / 夜 / 晨 / 昏 / 不限
地点标注：内（室内）/ 外（室外）/ 内外

### 2.2 动作描写格式

场景开头先写环境与人物状态，动作描写用段落形式：

```
大营内灯火通明，帅案上摊着地图。
廉颇身披铠甲，手指点在地图上的某一处，眉头紧锁。
帐外传来传令兵的脚步声。
```

### 2.3 对话格式

角色名加粗，对话内容另起一行：

```
**廉颇**
秦军屡次挑战，我军只守不攻，他们粮草不济，自会退去。

**赵括**
（上前一步）
老将军，守守守！我们守了三年了！再守下去，士气都没了！
```

括号内为动作/表情/语气提示：
- （上前一步）—— 动作
- （冷笑）—— 表情
- （压低声音）—— 语气
- （画外音）—— 画外音/旁白

### 2.4 旁白/内心独白

```
【旁白】：长平之战，是战国时期规模最大的战役，也是秦赵两国的国运之战。

【赵括内心】：难道……我真的错了吗？
```

### 2.5 转场格式

右对齐，用特殊符号标注：
```
△ 转场：夜 → 日
```

或：
```
>>> 切至：长平关·黎明 <<<
```

## 三、AI漫剧专用格式

### 3.1 格式特点

- 更强调画面描述（因为要生成画面）
- 对话更精炼（字幕不宜过长）
- 增加镜头提示（景别、角度、运动）
- 增加情绪标注（用于人物表情生成）

### 3.2 漫剧剧本模板

```
=== 第X集 第Y幕 ===

【镜头1】全景 / 俯视 / 缓慢推进
画面：长平战场，旌旗蔽日，秦军黑压压的军阵绵延数里。
气氛：肃杀、压抑
音效：风声、远处的号角声

【镜头2】中景 / 平视 / 固定
画面：赵军大营帅帐内，廉颇站在地图前，背对着镜头。
人物状态：廉颇，背影挺拔，双手负于身后

**廉颇**
（沉声）
传令下去，各营坚守不出，违令者斩。

【镜头3】特写 / 仰视 / 快速推近
画面：赵括愤怒的脸，眼中满是不甘。
情绪：愤怒、焦躁

**赵括**
（咬牙）
坚守坚守！难道要守到死吗！
```

### 3.3 镜头标注规范

| 标注类型 | 常用术语 |
|---------|---------|
| **景别** | 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 |
| **角度** | 平视 / 仰视 / 俯视 / 侧视 / 背视 |
| **运动** | 固定 / 推进 / 拉远 / 横移 / 升降 / 旋转 / 晃动 |
| **画面时长** | 短（1-2秒）/ 中（3-5秒）/ 长（5秒以上） |

### 3.4 AI漫剧分镜提示词增强（AI生图/生视频专用）

#### 提示词结构公式

```
画面提示词 = 主体描述 + 环境背景 + 镜头语言 + 风格质感 + 光影氛围 + 情绪基调
```

#### 各维度关键词库

**【主体描述】人物/物体**
- 人物：年龄、性别、发型、服饰、表情、动作、姿态
- 示例：25岁古装男子、束发、白衣、皱眉、拔剑、侧身站立

**【环境背景】场景/地点**
- 室内：大殿、书房、卧室、酒馆、密室、牢房
- 室外：战场、山林、街市、宫殿、悬崖、沙漠
- 天气：晴天、雨天、雪天、黄昏、黎明、夜晚
- 示例：古代战场、旌旗飘扬、黄沙漫天

**【镜头语言】景别/角度/运动**
- 景别：extreme close-up / close-up / medium shot / wide shot / aerial view
- 角度：low angle / high angle / dutch angle / over-the-shoulder
- 运动：slow zoom in / pan left / tracking shot / static
- 示例：medium shot, low angle, slow push in

**【风格质感】画风/材质**
- 国漫：Chinese animation style, xianxia aesthetic, ink wash painting
- 日漫：anime style, cel shading, Studio Ghibli style
- 写实：photorealistic, cinematic, hyper-detailed
- 水墨：ink painting, Chinese traditional painting style
- 赛博：cyberpunk, neon lights, futuristic
- 示例：Chinese xianxia animation style, highly detailed

**【光影氛围】光线/色调**
- 光线：golden hour lighting, dramatic lighting, soft ambient light, backlit, rim light
- 色调：warm tones, cool tones, desaturated, high contrast, cinematic color grading
- 氛围：mysterious, epic, serene, tense, romantic, melancholic
- 示例：dramatic side lighting, warm golden tones, epic atmosphere

**【情绪基调】整体感觉**
- 热血：intense, dynamic, action-packed, powerful
- 悲伤：melancholic, somber, emotional, heart-wrenching
- 悬疑：mysterious, tense, suspenseful, ominous
- 唯美：beautiful, ethereal, dreamy, poetic
- 搞笑：comedic, exaggerated, playful, funny

#### 分镜提示词模板（可直接用于AI生成）

```
【镜头X】景别 / 角度 / 运动
画面：[中文画面描述]
人物：[人物状态、表情、动作]
气氛：[整体氛围]
音效：[对应音效]

🎨 AI提示词（英文）：
[主体], [环境背景], [镜头语言], [风格质感], [光影氛围], [情绪基调], highly detailed, cinematic composition
```

#### 示例：长平之战开场镜头

```
【镜头1】全景 / 俯视 / 缓慢推进
画面：长平战场，旌旗蔽日，秦军黑压压的军阵绵延数里。
人物：无（纯环境镜头）
气氛：肃杀、压抑
音效：风声、远处的号角声

🎨 AI提示词（英文）：
Epic ancient Chinese battlefield, thousands of soldiers in black armor forming vast military formations, countless war flags fluttering in the wind, yellow sand swirling, aerial wide shot, slow downward push, Chinese xianxia animation style, dramatic overcast lighting, cold desaturated tones, oppressive and somber atmosphere, highly detailed, cinematic composition, 8k
```

#### 提示词写作原则

1. **主体优先**：先写最重要的人物/物体，再写环境
2. **从大到小**：整体场景 → 具体细节 → 质感光影
3. **控制长度**：每个镜头提示词控制在50-100个英文单词
4. **风格统一**：全剧使用统一的风格关键词，保持画风一致
5. **情绪匹配**：光影氛围要和剧情情绪一致
6. **避免矛盾**：不要同时出现互相矛盾的描述（如"bright sunlight" + "dark night"）

## 四、短剧/短视频格式

### 4.1 格式特点

- 节奏更快，冲突更密集
- 每集时长较短（1-3分钟）
- 强钩子开头，强反转结尾
- 对话口语化、生活化

### 4.2 短剧剧本模板

```
【第X集】标题：XXXX

▎开场（0-15秒）· 钩子
【画面】快速展示核心冲突/悬念
【台词】最抓人的第一句话

▎发展（15-60秒）· 冲突升级
【画面】冲突展开，人物对峙
【台词】关键对话，信息推进

▎高潮（60-90秒）· 反转/爆发
【画面】最激烈的场面/最大的反转
【台词】金句/名台词

▎结尾（90-120秒）· 留钩子
【画面】悬念/下集预告感
【台词】"下集更精彩"式的收尾
```

## 五、动画剧本格式

### 5.1 格式特点

- 更详细的画面描述
- 增加原画/作画提示
- 音效标注更细致
- 分镜意识更强

### 5.2 动画剧本模板

```
第X集 第Y场
场景：XXX
时间：XXX

【LAYOUT】
- 构图：前景XXX，中景XXX，背景XXX
- 光影：主光源方向，阴影位置
- 色调：整体色调倾向

【原画提示】
- 关键帧1：XXX动作起始
- 关键帧2：XXX动作峰值
- 关键帧3：XXX动作结束

【动作】
人物动作描述，包括细节动作（头发飘动、衣摆摆动等）

【特效】
需要的特效：火焰/水流/光线/粒子等

**角色A**
对话内容

【音效】
对应音效描述
```

## 六、格式选择指引

| 改编目标 | 推荐格式 | 重点关注 |
|---------|---------|---------|
| AI漫剧/动态漫 | 漫剧专用格式 | 镜头描述、画面细节、情绪标注 |
| 真人短剧 | 短剧格式 | 节奏、钩子、反转 |
| 影视长剧 | 标准格式 | 场景完整、对话自然 |
| 动画 | 动画格式 | 画面细节、动作分解、特效 |
| 舞台剧/广播剧 | 标准格式（简化场景） | 对话、旁白 |

## 七、通用写作规范

### 7.1 场景写作三要素

1. **在哪里**：地点、环境、氛围
2. **有谁**：在场人物、状态
3. **发生了什么**：核心事件、冲突

### 7.2 对话写作原则

1. **口语化**：说人话，不要书面语
2. **个性化**：每个角色说话方式不同
3. **有动作**：对话伴随动作，不是站着说
4. **有潜台词**：话里有话，不是直白说
5. **推进剧情**：每段对话都要有信息量

### 7.3 动作描写原则

1. **可视化**：写出来就能想象出画面
2. **有目的**：每个动作都有意义
3. **有细节**：关键动作要有细节描写
4. **有节奏**：快慢结合，张弛有度

### 7.4 时长估算参考

- **普通语速**：每分钟约180-220字对话
- **AI漫剧**：每100字剧本约对应30-45秒画面
- **真人短剧**：每100字剧本约对应20-30秒画面
- **影视长剧**：每集45分钟约1.5-2万字剧本

## 八、剧本排版模板（Markdown）

```markdown
# 《剧名》第X集 剧本

## 基本信息
- 集数：第X集
- 时长：约XX分钟
- 核心事件：一句话概括本集内容
- 重点场面：本集名场面列表

---

## 正文

### 【第X集-第1场】场景名  日/夜  内/外

动作描写段落……

**角色A**
（动作/表情）
对话内容……

**角色B**
（动作/表情）
对话内容……

【旁白】
旁白内容……

△ 转场说明

---

### 【第X集-第2场】场景名  日/夜  内/外

……

---

## 本集小结
- 剧情推进：本集推进了什么剧情
- 人物变化：人物有什么成长/变化
- 留下悬念：本集结尾的钩子
- 下集预告：下集大致内容
```
