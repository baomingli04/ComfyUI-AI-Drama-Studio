# 小说改编剧本创作 Skill

> 专业级小说转剧本一站式解决方案，忠实还原与优化改编双模式，从原著到分集剧本全流程覆盖

![icon](icon.png)

---

## ✨ 核心功能

### 📖 全格式小说接入
- **支持格式**：.txt / .docx / .pdf / .md / .doc 等任意文本格式
- **不限字数**：百万字长篇也能完整解析
- **智能分段**：自动识别章节结构，建立章节索引
- **全文覆盖**：逐章精读，无遗漏，无跳读

---

### 🔍 七大维度深度解析

| 解析维度 | 核心内容 |
|---------|---------|
| **人物体系** | 主角人设、核心配角、人物关系网、成长弧线、语言风格 |
| **剧情脉络** | 主线/支线/暗线、起承转合、关键转折点、伏笔与回收 |
| **名场面识别** | S/A/B/C 四级分级、经典台词标注、改编优先级管理 |
| **世界观设定** | 时代背景、地理设定、势力划分、规则体系、特殊设定 |
| **时间线梳理** | 故事时间跨度、关键节点、事件先后顺序 |
| **主题内核** | 核心主题、情感基调、价值观表达 |
| **人物语言** | 口头禅、说话方式、代表性台词库 |

### 🎬 两种改编模式

#### 模式 A：忠实原著改编
**核心原则：100% 还原，一字不改**

- ✅ 原著台词完整保留，一字不差
- ✅ 故事线完全遵循原著叙事顺序
- ✅ 人物人设、行为、动机严格一致
- ✅ 重要细节描写尽量转化为画面
- 🎯 适用：粉丝向改编、经典IP还原、文学性强的作品

#### 模式 B：优化改编
**核心原则：三不变 + 可优化**

**🔒 三不变底线（绝对不可触碰）**
1. 主角及核心配角人设不变
2. 剧情完整脉络不变
3. 重点名场面不变

**✏️ 六大优化方向**
1. **节奏优化**：压缩冗余、强化冲突、加快前期节奏
2. **叙事优化**：调整顺序、整合多线、优化伏笔释放
3. **结构优化**：支线整合、场景合并、次要角色精简
4. **视觉化优化**：增强画面感、强化动作场面、设计标志性镜头
5. **对话优化**：书面语口语化、长对话拆分、增加动作表情（不改变原意）
6. **风格适配**：根据目标平台和载体调整表达方式

🎯 适用：商业改编、平台适配、载体转换、短视频化

### 📦 四类产物输出

#### 1. 原始创意
- 核心概念（一句话 pitch）
- 故事卖点提炼
- 目标受众分析
- 差异化定位
- 核心主题与情感基调

#### 2. 剧本大纲
- 整体故事结构（五段式/三幕式）
- 主线走向与关键节点
- 人物设定与人物关系
- 世界观设定
- 分集梗概（每集核心事件+结尾钩子）
- 名场面分布表

#### 3. 剧本摘要
- 一句话简介
- 三百字梗概
- 千字详梗
- 核心人物简介
- 核心看点列表

#### 4. 分集剧本
- 每集完整剧本
- 场景标题 + 动作描写 + 对话 + 旁白
- 人物动作/表情/语气标注
- 转场提示
- 本集小结（剧情推进+人物变化+下集预告）

### ✅ 六级质量校验体系

生成完成后自动执行质量校验：

| 校验项 | 检查内容 | 优先级 |
|-------|---------|--------|
| **台词保真度** | 原著台词准确性、说话人正确性 | 🔴 最高 |
| **人设一致性** | 性格、语言、行为、动机是否OOC | 🔴 最高 |
| **剧情完整性** | 主线完整、关键转折、伏笔回收 | 🟠 高 |
| **名场面还原度** | S/A级名场面完整性、经典台词 | 🟠 高 |
| **节奏与时长** | 每集时长、整体节奏、钩子设置 | 🟡 中 |
| **格式规范性** | 格式统一、错别字、编号正确 | 🟢 低 |

### 🎯 多载体格式适配

支持四种专业剧本格式，一键切换：

| 格式类型 | 适用场景 | 特点 |
|---------|---------|------|
| **标准影视格式** | 影视长剧、舞台剧 | 场景+动作+对话，专业规范 |
| **AI漫剧格式** | AI漫剧、动态漫 | 镜头标注+画面描述+情绪标注 |
| **短剧格式** | 短视频、竖屏短剧 | 强钩子+快节奏+高密度冲突 |
| **动画格式** | 动画番剧、动画电影 | LAYOUT+原画提示+特效标注 |

## 🚀 使用方式

### 快速开始
1. 上传你的小说文件（支持 .txt/.docx/.pdf/.md 等）
2. 选择改编模式：忠实原著 / 优化改编
3. 指定集数和风格（如：12集AI漫剧，热血燃向）
4. 选择需要的产物类型
5. 等待解析与生成，获得完整剧本文件

### 典型使用场景

**场景1：AI漫剧改编**
> 上传网文小说 → 选择优化改编 → 指定24集漫剧 → 输出分镜式分集剧本

**场景2：短剧剧本创作**
> 上传长篇小说 → 选择优化改编 → 指定30集短剧 → 输出快节奏强钩子剧本

**场景3：经典IP还原**
> 上传经典小说 → 选择忠实原著 → 指定集数 → 输出100%还原剧本

**场景4：IP评估**
> 上传小说 → 快速解析 → 输出创意+大纲+摘要 → 评估改编价值
