# 豆包视频生成 · Prompt 规范与禁忌

> 写入 promp t 时的工程边界清单。仅在生成镜头 prompt 时按需查阅，不要硬塞进 SKILL.md。

---

## 一、模型基本特性

豆包视频生成（豆包 / 即梦 / Seedance 系列）的输入是**自然语言段落式描述**，不是关键词清单。模型对「一段流畅、视觉化的中文/英文描述」的响应远好于「一堆逗号分隔的标签」。

### 它擅长的事

- 单一主体的清晰动作（如「黑衣男子拔剑」）
- 具体的环境与光线（黄昏、雨夜、霓虹灯）
- 稳定的镜头运镜（推/拉/摇/移/跟）
- 风格迁移（写实、二次元、3D、电影感）
- 7 秒内情绪起承转合
- 简单手势、转头、微笑、注视

### 它容易翻车的事

- 多个主体同时动作（「A打B，B挡C，D躲」）
- 复杂物理交互（精细的手指动作、握持、捏取）
- 镜头中后期被遮挡再出现的人物
- 一镜内剧烈运镜切换（从定镜突甩到环绕）
- 文本 / 数字 / UI / 字幕 / 水印
- 长对话（旁白、画外音叙述）
- 跨镜头的连续动作衔接（这是用户后期拼接的活，不该塞给单镜）
- 否定指令（「不要出现 X」「不要戴眼镜」）—— 写入 prompt 主模型基本忽略，且消耗 token

---

## 二、推荐的 Prompt 结构

按下面这个顺序组织自然语言段落，**不要**用逗号分隔的关键词流。

```
[主体外貌与状态]，[关键动作]。[环境与光线]。[镜头语言与构图]。[情绪与氛围]。[风格标签]
```

### 标准模板

**中文：**
```
[主体外貌描述]，[正在做的核心动作]。[时间、地点、光线、空间感]。[景别 + 运镜 + 构图]。
[情绪词或氛围]。[风格标签]
```

**English：**
```
[Subject description with consistent appearance], [single core action].
[Time of day, location, lighting, spatial atmosphere]. [Shot scale + camera movement + composition].
[Mood / atmosphere verb]. [Style tags]
```

### 字数与时长匹配

| 单镜时长 | 中文 prompt 字数 | 英文 prompt 词数 |
|---|---|---|
| 2–3 秒 | 60–100 字 | 40–70 词 |
| 4–5 秒 | 90–140 字 | 60–100 词 |
| 6–8 秒 | 120–180 字 | 80–130 词 |

镜头越长，prompt 越需要更细腻的环境、动作分层、镜头组合运镜。超过 8 秒容易出现"卡顿/定格"现象。

---

## 三、风格标签速查表

把风格词作为**整段 prompt 的收尾**，中间逗号或顿号分隔。3–7 个标签最稳妥。

### 网文短视频风格（默认）

```
digital illustration, stylized, high contrast, vivid color, 8K, sharp focus
```

按题材叠加：
- 玄幻：+ `wuxia fantasy, mystical aura, ancient Chinese aesthetic`
- 都市：+ `urban night, neon glow, modern cinematic`
- 言情：+ `soft romantic light, pastel mood, shallow depth of field`
- 悬疑：+ `noir, low-key lighting, dramatic shadows`
- 古风：+ `ink wash palette, hanfu costume, classical composition`
- 科幻：+ `cyberpunk neon, holographic, futuristic matte`

### 电影写实风格

```
cinematic, anamorphic, film grain, shallow depth of field, 8K, photorealistic
```

按题材叠加：
- 史诗：+ `epic wide, IMAX composition, golden hour`
- 文艺：+ `subtle vignette, soft muted color, contemplative pacing`
- 商业大片：+ `high octane, dynamic motion, dramatic lighting`

## 四、镜头间的人物一致性工程

豆包/Seedance 类模型最大的痛点是**人物漂移**。控制策略：

1. **外貌统一段**：每个核心人物预先写一段固定外貌描述，所有镜头 prompt 复用同一段
2. **不要拼凑短描述**：「黑发、剑眉」「黑发、剑眉、长袍」写法会让模型看成不同人
3. **避免每镜重写年龄**：用「二十岁出头的青年」而不是「二十岁零三个月的青年」
4. **突出 1 个标志性特征**：如「眉心一颗红痣」「腰间银色铃铛」「左眼一道旧疤」
5. **服饰锁定场景**：同一场景内人物服饰不变；切换场景时再统一改写
6. **不写多余**：删掉与本镜无关的人物外貌信息

### 不一致时的修法

如果某镜生成结果人物外形跑了：
- 在该镜 prompt 里**单独再次粘贴**完整外貌段
- 降低该镜运镜强度（改成固定或缓推）
- 减少并发主体数量

---

## 五、负向处理：不写否定，写正向反义

把「不要 X」改写成正向期望：

| ❌ 否定式 | ✅ 正向替代 |
|---|---|
| 不要戴眼镜 | 面部无遮挡 |
| 不要下雨 | 晴空万里 |
| 不要红色 | 素白长裙 |
| 不要背景人 | 空旷无人荒野 |
| 不要血腥 | 清澈水面倒影 |

原因是豆包主模型对显式否定不敏感，对显式存在敏感。

---

## 六、镜头转场建议

豆包输出的镜头是**片段**，用户**自行用剪辑工具**拼接。生成 prompt 时**不写**转场，但按以下规则保证拼接顺畅：

1. **动作守恒**：A 镜结尾的姿势应能接上 B 镜开头
2. **景别跳跃**：避免连续两镜同景别
3. **空间方向一致**：始终维持 180 度轴线
4. **首帧姿态明确**：把"开始动作"写在 prompt 开头，不要写"动作完成后"

---

## 七、典型坑位清单（避免清单）

- ❌「两人边走边聊」 — 多主体多动作
- ❌「他缓缓转过头，露出半边脸微笑，然后低头叹了口气」 — 单镜多动作链
- ❌「宏大史诗场面，千军万马」 — 主体数量超限
- ❌「画面中有字幕'你好'" — 文本渲染
- ❌「一个古装的现代人」 — 风格冲突
- ❌「画外音讲述一段往事」 — 不支持
- ❌「先 A 后 B 然后 C 镜头拉远」 — 时序不可控
- ❌ 在镜 prompt 里写「转场」、「切黑」、「淡入淡出」 — 模型不会执行剪辑转场

---

## 八、调试 SOP

生成不理想时按此顺序排查：

1. **人物漂移** → 重新粘入外貌段 + 减少并发主体 + 改为固定运镜
2. **动作卡顿/不完整** → 镜头时长压到 3s + 精简到 1 个动作
3. **风格跑偏** → 在 prompt 末尾追加 2–3 个精准风格词
4. **构图偏远/主体消失** → 强调"前景中央""特写""直视镜头"
5. **整体氛围不对** → 重写环境段开头，从「时间+光线+空间」三件套下手
6. **全片都不行** → 可能是题材与风格标签互斥，换风格前缀重试
