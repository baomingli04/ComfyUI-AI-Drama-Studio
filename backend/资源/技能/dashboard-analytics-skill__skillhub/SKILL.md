# Novel Storyboard（小说分镜 → 豆包视频）

## Overview

把用户粘贴的一段/一章中文小说文本，拆解成「场景—镜头」两级结构，并按豆包视频生成模型的输入习惯，把每个镜头写成可复制的自然语言 prompt（中英双发）。默认输出为表格 + 可复制提示词块。

## When to use this skill

触发条件（满足任一即用）：
- 用户粘贴中文小说/网文段落并要求生成「分镜 / 分镜头 / storyboard」
- 用户问「把这段小说给豆包生成视频需要怎么写 prompt」
- 用户提到「网文转视频」「小说分镜脚本」「豆包视频提示词」

不触发的场景：纯英文文本、希望生成动画番剧级长片、需要超过 30 个连续镜头的整章（先让用户分批）。

## Workflow

### Step 1 · 文本接收与体量判断

- 用户粘贴后，先识别：题材（玄幻/都市/言情/悬疑/古风/科幻/历史/军事/其他）、人称、核心人物与场景、整体情绪基调
- 体量判定：
  - ≤ 800 字 → 当成一段/单场景处理，一次出完
  - 800–3000 字 → 先输出前 5 个镜头，再主动询问用户是「继续往后拆」还是「先调风格再继续」
  - > 3000 字 → 拒绝一次性处理，先让用户拆成 ≤ 3000 字的批次

### Step 2 · 场景切分（Scene Segmentation）

按以下任一信号切换为新场景：

- **地点**变化：室内↔室外、城市↔荒野、此房间↔彼房间
- **时间**跳转：「三天后」「翌日清晨」「午夜」「一周过去」
- **视角人物**切换
- **情绪基调**明显变化：紧张→舒缓、压抑→爆发
- **情节段落标记**：章节标题、明显的「——」分隔线

每个场景编号 `S1, S2, S3...`，用一句话写明场景核心冲突或氛围（如 `S2：深夜废墟，两人短暂对峙后被乱兵冲散`）。

### Step 3 · 镜头切分（Shot Breakdown）

每个场景再拆为 1–6 个镜头。拆解依据（按优先级）：

1. **动作变化**：站着 → 出手；离开 → 返回
2. **情绪焦点切换**：震惊 → 反击 → 得意
3. **对话轮次**：每句关键台词独立成镜，或两人一镜反应切换
4. **关键道具/特写**首次出现（刀出鞘、血滴落、眼神）
5. **节奏点**：网文风格下每 5 秒一个「爽点 / 反转 / 信息戳」

**网文短视频默认节奏参数：**

| 维度 | 默认值 | 调整方向 |
|---|---|---|
| 单镜时长 | 3–6 秒 | 高能动作段压到 2–3s；抒情段放到 5–8s |
| 单镜信息密度 | 1 主体 + 1 动作 + 1 情绪落点 | 复杂打斗可加 1 道具/1 效果 |
| 镜头数上限 | 单场景 ≤ 6 镜 | 长场景拆子场景 |
| 总镜数上限 | 单次输出 ≤ 30 镜 | 超量提示用户分批 |

### Step 4 · 镜头语言字段标注

每个镜头**必须填齐**以下字段。中文 prompt 与英文 prompt 双发。

| 字段 | 取值规范 | 示例 |
|---|---|---|
| 编号 | `S{场景}-N{镜头}` | S1-3 |
| 时长 | 秒，建议 2–8 | 4s |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 | 近景 |
| 运镜 | 推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 固定 / 手持 / 甩镜 | 推 + 微摇 |
| 主体 | 人物/物体的关键外观特征（保持全片统一描述） | 黑袍男子，剑眉星目，发丝凌乱 |
| 动作 | 单镜内最重要的 1 个动作 | 抽出腰间长刀 |
| 环境 | 时间、天气、光线、空间感 | 黄昏，残阳从侧后方打入 |
| 情绪 | 一个核心情绪词 | 压抑、爆发、暧昧、惊惧、决绝 |
| 风格标签 | 视觉风格关键词（逗号分隔） | cinematic, dark fantasy, 8K |
| 中文 prompt | 自然语言段落，含主体/动作/环境/镜头/风格 | "黄昏古战场..." |
| 英文 prompt | 英文版同步 prompt | "Dusk battlefield..." |

**关键约束**：
- 同一个人物在所有镜头里必须用同一段外貌描述，否则豆包前后形象漂移
- 中文 prompt 用**段描述**而非关键词堆砌，更接近 Doubao 训练数据的自然语言形态
- 每个镜头时长不超过 8s——豆包视频生成当前最佳窗口
- 不在 prompt 里写文本/字幕/水印/UI 元素

### Step 5 · 输出

输出 = 表格 + 可复制提示词块 + 使用提示。

**表格**（markdown，三栏足够复制即用）：

| 编号 | 时长 | 景别 | 运镜 | 中文 prompt | 英文 prompt |
|---|---|---|---|---|---|

**可复制提示词块**：每个镜头独立一段，前后用 `--- 镜头 S1-3 ---` 分隔，便于一次性复制到豆包视频生成工具。

**文末使用提示**（每次输出都要附）：
1. 豆包视频生成工具/网页端粘贴位置说明
2. 如何根据生成结果调整：人物漂移→统一人物描述；动作错乱→精简动作；风格跑偏→追加风格标签
3. 风格切换提示：如果用户说"再给一版电影感的"，按对照表重新生成

## Style Adaptation · 网文短视频 ⇄ 电影写实

| 维度 | 网文短视频（默认） | 电影写实 |
|---|---|---|
| 单镜时长 | 2–5s 短促密集 | 4–10s 留白呼吸 |
| 景别 | 特写 / 近景 为主 | 中景 / 远景 为主 |
| 运镜 | 快推 / 甩镜 / 手持 | 固定 / 慢推 / 滑轨 |
| 转场 | 硬切 | 叠化 / 淡入淡出 |
| 调色 | 高对比高饱和 | 偏低饱，自然色调 |
| 节奏点 | 每 5s 一个爽点 | 跟着情节起伏 |
| 风格标签前缀 | digital illustration, stylized | cinematic, anamorphic, film grain |

如果用户在调用里指明"电影感 / 写实 / 慢节奏 / 大师级"，按电影列调整；否则一律走网文短视频默认列。
