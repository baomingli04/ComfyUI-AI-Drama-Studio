# 爆款拆解方法论模板库

本库定义「爆款对标生成」模式的拆解方法论。当用户输入一段爆款网文开头或书名时，按本库的方法论自动拆解其爽点结构、叙事节奏、人设框架和赛道归属，然后基于拆解结果生成同风格同赛道的新内容。

---

## 一、拆解流程总览

```
用户输入（爆款开头/书名）
  → Step 1: 赛道识别
  → Step 2: 爽点结构提取
  → Step 3: 叙事节奏分析
  → Step 4: 人设框架提取
  → Step 5: 差异化标记
  → 生成同风格新内容
```

---

## 二、拆解方法论详解

### Step 1: 赛道识别

根据输入内容中的关键词和场景特征，匹配到8大热门赛道之一：

| 识别信号 | 赛道 |
|----------|------|
| 赘婿/上门/妻子/丈母娘/隐忍 | 都市赘婿/战神返乡 |
| 签到/宗门/弟子/长老/大比 | 玄幻签到/无敌流 |
| 末世/丧尸/囤货/变异/异能 | 末世囤货/异能 |
| 穿书/快穿/系统/原著/炮灰 | 穿书/快穿/反派 |
| 总裁/追妻/替身/火葬场/离婚 | 甜宠/追妻火葬场 |
| 年代/工分/知青/粮票/生产队 | 年代文/种田 |
| 重生/前世/回到/再次/上一世 | 重生/穿越 |
| 案件/推理/魔法/密室/诡秘 | 悬疑/西幻 |

如果输入是书名而非开头正文，先根据书名的关键词匹配赛道，再结合书名暗示的爽点方向推断具体结构。

### Step 2: 爽点结构提取

从输入开头中提取爽点节点，对照赛道专属爽点模板定位当前开头处于爽点结构的哪个阶段：

**提取维度：**

| 维度 | 说明 | 示例 |
|------|------|------|
| 当前爽点阶段 | 这段开头处于赛道爽点结构的第几个节点 | "三年隐忍"阶段（第1节点） |
| 爽点密度 | 单位字数内的爽点事件数量 | 高/中/低 |
| 压抑-释放比 | 压抑描写与爽感释放的比例 | 7:3（先抑后扬型） |
| 钩子位置 | 悬念钩子出现在开头的位置 | 最后一句（尾钩型） |
| 爽点类型 | 具体的爽点类型 | 身份反差/打脸/碾压 |

**提取输出格式：**

```
【爽点结构拆解】
- 赛道：xxx
- 当前阶段：xxx（对应赛道爽点结构的第X节点）
- 爽点密度：高/中/低
- 压抑释放比：X:Y
- 钩子类型：尾钩型/中钩型/双钩型
- 核心爽点：xxx
```

### Step 3: 叙事节奏分析

分析输入开头的叙事技巧和节奏：

**分析维度：**

| 维度 | 说明 | 判断方法 |
|------|------|----------|
| 开场方式 | 如何开始第一句 | 对话开场/场景开场/心理独白/倒叙开场 |
| 视角 | 叙事视角 | 第一人称/第三人称限知/第三人称全知 |
| 信息释放节奏 | 信息量分布 | 前密后疏/前疏后密/均匀分布/炸弹式 |
| 对话占比 | 对话vs叙述的比例 | 高对话型/低对话型/混合型 |
| 情绪曲线 | 读者情绪变化轨迹 | 如：压抑→好奇→震撼 |
| 句式风格 | 句子长度和结构 | 短句密集型/长短交错型/长句叙事型 |
| 留白程度 | 未说出的信息量 | 高留白（暗示多）/低留白（直白） |

**分析输出格式：**

```
【叙事节奏分析】
- 开场方式：xxx
- 视角：xxx
- 信息释放节奏：xxx
- 对话占比：高/低/混合
- 情绪曲线：xxx → xxx → xxx
- 句式风格：xxx
- 留白程度：高/中/低
```

### Step 4: 人设框架提取

从输入开头中提取主角和关键角色的人设要素：

**提取维度：**

| 维度 | 说明 |
|------|------|
| 主角辨识度 | 姓名+至少1个标志性特征 |
| 主角处境 | 开局时的身份/状态/困境 |
| 实力暗示 | 暗示主角真实实力的细节 |
| 性格信号 | 通过行为/对话体现的性格特质 |
| 关系张力 | 与其他角色的关系暗示 |
| 金手指暗示 | 主角拥有的外挂暗示 |

**提取输出格式：**

```
【人设框架提取】
- 主角姓名：xxx
- 标志性特征：xxx
- 开局处境：xxx
- 实力暗示：xxx
- 性格信号：xxx
- 金手指暗示：xxx
- 关系张力：xxx
```

### Step 5: 差异化标记

在拆解完成后，标记原作的独特之处和可复用要素：

| 标记类型 | 说明 |
|----------|------|
| 核心创意点 | 原作最独特的1-2个创意 |
| 可复用结构 | 可以套用到新内容中的结构框架 |
| 需差异化部分 | 新内容必须做出区别的部分 |
| 避免照搬点 | 不能直接抄的元素（版权风险） |

## 三、同风格生成规范

### 生成原则

1. **结构对标，内容原创** — 拆解出的爽点结构和叙事节奏可以直接复用，但人物、设定、具体情节必须原创
2. **保留节奏感** — 新内容的爽点密度、压抑释放比、钩子位置应与原作保持一致
3. **同赛道同风格** — 新内容必须与原作属于同一赛道，使用同一赛道的专属爽点模板
4. **差异化创新** — 在对标基础上必须加入至少1个原作没有的创新点
5. **版权红线** — 不得使用原作的人物姓名、地名、招式名、特殊术语等专有元素

### 生成流程

```
拆解结果 → 提取可复用结构 → 生成原创人设和设定 → 套用结构生成新内容 → 差异化检查 → 敏感词过滤 → 输出
```

## 四、常见爆款开头模式速查

以下是各赛道常见爆款开头的模式，用于辅助拆解：

### 都市赘婿爆款模式
- **模式A**: 日常送外卖/低调上班 → 被熟人撞见 → 暗示身份 → 尾句炸弹
- **模式B**: 家宴被羞辱 → 妻子不帮 → 一通电话翻转 → 全场跪
- **模式C**: 丈母娘介绍"优秀人选" → 对方挑衅 → 主角一句话搞定 → 身份冰山一角

### 玄幻签到爆款模式
- **模式A**: 被分到最差住处 → 签到激活 → 发现住处是禁地 → 首次奖励
- **模式B**: 师兄抢夺资源 → 签到功法碾压 → 同辈懵 → 大比预告
- **模式C**: 宗门大比 → 一招秒杀 → 长老折服 → 敌宗来袭

### 末世囤货爆款模式
- **模式A**: 重生醒来 → 倒计时 → 疯狂采购 → 空间觉醒
- **模式B**: 末世爆发 → 邻居求救 → 冷漠拒绝 → 异能觉醒
- **模式C**: 变异体围攻 → 异能全开 → 建据点 → 军方求合作

### 穿书快穿爆款模式
- **模式A**: 穿成炮灰 → 系统任务 → 偏离原著 → 原主角出场
- **模式B**: 穿成反派 → 改写剧情 → 原主角懵 → 世界线偏移
- **模式C**: 快穿副本 → 任务目标 → 意外变量 → 积分奖励

### 甜宠追妻爆款模式
- **模式A**: 女主离开 → 男主不在意 → 发现真相 → 慌了
- **模式B**: 替身身份揭露 → 女主决绝 → 男主追妻 → 被拒
- **模式C**: 离婚现场 → 男主冷漠 → 女主蜕变 → 男主后悔

### 年代种田爆款模式
- **模式A**: 穿越到年代 → 家徒四壁 → 第一笔生意 → 极品闹事
- **模式B**: 知青下乡 → 被欺负 → 用知识反击 → 带队致富
- **模式C**: 恢复高考 → 重生先知 → 提前布局 → 命运改写

### 重生穿越爆款模式
- **模式A**: 死亡瞬间 → 重生睁眼 → 确认时间 → 仇人就在眼前
- **模式B**: 前世记忆 → 提前截胡 → 仇人懵 → 蝴蝶效应
- **模式C**: 重生回来 → 弥补遗憾 → 意外收获 → 更大阴谋

### 悬疑西幻爆款模式
- **模式A**: 诡异案件 → 不合常理的线索 → 第二条命 → 嫌疑人反转
- **模式B**: 魔法学院 → 禁忌知识 → 被追杀 → 真相碎片
- **模式C**: 密室推理 → 层层反转 → 真相揭露 → 更大谜团
