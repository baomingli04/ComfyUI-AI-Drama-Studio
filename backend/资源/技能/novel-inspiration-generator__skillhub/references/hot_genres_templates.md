# 热门赛道题材模板库

本库覆盖8大热门网文赛道，每个赛道内置专属爽点模板、人设标签、金手指设定和世界观规则。用户选择赛道后自动匹配对应模板，确保生成的灵感/开头/黄金三章符合该赛道的核心爽感结构。

---

## 赛道一：都市赘婿/战神返乡

### 专属爽点模板（固定结构）
```
三年隐忍 → 当众打脸 → 丈母娘/妻子反差 → 身份揭露 → 实力碾压
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 三年隐忍 | 主角以赘婿/普通人身份被全家轻视，忍辱负重 | 压抑↓ |
| 当众打脸 | 关键场合（宴席/婚礼/谈判）主角被迫出手，一击逆转 | 爆发↑↑ |
| 丈母娘/妻子反差 | 曾经最看不起主角的人，态度180度转变 | 爽感↑ |
| 身份揭露 | 主角真实身份曝光（财阀继承人/兵王/医圣） | 震撼↑↑ |
| 实力碾压 | 曾经欺负主角的人逐一被清算 | 持续爽↑ |

### 人设标签
- **男主**: 隐忍型/低调王者/全能隐藏实力，标签：废婿→龙王/战神/神医/财阀少主
- **女主**: 高冷傲娇→追悔莫及，或始终暗中信任男主的温柔型
- **反派标签**: 势利丈母娘、嚣张情敌、家族纨绔、商业对手
- **金手指**: 隐藏身份（财阀/军中/医道传承）、神秘师父、战神血脉

### 世界观核心规则
- 现代都市背景，暗藏地下势力格局
- 权力层级：豪门家族 > 商业集团 > 地下势力 > 普通人
- 核心矛盾：主角隐藏身份的约束 vs 需要出手保护身边人的冲动

### 开头适配风格
- 悬念反转型（推荐）、高燃冲突型、冷峻叙事型

## 赛道二：玄幻签到/无敌流

### 专属爽点模板（固定结构）
```
低调签到 → 积累碾压 → 同辈震惊 → 长老折服 → 一拳秒杀
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 低调签到 | 主角在宗门/圣地签到，获得奖励但不动声色 | 平缓→ |
| 积累碾压 | 签到奖励叠加，实力远超同辈但无人知晓 | 期待↑ |
| 同辈震惊 | 大比/试炼中主角被迫出手，同辈全懵 | 爆发↑↑ |
| 长老折服 | 长老/宗主发现主角实力，态度从轻视到敬畏 | 爽感↑↑ |
| 一拳秒杀 | 越级挑战，一招秒杀Boss级对手 | 巅峰爽↑↑↑ |

### 人设标签
- **男主**: 佛系/懒散/低调但无敌，标签：废柴弟子→签到万年→无敌至尊
- **女主**: 宗门圣女/天才少女，被主角实力吸引
- **反派标签**: 嚣张师兄、天才对手、敌对宗门少主、远古封印魔物
- **金手指**: 签到系统（签到地点越珍贵奖励越大）、无敌血脉、远古传承

### 世界观核心规则
- 修炼体系：练气→筑基→金丹→元婴→化神→渡劫→大乘→飞升
- 宗门格局：圣地>大宗>中宗>小宗>散修
- 核心规则：签到地点品级决定奖励品级（废墟→普通→稀有→传说→神话）

### 开头适配风格
- 戏谑吐槽型（推荐）、悬念反转型、冷峻叙事型

## 赛道三：末世囤货/异能

### 专属爽点模板（固定结构）
```
重生预知 → 疯狂囤货 → 末世降临 → 异能觉醒 → 建立避难所
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 重生预知 | 主角带前世记忆回到末世前，知道即将发生什么 | 紧迫↑ |
| 疯狂囤货 | 倾尽所有囤物资，别人还在嘲笑时主角已准备就绪 | 期待↑ |
| 末世降临 | 灾变爆发，曾经嘲笑主角的人求上门 | 反转爽↑↑ |
| 异能觉醒 | 主角觉醒前世记忆中的异能，远超普通幸存者 | 爆发↑↑ |
| 建立避难所 | 主角成为领袖，建立安全区，收服人心 | 成就感↑ |

### 人设标签
- **主角**: 冷静理智/重生先知/异能觉醒者，标签：末世倒霉蛋→避难所领袖
- **搭档**: 前世战友/异能互补者/忠诚追随者
- **反派标签**: 前世仇人、掠夺者首领、人性泯灭的幸存者、变异体Boss
- **金手指**: 重生记忆（知道物资点/异能觉醒点/安全路线）、空间能力（储物）、异能觉醒

### 世界观核心规则
- 末世类型：丧尸/异变/天灾/外星入侵/灵气复苏变异
- 异能分级：F→E→D→C→B→A→S→SS→SSS
- 核心资源：食物/药品/武器/晶核（异能升级材料）
- 安全区等级：流浪者→小型据点→中型避难所→大型基地→军事要塞

### 开头适配风格
- 倒叙震撼型（推荐）、悬念反转型、高燃冲突型

## 赛道四：穿书/快穿/反派

### 专属爽点模板（固定结构）
```
穿书/进入副本 → 系统任务 → 偏离原剧情 → 改写角色命运 → 世界线重构
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 穿书/进入副本 | 主角穿入小说世界/进入新副本，获得系统任务 | 新奇↑ |
| 系统任务 | 任务要求与原剧情冲突（如：让反派洗白/让炮灰逆袭） | 紧张↑ |
| 偏离原剧情 | 主角的操作导致剧情偏离原著，原主角/原反派措手不及 | 爽感↑↑ |
| 改写角色命运 | 被原著判了"死刑"的角色因主角而改变命运 | 暖+爽↑ |
| 世界线重构 | 主角彻底改写世界走向，从棋子变成执棋者 | 震撼↑↑ |

### 人设标签
- **主角**: 知道剧情的"读者"/任务执行者，标签：炮灰/路人→剧情改写者
- **攻略对象**: 原著反派/原著主角/被虐配角
- **反派标签**: 原著Boss、系统背后的操控者、其他穿书者
- **金手指**: 剧情预知（知道原著走向）、快穿系统、任务奖励

### 世界观核心规则
- 快穿结构：每个世界有独立设定（古代/现代/星际/末世等），系统统一管理
- 任务类型：攻略/逆袭/洗白/救赎/改变结局
- 核心规则：偏离原著剧情程度越大，任务奖励越高，但世界崩坏风险也越大
- 积分体系：完成任务获积分，积分兑换技能/道具/跨世界携带能力

### 开头适配风格
- 戏谑吐槽型（推荐）、倒叙震撼型、悬念反转型

## 赛道五：甜宠/追妻火葬场

### 专属爽点模板（固定结构）
```
男主高冷疏离 → 女主心冷离开 → 男主追悔 → 追妻火葬场 → 甜蜜HE
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 男主高冷疏离 | 男主对女主冷漠/误解/忽视，女主默默付出 | 虐↓ |
| 女主心冷离开 | 女主彻底失望，决然离开，男主不以为意 | 痛↓↓ |
| 男主追悔 | 男主发现真相/意识到离不开女主，开始慌了 | 反转↑ |
| 追妻火葬场 | 男主卑微追妻，各种讨好被拒，读者爽感释放 | 爽↑↑ |
| 甜蜜HE | 误会解开，双向奔赴，甜蜜收尾 | 暖↑↑ |

### 人设标签
- **男主**: 高冷/傲娇/占有欲强→追妻时卑微可怜，标签：总裁/影帝/将军→忠犬
- **女主**: 隐忍→觉醒→决绝→心软，标签：替身/原配/白月光→独立女性
- **反派标签**: 白月光/绿茶/心机配角、阻挠在一起的家族
- **金手指**: 女主重生记忆（知道被辜负的结局，这次不再卑微）/读心术/情感系统

### 世界观核心规则
- 背景可适配：现代都市/娱乐圈/古代宅斗/校园/职场
- 核心规则：感情线是唯一主线，所有冲突服务于情感转折
- 情感节奏：虐（前30%）→ 追（中50%）→ 甜（后20%）
- 关键设定：追妻阶段的"拒绝-靠近-再拒绝-心动"循环

### 开头适配风格
- 高燃冲突型（推荐）、悬念反转型、冷峻叙事型

```
穿越/重生到年代 → 利用现代知识搞钱 → 打脸极品亲戚 → 带领全家致富 → 时代赢家
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 穿越到年代 | 主角穿越到60-80年代，一穷二白 | 困难↓ |
| 利用现代知识 | 用现代知识做小生意/搞养殖/种特色作物 | 期待↑ |
| 打脸极品 | 极品亲戚/邻居欺负上门，主角用智慧和钱反击 | 爽↑↑ |
| 带领全家致富 | 逐步扩大经营，带领全家甚至全村致富 | 成就↑↑ |
| 时代赢家 | 赶上时代红利，成为先富起来的那批人 | 圆满↑ |

### 人设标签
- **主角**: 勤劳聪明/会来事/有现代头脑，标签：农村青年/知青→时代弄潮儿
- **搭档**: 老实可靠的伴侣/一起创业的伙伴
- **反派标签**: 极品婆婆/大伯嫂/嫉妒的邻居/刁难的村干部
- **金手指**: 现代知识（recipes/技术/商业思维）、空间（储物/种菜）、重生预知（知道时代机遇）

### 世界观核心规则
- 时代背景：50-90年代中国农村/城镇，物资匮乏，票证制度
- 核心矛盾：时代限制 vs 主角的现代思维
- 经济体系：工分→个体户→乡镇企业→下海经商（随时代推进）
- 关键节点：包产到户、恢复高考、改革开放、下海潮

### 开头适配风格
- 戏谑吐槽型（推荐）、悬念反转型、冷峻叙事型

## 赛道七：重生/穿越

### 专属爽点模板（固定结构）
```
前世悲剧 → 重生/穿越 → 提前布局 → 改写命运 → 终极清算
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 前世悲剧 | 前世被害/被骗/失败，含恨而终 | 虐↓↓ |
| 重生/穿越 | 回到关键时间节点，带着记忆重新开始 | 燃↑ |
| 提前布局 | 利用预知优势，提前布局截胡仇人 | 爽↑↑ |
| 改写命运 | 前世的遗憾逐一弥补，命运轨迹彻底改变 | 暖+爽↑↑ |
| 终极清算 | 前世仇人逐一清算，因果闭环 | 巅峰爽↑↑↑ |

### 人设标签
- **主角**: 带着前世记忆的复仇者/改命者，标签：受害者→幕后操盘手
- **搭档**: 前世错过的人/新盟友/前世敌人转盟友
- **反派标签**: 前世害主角的人、假白莲花、背叛者、新的敌人
- **金手指**: 前世记忆（人事/事件/机遇）、重生时获得的异能/空间

### 世界观核心规则
- 背景可适配：现代/古代/修仙/末世/星际
- 核心规则：蝴蝶效应——主角的每个改变都会引发连锁反应
- 时间线管理：主角必须记住"原时间线"的关键节点，利用信息差
- 风险机制：改变过大可能触发"时间修正"，前世记忆逐渐模糊

### 开头适配风格
- 倒叙震撼型（推荐）、高燃冲突型、悬念反转型

## 赛道八：悬疑/西幻

### 专属爽点模板（固定结构）
```
诡异事件 → 线索追寻 → 层层反转 → 真相揭露 → 更大谜团
```

### 爽点节点详解
| 节点 | 内容 | 情绪曲线 |
|------|------|----------|
| 诡异事件 | 一起不可能的犯罪/超自然现象发生 | 悬↑ |
| 线索追寻 | 主角通过推理/调查发现隐藏线索 | 紧张↑ |
| 层层反转 | 每个答案都带来新问题，嫌疑人不断变换 | 震撼↑↑ |
| 真相揭露 | 最终真相浮出水面，但远比想象复杂 | 巅峰↑↑ |
| 更大谜团 | 单个案件解决，但牵出更大的阴谋/世界观 | 期待↑ |

### 人设标签
- **主角**: 天才推理者/异常事件调查员/身怀秘密的旅人
- **搭档**: 忠诚助手/能力互补者/身份可疑的盟友
- **反派标签**: 幕后操盘手、伪善权威、不可名状的存在、双面间谍
- **金手指**: 特殊感知能力/前FBI profiler经验/魔法天赋/神秘血脉

### 世界观核心规则
- 悬疑向：现代都市/封闭空间/历史悬案，核心是逻辑推理和线索链
- 西幻向：魔法体系（元素/符文/召唤）、种族（人/精灵/矮人/兽人/龙）、教廷与王权
- 核心规则：每个线索必须合理，反转不能靠"机械降神"
- 氛围管理：悬疑感递进，每个反转都升级危机级别

### 开头适配风格
- 冷峻叙事型（推荐）、悬念反转型、倒叙震撼型
