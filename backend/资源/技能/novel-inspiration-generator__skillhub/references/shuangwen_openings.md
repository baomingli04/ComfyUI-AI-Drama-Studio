# 爽文开头模板库

本库收录爽文开头的爽点类型、风格分类、写作公式和模板示例，供生成开头时参考调用。

---

## 一、爽点类型详解

### 1. 扮猪吃虎
- **核心快感**: 隐藏实力→被轻视→突然暴露→全场震惊
- **读者心理**: 期待"打脸"瞬间的爽感释放
- **开头要点**: 尽快建立"主角被低估"的处境，埋下实力暗示
- **常见场景**: 赘婿被嘲、废物弟子被逐、低调员工被欺负、隐世高手装普通
- **开头节奏**: 先抑后扬——前30字写"惨/弱"，后70字暗示"不简单"

### 2. 重生复仇
- **核心快感**: 带着前世记忆重来，提前布局，让前世的仇人逐步走入陷阱
- **读者心理**: 期待"蝴蝶效应"和"因果清算"的快感
- **开头要点**: 用前世死亡瞬间开场，制造强烈的情感锚点和复仇动力
- **常见场景**: 被背叛致死、含冤而死、众叛亲离、功亏一篑
- **开头节奏**: 倒叙开局——死亡瞬间→重生醒来→确认时间节点→暗下决心

### 3. 系统流
- **核心快感**: 获得外挂能力，以游戏化方式碾压现实困境
- **读者心理**: 期待"升级"和"开箱"的即时正反馈
- **开头要点**: 系统激活的触发条件要意外且有趣，第一波奖励要即时
- **常见场景**: 绝境激活、意外绑定、被选中者、穿越自带系统
- **开头节奏**: 困境→激活→新手大礼包→第一波爽感释放

### 4. 退婚打脸
- **核心快感**: 被退婚/被抛弃→实力暴涨→对方追悔莫及
- **读者心理**: 期待"后悔"和"高攀不起"的情绪释放
- **开头要点**: 退婚场景要写得足够屈辱，为后续打脸蓄力
- **常见场景**: 上门女婿被退婚、世家子弟被悔婚、天才沦为废物后被抛弃
- **开头节奏**: 屈辱场景→决裂→转折暗示（血脉觉醒/传承出现）

### 5. 归来强者
- **核心快感**: 消失数年的强者回归，曾经的轻视者瑟瑟发抖
- **读者心理**: 期待"身份揭露"和"实力碾压"的快感
- **开头要点**: 回归场景要有反差感，低调出场但暗藏锋芒
- **常见场景**: 隐退兵王回城、修仙大能归来、狱中王者出狱、海外巨头回国
- **开头节奏**: 低调回归→遇到旧人→旧人不知→实力暗示

### 6. 万能签到/打卡
- **核心快感**: 每天签到获得奖励，低调积累后一鸣惊人
- **读者心理**: 期待"积攒"和"爆发"的反差爽感
- **开头要点**: 第一次签到奖励要实用且有趣，建立"签到=变强"的循环
- **常见场景**: 在废品站签到、在宗门藏经阁签到、在医院签到
- **开头节奏**: 签到系统激活→首次奖励→时间跳跃（积累期）→首次出手

## 二、开头风格分类

### A. 悬念反转型
- 用一个看似普通的场景开场，最后一句翻转认知
- 适合：扮猪吃虎、归来强者
- 示例节奏：日常描写 → 细节暗示 → 最后一句信息炸弹

### B. 高燃冲突型
- 开篇即冲突，第一句就是矛盾爆发点
- 适合：退婚打脸、重生复仇
- 示例节奏：冲突对话 → 群众反应 → 主角内心独白

### C. 冷峻叙事型
- 极简克制的叙事，信息量密度高，暗藏锋芒
- 适合：归来强者、系统流
- 示例节奏：时间地点交代 → 行为描写 → 身份暗示

### D. 戏谑吐槽型
- 用轻松幽默的口吻化解沉重感，适合轻松向爽文
- 适合：系统流、扮猪吃虎
- 示例节奏：自嘲式独白 → 情况说明 → 反差转折

### E. 倒叙震撼型
- 从高潮/死亡/结局开场，再回溯开始
- 适合：重生复仇、归来强者
- 示例节奏：震撼场景 → "一切要从X天前说起" → 时间回溯

## 三、开头写作公式

### 公式1：反差三段式（万能型）
```
[日常/屈辱场景，20-30字] + [细节暗示不简单，20-30字] + [反转/悬念收尾，20-40字]
```
适用：大多数爽点类型

### 公式2：对话冲突式
```
[对方嚣张台词] + [围观者嘲讽/附和] + [主角平淡反应，暗藏实力]
```
适用：退婚打脸、扮猪吃虎

### 公式3：系统激活式
```
[主角困境] + [叮——系统激活] + [新手大礼包] + [第一波爽感]
```
适用：系统流

### 公式4：重生回溯式
```
[前世死亡瞬间，高密度情绪] + [重生睁眼] + [确认时间节点] + [暗下决心]
```
适用：重生复仇

### 公式5：归来低调式
```
[回归场景，极简叙事] + [偶遇旧人，对方不识] + [一个动作暴露实力冰山一角]
```
适用：归来强者

## 四、各爽点开头模板示例

### 扮猪吃虎 · 悬念反转型
> 林安把外卖放在前台时，前台小姑娘头都没抬："放那儿吧。"
> 没人知道，这份外卖送到的写字楼十七层，整层都是他的。
> 更没人知道，三分钟前他在电梯里接的那个电话，让这栋楼的开发商连夜从国外飞了回来。

### 重生复仇 · 倒叙震撼型
> 刀子捅进后心的时候，苏晚其实没觉得疼。
> 她只是想笑——护了十年的人，拿命喂出来的白眼狼。
> 再睁眼，教室墙上的日历写着2014年9月1日。
> 她十七岁。一切还来得及。

### 系统流 · 戏谑吐槽型
> 陈默觉得自己可能是全网最惨的穿越者。
> 别人穿越带金手指，他穿越带了个打卡机——对，就是工地门口那种。
> "叮！在'废品回收站'签到成功，获得：废铁一块。"
> 他看着手里锈迹斑斑的铁疙瘩，陷入了沉思。

### 退婚打脸 · 高燃冲突型
> "这婚，我退了。"
> 陆家大厅里，穿着名牌的年轻女人把订婚戒指推到桌对面，语气像在通知一个陌生人。
> 满堂宾客看向角落里那个沉默的男人。
> 沈舟把戒指收进口袋，站起来，笑了笑："好。"
> 他没说出口的是——三天后你们陆家求着退回来的，就不止是一枚戒指了。

### 归来强者 · 冷峻叙事型
> 青州火车站，下午两点。
> 一个穿旧军装的男人提着蛇皮袋走出出站口，在台阶上站了一会儿。
> 六年前他从这里离开时，整条街的人放鞭炮送行。
> 六年后回来，没人认出他。
> 手机响了，那头声音发颤："长官，青州的线报确认了，您要找的人……就在本地。"

## 五、开头质量检查清单

生成开头后，逐项检查：

- [ ] **前50字有钩子**: 读者在前50字内必须产生"然后呢？"的好奇心
- [ ] **主角有辨识度**: 姓名出现，且至少一个特征让读者记住
- [ ] **爽点方向明确**: 开头必须暗示核心爽点类型，不能模糊
- [ ] **信息量适中**: 不能太少（空洞）也不能太多（信息过载）
- [ ] **留有余地**: 开头是引子，不要把底牌全亮
- [ ] **节奏明快**: 避免大段景物描写，用动作和对话推进
- [ ] **结尾有悬念/期待感**: 最后一句要让人想往下读
