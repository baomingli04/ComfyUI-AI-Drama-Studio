# 网文题材参考手册

本手册涵盖主流网文题材的核心要素、常见套路、世界观构建方向和角色原型，供生成灵感时参考。

---

## 一、主流题材速览

### 1. 玄幻
- **核心设定**: 灵气/斗气/元气等修炼体系，境界分明（如练气→筑基→金丹→元婴→化神→大乘→渡劫）
- **常见世界观**: 大陆割据、宗门林立、万族争霸、远古遗迹
- **经典套路**: 废柴逆袭、神器认主、远古传承、丹药/阵法/符箓副职业、拍卖会捡漏
- **角色原型**: 隐忍型主角、亦正亦邪型、热血战斗型、腹黑智谋型
- **冲突驱动**: 宗门大比、秘境探索、种族战争、飞升之劫

### 2. 仙侠
- **核心设定**: 修仙求道，渡劫飞升，天道法则
- **常见世界观**: 凡界→灵界→仙界→神界的多层结构，仙门与散修并存
- **经典套路**: 逆天改命、道心磨砺、仙魔之争、轮回转世、因果业力
- **角色原型**: 问道痴修、红尘历练者、亦仙亦魔、转世大能
- **冲突驱动**: 天劫降临、仙门论道、渡劫失败重修、仙界阴谋

### 3. 都市异能
- **核心设定**: 现代都市背景下的超自然能力觉醒，隐藏社会与普通社会并存
- **常见世界观**: 异能者组织、暗世界、神秘事件调查局、超自然学院
- **经典套路**: 觉醒异能、隐世高手、都市暗面、地下势力角逐、神秘遗产继承
- **角色原型**: 平凡觉醒者、隐世传人、双面人生、都市猎人
- **冲突驱动**: 异能犯罪、组织对决、秘密曝光危机、跨维度入侵

### 4. 科幻
- **核心设定**: 未来科技、星际探索、人工智能、基因改造
- **常见世界观**: 星际帝国、赛博朋克都市、末日废土、虚拟现实世界
- **经典套路**: 文明等级跃迁、星际殖民、AI觉醒、基因进化、时间旅行
- **角色原型**: 星际探险者、赛博黑客、基因改造人、AI与人类混血
- **冲突驱动**: 星际战争、文明冲突、技术伦理危机、宇宙灾难

### 5. 悬疑/推理
- **核心设定**: 谜题驱动，层层推理，真相隐藏在线索之中
- **常见世界观**: 现代都市、封闭空间、历史悬案、超自然谜团
- **经典套路**: 密室杀人、连环谜题、不可靠叙述者、反转再反转、时间线交错
- **角色原型**: 天才侦探、业余推理者、罪犯视角、受害者视角
- **冲突驱动**: 连环案件、密室谜题、阴谋揭露、心理博弈

### 6. 言情
- **核心设定**: 情感关系为核心，可融合任何题材背景
- **常见世界观**: 现代都市、古代宫廷、校园、职场、星际、末世
- **经典套路**: 欢喜冤家、破镜重圆、先婚后爱、青梅竹马、替身文学、重生追爱
- **角色原型**: 冷面精英、温暖治愈系、腹黑深情、独立自强型
- **冲突驱动**: 误会与化解、身份差异、外部阻碍、情感成长

### 7. 历史/架空历史
- **核心设定**: 基于或借鉴真实历史，可加入架空元素
- **常见世界观**: 朝堂权谋、乱世争霸、江湖武林、穿越改史
- **经典套路**: 穿越重生、权谋布局、种田发展、军事谋略、改写历史
- **角色原型**: 腹膜权臣、草根崛起、穿越者、乱世枭雄
- **冲突驱动**: 皇权争夺、外敌入侵、世家倾轧、变革与守旧

### 8. 无限流/轮回
- **核心设定**: 主角进入多个副本/世界完成任务，积累能力
- **常见世界观**: 无限空间、轮回世界、游戏化副本、生存竞技
- **经典套路**: 副本通关、规则解析、隐藏任务、团队组建、BOSS战
- **角色原型**: 智力型通关者、战斗型莽夫、辅助型支援、反派型掠夺者
- **冲突驱动**: 副本难度升级、玩家内斗、隐藏规则、终极真相

### 9. 系统/游戏化
- **核心设定**: 主角获得系统面板，以游戏化方式成长
- **常见世界观**: 可叠加任何题材背景，核心是系统机制
- **经典套路**: 签到系统、任务系统、抽奖系统、商城系统、成就系统
- **角色原型**: 系统宿主、NPC觉醒者、游戏玩家穿越
- **冲突驱动**: 系统任务、排行榜竞争、系统升级解锁、隐藏系统功能

### 10. 末世/废土
- **核心设定**: 文明崩塌后的生存世界，资源稀缺，危险遍布
- **常见世界观**: 丧尸末世、核废土、异变生物、自然灾害、外星入侵后
- **经典套路**: 重生先知、避难所建设、变异能力觉醒、物资搜刮、人性考验
- **角色原型**: 冷酷求生者、避难所领袖、变异者、守护者
- **冲突驱动**: 资源争夺、丧尸潮/兽潮、幸存者势力冲突、环境恶化

## 二、灵感生成维度

生成灵感时，从以下维度组合创意：

### 核心悬念（Hook）
- 一句话能引起好奇心的设定或反转
- 例：「一个每死一次就会回到当天的清晨，但每次保留一项死前技能的人」

### 冲突引擎
- 内在冲突：道心 vs 欲望、记忆 vs 现实、人性 vs 力量
- 外在冲突：势力对抗、资源争夺、生存危机、理念碰撞
- 持续动力：升级体系、谜题链、情感纠葛、世界真相逐步揭露

### 差异化要素
- 反套路：对经典套路的颠覆或反转
- 融合创新：跨题材元素组合（如「修仙+赛博朋克」「系统+历史」）
- 独特视角：非主角视角、反派视角、旁观者视角
- 设定创新：新颖的力量体系、独特的社会结构、原创的规则

### 情感锚点
- 读者共鸣点：成长、复仇、守护、自由、归属
- 情感节奏：爽感（打脸/逆袭）、燃（热血战斗）、虐（情感纠葛）、暖（日常治愈）

## 三、角色设计框架

生成角色时参考以下维度：

| 维度 | 说明 |
|------|------|
| 核心动机 | 驱动角色行动的根本欲望（复仇、守护、求道、自由等） |
| 性格特质 | 2-3个鲜明特质组合，避免脸谱化 |
| 背景故事 | 影响角色性格和动机的关键经历 |
| 成长弧线 | 角色从起点到终点的内在变化轨迹 |
| 缺陷/弱点 | 使角色立体可信的短板或执念 |
| 标志性特征 | 外貌、口头禅、习惯动作等辨识度元素 |
| 关系网络 | 与主角/其他角色的关系张力 |

## 四、世界观构建清单

| 层面 | 要素 |
|------|------|
| 力量体系 | 修炼境界/异能分级/科技等级，升级路径清晰 |
| 社会结构 | 势力分布、阶层划分、权力运作方式 |
| 历史背景 | 影响当前格局的重大历史事件 |
| 经济系统 | 资源流通方式、货币体系、交易规则 |
| 文化风俗 | 信仰、禁忌、节日、日常生活细节 |
| 地理环境 | 核心区域、危险地带、资源产地 |
| 规则/禁忌 | 世界运转的核心法则和违反后果 |
| 悬念伏笔 | 世界中尚未揭露的谜题和真相 |
