# 黄金三章框架模板库

本库定义「黄金三章配套生成」模式的输出结构、各模块规范和章节爽点节点设计模板。黄金三章是网文开局的核心——前三章决定读者留存率，必须做到"章章有爽点、章章有钩子"。

---

## 一、黄金三章整体架构

```
核心人设 → 世界观核心规则 → 前3章爽点节点
```

三者必须逻辑自洽：人设决定金手指，金手指融入世界观规则，前3章爽点依赖金手指和世界观的交互。

---

## 二、核心人设模板

### 2.1 男主/女主档案

```
【主角档案】
- 姓名：
- 年龄：
- 表面身份：（开局时的身份，越低越好）
```

### 2.4 金手指设定

| 金手指类型 | 说明 | 适用赛道 |
|------------|------|----------|
| 系统类 | 签到/任务/商城/抽奖系统，游戏化成长 | 玄幻签到、穿书快穿 |
| 血脉类 | 远古血脉/特殊体质/先天灵根 | 玄幻、重生 |
| 空间类 | 随身空间/储物空间/种植空间 | 末世囤货、年代种田 |
| 预知类 | 重生记忆/穿书剧情预知/未来碎片 | 重生穿越、穿书快穿 |
| 身份类 | 隐藏的财阀/军中/医道身份 | 都市赘婿、战神返乡 |
| 异能类 | 觉醒超能力/魔法天赋 | 末世、悬疑西幻 |
| 技能类 | 现代知识/专业能力穿越 | 年代种田、重生 |

金手指设定规范：
- **获得方式**：必须在第1章交代清楚
- **使用限制**：必须有代价或冷却，不能无脑无敌
- **成长路径**：金手指本身要有升级空间
- **与剧情绑定**：每个爽点节点都依赖金手指的运用

## 四、前3章爽点节点设计

### 4.1 总体节奏要求

| 章节 | 核心任务 | 爽点类型 | 结尾要求 |
|------|----------|----------|----------|
| 第1章 | 建立处境+激活金手指 | 第一个小爽点 | 留悬念钩子 |
| 第2章 | 首次运用金手指 | 打脸/逆袭爽点 | 矛盾升级 |
| 第3章 | 首次大爆发 | 碾压级爽点 | 引出更大危机 |

### 4.2 第1章模板

```
【第1章：处境建立+金手指激活】
- 场景：（主角所处的低谷场景）
- 冲突点：（主角面临的具体困境/羞辱/危机）
- 金手指激活：（系统绑定/血脉觉醒/重生醒来/空间开启）
- 首个爽点：（金手指带来的第一个小优势，让读者看到希望）
- 结尾钩子：（一句话制造悬念，让读者必须点下一章）
```

第1章节奏公式：
```
低谷处境(200字) → 冲突爆发(300字) → 金手指激活(200字) → 首次小爽(200字) → 钩子结尾(100字)
```

### 4.3 第2章模板

```
【第2章：首次出手+打脸】
- 场景：（第1章冲突的延续或新场景）
- 冲突点：（对手继续嚣张/新麻烦出现）
- 金手指运用：（主角用金手指化解危机）
- 爽点释放：（对手震惊/围观者震惊/态度反转）
- 结尾钩子：（更大的麻烦/更强的对手出现）
```

第2章节奏公式：
```
对手嚣张(200字) → 主角隐忍/布局(200字) → 金手指出手(200字) → 打脸爽感(300字) → 新危机钩子(100字)
```

### 4.4 第3章模板

```
【第3章：碾压爆发+格局展开】
- 场景：（升级版冲突场景，如大比/宴席/末世爆发）
- 冲突点：（比前两章更强的对手/更大的危机）
- 金手指爆发：（金手指的更强运用，超出所有人预期）
- 碾压爽点：（实力差距碾压，全场震撼）
- 结尾钩子：（引出主线——更大的世界/更强的对手/更深的秘密）
```

第3章节奏公式：
```
大场面铺垫(200字) → 强敌出现(200字) → 主角出手(200字) → 碾压震撼(300字) → 主线开启钩子(100字)
```

## 五、黄金三章质量检查清单

生成后逐项检查：

- [ ] **第1章有钩子**：结尾是否有让读者必须点下一章的悬念
- [ ] **金手指清晰**：第1章是否交代了金手指的获得方式和基本功能
- [ ] **爽点递进**：3章爽点是否逐章升级（小爽→打脸→碾压）
- [ ] **反派可打脸**：前期反派是否足够嚣张，打脸是否够爽
- [ ] **人设鲜明**：主角至少有1个让人记住的标志性特征
- [ ] **世界观自洽**：金手指在世界观规则内运作，无矛盾
- [ ] **第3章引主线**：第3章结尾是否从"单元冲突"升级到"主线悬念"
- [ ] **节奏明快**：每章1000字内有冲突出现，避免慢热
- [ ] **CP/搭档暗示**：如果有CP线，前3章是否有暗示
- [ ] **留有余地**：金手指不要在第3章就全部展示，留成长空间

## 六、各赛道黄金三章速查

### 都市赘婿
- 第1章：赘婿被全家羞辱 → 隐藏身份暗示 → 钩子：一个电话暴露身份冰山一角
- 第2章：丈母娘介绍"优秀女婿"候选人 → 主角被当空气 → 候选人挑衅 → 主角一句话让对方公司股价暴跌 → 钩子：女主看到全程
- 第3章：家族宴会 → 族长当众宣布主角"不配" → 主角真实身份揭露 → 全场跪 → 钩子：更大的家族找上门

### 玄幻签到
- 第1章：废柴弟子被分到最差住处 → 签到系统激活 → 首次签到获奖励 → 钩子：发现住处竟是远古禁地
- 第2章：师兄抢夺资源 → 主角签到获得的功法碾压 → 师兄震惊 → 钩子：宗门大比公告
- 第3章：宗门大比 → 主角一招秒杀种子选手 → 长老折服 → 钩子：敌对宗门来袭

### 末世囤货
- 第1章：重生回到末世前30天 → 疯狂采购囤货 → 空间能力觉醒 → 钩子：倒计时7天
- 第2章：末世爆发 → 邻居求上门 → 主角冷漠拒绝 → 异能觉醒 → 钩子：变异体靠近
- 第3章：变异体围攻楼栋 → 主角异能全开碾压 → 建立第一个安全据点 → 钩子：军队残部求合作

### 穿书快穿
- 第1章：穿成炮灰/反派 → 系统发布任务 → 偏离原著第一步 → 钩子：原著主角出场
- 第2章：原著主角按剧情行动 → 主角提前截胡 → 剧情偏离 → 钩子：被偏离的角色产生自我意识
- 第3章：关键剧情节点 → 主角彻底改写走向 → 任务完成 → 钩子：系统背后的真相暗示

### 甜宠追妻
- 第1章：女主在男主身边最后一天 → 默默离开 → 男主不以为意 → 钩子：男主发现女主真的走了
- 第2章：男主开始不习惯 → 调查女主去向 → 发现自己亏欠多少 → 钩子：女主身边出现新的人
- 第3章：男主追到女主面前 → 被冷漠拒绝 → 火葬场开始 → 钩子：女主隐藏的秘密

### 年代种田
- 第1章：穿越到六零/七零 → 家徒四壁 → 用现代知识做第一笔小生意 → 钩子：被极品亲戚盯上
- 第2章：极品亲戚闹事 → 主角用智慧和钱反击 → 全村震惊 → 钩子：更大的商机出现
- 第3章：扩大经营 → 带领全家致富 → 打脸所有看不起的人 → 钩子：时代机遇降临

### 重生穿越
- 第1章：前世死亡瞬间 → 重生醒来 → 确认时间节点 → 钩子：前世仇人就在眼前
- 第2章：提前布局截胡 → 仇人计划落空 → 暗爽 → 钩子：蝴蝶效应引发新变数
- 第3章：关键事件改写 → 前世遗憾弥补 → 实力碾压 → 钩子：更大的阴谋浮出水面

### 悬疑西幻
- 第1章：诡异案件发生 → 主角介入调查 → 发现不合常理的线索 → 钩子：第二条人命
- 第2章：深入调查 → 嫌疑人指向意想不到的人 → 反转 → 钩子：主角自身也陷入危险
- 第3章：真相初步揭露 → 但牵出更大谜团 → 危机升级 → 钩子：幕后组织的影子
