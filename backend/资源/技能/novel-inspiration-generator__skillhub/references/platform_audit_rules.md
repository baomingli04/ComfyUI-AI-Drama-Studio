本库覆盖番茄小说、起点中文网、晋江文学城、七猫小说四大平台的审核规则。所有模式生成内容后，在输出前自动执行敏感词检查，标记违规内容并提供替代建议，最后给出各平台「过审概率评分」，避免用户发书被卡。

### 6. 平台特有规则

**番茄小说特有：**
- 标题不能含"最""第一"等极限词
- 简介不能有联系方式
- 免费章节不能有付费引导
- 对"系统流"有额外审核（避免类传销表述）

**起点中文网特有：**
- 敏感词会触发"章节锁定"而非直接拒发
- 对"穿越改史"类内容审核更严
- VIP章节审核比免费章节宽松
- 同一作品多次违规会降权

**晋江文学城特有：**
- 分级制度：全年龄/12+/16+/18+
- 性别区分：耽美/言情分区严格
- "先审后发"机制：新章节需审核通过才可见
- 对"师生恋""未成年恋爱"零容忍

**七猫小说特有：**
- 免费阅读模式，作者靠广告分成，审核向番茄看齐
- 标题/简介禁用"最""第一""绝世"等极限词和夸大宣传
- 对"系统流/无限流"的涉传销表述（如"拉人头""层级返利"）敏感
- 开篇前 3 章完读率要求高，建议前 3 章密集埋钩子

## 三、过审概率评分方法论（自动输出）

生成内容经敏感词检查后，按平台分别计算「过审概率评分」（0–100，越高越安全）：

```
基础分 = 98
对每个命中敏感词，按类型与平台扣分：
  - 政治敏感：  各平台 -40（命中即高危）
  - 色情低俗：  番茄 -25 / 起点 -25 / 晋江 -30 / 七猫 -25
  - 暴力血腥：  番茄 -8  / 起点 -6  / 晋江 -12 / 七猫 -8
  - 违禁品/违法：番茄 -15 / 起点 -15 / 晋江 -18 / 七猫 -15
  - 价值观导向：各平台 -5（每处）
最终得分 = max(5, min(99, 基础分 - 扣分总和))
```

评分区间提示：
- **≥90**：绿区，安全，可直接投稿
- **70–89**：黄区，需留意标红处，建议替换后投稿
- **<70**：红区，命中高危项，必须修改后再投

输出时同时给出四平台分数条，并推荐分数最高的平台作为首发建议。

## 四、自动检查与标记规范

### 检查流程

所有模式生成内容后，在输出给用户前，自动执行以下检查：

```
生成内容 → 政治敏感检查 → 色情低俗检查 → 暴力血腥检查 → 违法内容检查 → 价值观检查 → 输出
```

### 标记格式

发现敏感内容时，在对应位置插入标记：

```
[⚠️ 敏感词标记] 原文内容 → 建议替代：替代内容（违规类型：xxx | 番茄:禁/起点:限/晋江:禁）
```

### 检查报告格式

在生成内容末尾附上检查报告：

```
---
📋 敏感词检查报告

| 检查项 | 状态 | 详情 |
|--------|------|------|
| 政治敏感 | ✅ 通过 | 未发现违规内容 |
| 色情低俗 | ⚠️ 注意 | 第2段"xxx"建议替换为"xxx"（晋江敏感） |
| 暴力血腥 | ✅ 通过 | 暴力描写在平台允许范围内 |
| 违法内容 | ✅ 通过 | 未发现违规内容 |
| 价值观导向 | ⚠️ 注意 | 打脸动机建议强化"被欺负在先"的铺垫 |

过审概率评分：番茄 95 · 起点 96 · 晋江 88 · 七猫 95
推荐发布平台：起点中文网 | 番茄小说 | 七猫小说（根据内容适配度推荐）
```

### 平台适配建议

根据生成内容的特征，自动推荐最适合的发布平台：

| 内容特征 | 推荐平台 | 原因 |
|----------|----------|------|
| 高频打脸/爽文 | 番茄小说 | 免费流量大，爽文受众集中 |
| 长篇连载/复杂世界观 | 起点中文网 | 付费生态成熟，容忍度稍高 |
| 甜宠/言情/细腻情感 | 晋江文学城 | 女频读者集中，情感向优势 |
| 暴力描写较多 | 起点中文网 | 三平台中暴力容忍度最高 |
| 敏感度较高的创新设定 | 起点中文网 | 审核机制有缓冲（锁章而非拒发） |
