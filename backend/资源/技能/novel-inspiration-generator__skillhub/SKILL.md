# Novel Inspiration Generator

## Overview

为创作者提供结构化的小说灵感生成能力，覆盖六大模式 + 九项增值能力：

1. **灵感综合生成** — 故事大纲、角色设定、世界观构建
2. **爽文开头生成** — 多风格开头快速产出
3. **黄金三章配套生成** — 核心人设+世界观规则+前3章爽点节点
4. **爆款对标生成** — 输入爆款开头/书名，自动拆解爽点结构，生成同风格同赛道内容
5. **章节续写** — 粘贴已有章节，生成下一段续写（AI 模式可真正读懂原文续写）
6. **新书配套生成** — 一键产出匹配的小说简介（三版）+ AI 封面预览/提示词 + 投稿渠道推荐，搞定新书前期准备

九项增值能力（所有模式通用）：
- **① 网文合规审核** — 内置番茄/起点/晋江/七猫四平台敏感词规则，生成后自动标红违规词+替换建议+过审概率评分，避免投稿被卡
- **② 热门元素自动植入** — 可选植入当前番茄/起点新书榜热门元素（国运/算命/四合院/玄学大佬/规则怪谈等），提升爆款概率
- **③ 引流文案配套生成** — 开关开启后，生成适配小红书/抖音/快手的引流短文案，自带"后续更精彩"类钩子
- **④ 生成历史存档** — 每次生成自动保存记录（最多50条，localStorage），支持随时查看/复用/复制/删除，不用每次重新生成
- **⑤ 自定义模板保存** — 把常用参数组合（如「末世囤货+女主+空间+搞笑」）保存为命名模板，下次一键套用，不用重复选择
- **⑥ 爽点节奏检查** — 每次生成后自动评分（100分制）：检查开头300字内是否出冲突、结尾是否有钩子、爽点密度是否≥2.5个/千字、内容体量是否充足，并给新手修改建议
- **⑦ 章节续写** — 支持粘贴章节生成下1000/2000字续写草案（含冲突点+结尾钩子），可选"保持人设/世界观不变"
- **⑧ 多平台风格适配** — 顶部全局选择目标平台（通用/番茄/起点/晋江/七猫/知乎），所有模式生成后自动附加「平台风格适配卡」，并按平台调整节奏偏好、内容侧重、文风语气与避坑要点
- **⑨ 新书配套** — 独立模式生成三版简介（短/中/长，按平台语气）、封面 CSS 预览+AI 图像生成提示词（可交 AI 出真实封面）、投稿渠道推荐（按题材匹配番茄/起点/晋江/七猫/飞卢/知乎，含付费模式与官方渠道，附防诈骗声明）

内置8大热门赛道专属爽点模板，选定赛道后自动匹配固定爽点结构。支持多版本批量生成（同一关键词出3-5个不同方向）。支持一键导出为 Markdown / Word / 剪贴板。

## When to Use

以下场景触发本 skill：

**灵感综合生成模式：**
- 用户请求小说/故事创意、灵感、脑洞、点子
- 用户需要设计角色、构建世界观、撰写故事大纲
- 用户提到「写作卡文了」「来点灵感」「帮我想个故事」「角色怎么设计」「世界观怎么设定」
- 用户要求生成特定题材的设定方案
- 用户请求将灵感方案保存为文件

**爽文开头生成模式：**
- 用户提到「写爽文开头」「爽文开头」「要爽文开头」「小说开头怎么写」「帮我写个开头」
- 用户提到具体爽点方向：「扮猪吃虎」「重生复仇」「系统流」「退婚打脸」「归来强者」「签到打卡」
- 用户要求生成多个不同风格的开头供选择

**黄金三章配套生成模式：**
- 用户提到「黄金三章」「前三章」「开局框架」「落地框架」
- 用户要求生成「人设+世界观+爽点」整套方案
- 用户提到「帮我设计开局」「前三章怎么写」「开局怎么安排爽点」
- 用户需要从灵感到落地的完整框架

**爆款对标生成模式：**
- 用户提到「对标」「拆解」「仿写」「同风格」「参考这个开头」
- 用户粘贴一段网文开头并要求分析其爽点结构
- 用户提到某个书名/作者并要求「按这个风格写」
- 用户提到「帮我分析这个开头为什么火」「拆解一下这个爆款」

**章节续写模式：**
- 用户提到「续写」「接着写」「下一章」「卡文了帮我续」「这段后面怎么写」
- 用户粘贴了一段已写内容并要求「帮我往下写N字」
- 用户要求「保持人设/世界观不变续写」

**增值能力触发词（可与上述任意模式叠加）：**
- 合规审核：「过审」「敏感词」「会不会被卡」「违规」「审核」
- 热门元素：「植入热门元素」「最近火的」「国运/玄学/四合院」「蹭热点」
- 引流文案：「引流」「小红书文案」「抖音文案」「快手文案」「推广文案」

## Workflow

### 模式判断

根据用户输入判断使用哪种模式：

- **灵感综合生成模式**: 用户请求故事大纲、角色设定、世界观、综合灵感 → 进入模式一
- **爽文开头生成模式**: 用户请求写开头、爽文开头、特定爽点方向的开头 → 进入模式二
- **黄金三章配套生成模式**: 用户请求黄金三章、开局框架、人设+世界观+爽点整套 → 进入模式三
- **爆款对标生成模式**: 用户粘贴爆款开头/书名并要求拆解或仿写 → 进入模式四
- **章节续写模式**: 用户粘贴已有章节并要求续写 → 进入模式五（读取粘贴内容，保持人设/世界观，续写含冲突点+钩子）

### 赛道匹配（所有模式通用）

1. 扫描用户输入，与「题材赛道体系」中的关键词匹配
2. 匹配成功 → 加载 `references/hot_genres_templates.md` 中对应赛道的专属模板
3. 匹配失败 → 列出8大赛道供用户选择
4. 用户指定题材但不在8大赛道中 → 回退到 `references/web_novel_genres.md` 的通用题材库

### 多版本批量生成（所有模式通用）

当用户请求多个方案，或未指定但需要提供选择时：

1. 加载 `references/hot_genres_templates.md` 中「批量生成方向变体」表
2. 根据匹配赛道选取3-5个不同方向变体
3. 每个变体独立生成完整内容，确保方向差异化
4. 输出时标注每个版本的方向标签

### 敏感词自动过滤（所有模式通用，输出前必执行）

所有模式生成内容后，在输出给用户前，必须执行敏感词检查（网文合规审核模块）：

1. 加载 `references/platform_audit_rules.md`（已覆盖番茄/起点/晋江/**七猫**四大平台）
2. 依次检查：政治敏感 → 色情低俗 → 暴力血腥 → 违法内容 → 价值观导向
3. 发现敏感内容时，**在正文对应位置标红**该词，并给出替换建议：`[⚠️ 敏感词标记] 原文 → 建议替代：xxx（违规类型 | 番茄:禁/起点:限/晋江:禁/七猫:限）`
4. 计算**四平台过审概率评分**（0–100，按违规类型/平台扣分，详见规则库「过审概率评分方法论」），以分数条呈现并推荐分数最高的平台首发
5. 在生成内容末尾附上检查报告（检查项/状态/详情表格 + 评分条 + 推荐平台）
6. 如果内容完全安全，简化输出为：`✅ 敏感词检查通过，四平台适配度：番茄98·起点98·晋江98·七猫98`

### 一键导出（所有模式通用）

用户可随时要求导出生成的内容，支持三种方式：

| 导出方式 | 说明 | 实现方法 |
|----------|------|----------|
| Markdown 文件 | 生成 `.md` 文件，结构化排版 | 使用 Write 工具写入文件，文件名格式：`<内容类型>_<赛道/主角名>_<日期>.md` |
| Word 文件 | 生成 `.docx` 文件，可直接用于投稿 | 生成 HTML 后通过 html-to-docx skill 转换为 Word |
| 剪贴板复制 | 将纯文本内容复制到剪贴板 | 将内容整理为纯文本格式，通过命令写入系统剪贴板 |

用户说「导出」「保存」「下载」时，询问导出格式（如未指定则默认 Markdown）。导出后使用 `present_files` 展示文件。

### 热门元素自动植入（所有模式通用，可选）

用户可要求「植入最新热门元素」提升爆款概率：

1. 加载 `references/hot_elements.md`，获取当前番茄/起点新书榜热门元素清单（国运、算命/玄学、四合院、玄学大佬、规则怪谈、诡异修仙、神豪/钞能力、读心术、年代美食、重生+直播等）
2. 用户指定具体元素，或未指定则默认从「外挂型」中随机挑选 1 个
3. 将元素作为金手指/外挂**叠加**进已匹配赛道的爽点结构（而非孤立堆砌），并标注融合方式 + 自检（已包裹爽点结构/与金手指自洽/保留原赛道核心冲突）
4. 每周用 WebSearch 同步一次榜单，更新 `hot_elements.md` 的清单

### 引流文案配套生成（模式二默认可用，其他模式可叠加）

用户开启「生成配套引流文案」后，生成完爽文开头自动输出适配三平台的短文案：

1. **小红书文案** — emoji 风、标题党钩子、「想看全本点我主页」类引导、带 #话题标签
2. **抖音文案** — 口语化、「家人们谁懂啊」、「点关注看全集」类钩子
3. **快手文案** — 老铁风、「双击屏幕看全集」类钩子
文案需从生成的开头截取钩子片段，避免剧透核心反转。

## 模式一：灵感综合生成

### Step 1A: 确认需求

根据用户输入识别以下要素（缺失时主动询问，但尽量从上下文推断，避免过度提问）：

| 要素 | 说明 | 默认值 |
|------|------|--------|
| 题材/赛道 | 8大热门赛道 或 通用题材 | 不限时随机选取 |
| 生成维度 | 故事大纲 / 角色设定 / 世界观 / 综合方案 | 综合方案 |
| 数量 | 生成几套方案 | 1套（综合）或3套（单项） |
| 特殊要求 | 用户指定的元素、风格、禁忌等 | 无 |
| 输出格式 | 对话文本 / Markdown 文件 | 对话文本 |

### Step 2A: 加载参考

- 匹配到热门赛道 → 加载 `references/hot_genres_templates.md` 中对应赛道的爽点模板、人设标签、金手指和世界观规则
- 通用题材 → 加载 `references/web_novel_genres.md` 获取核心设定、常见套路、角色原型等

### Step 3A: 生成灵感内容

#### 故事大纲生成

按以下结构输出：

1. **一句话简介（Logline）**: 用一句话概括故事核心，包含主角、目标、冲突和独特设定
2. **核心悬念（Hook）**: 能在3秒内抓住读者的设定或反转
3. **故事梗概**: 200-300字概述起承转合
4. **主线冲突**: 主角面临的核心矛盾和驱动力
5. **关键转折点**: 3-5个推动剧情的重大转折
6. **差异化亮点**: 与同类作品的区别和创新点
7. **目标读者画像**: 适合什么口味的读者

匹配到热门赛道时，故事大纲必须遵循该赛道的专属爽点结构。

#### 角色设定生成

按以下结构输出：

1. **基础档案**: 姓名、年龄、身份、外貌标志特征
2. **核心动机**: 驱动角色行动的根本欲望
3. **性格特质**: 2-3个鲜明特质组合，附具体行为表现
4. **背景故事**: 影响角色性格和动机的关键经历
5. **成长弧线**: 从起点到终点的内在变化轨迹
6. **缺陷与弱点**: 使角色立体可信的短板或执念
7. **关系网络**: 与主角/关键角色的关系张力
8. **标志性细节**: 口头禅、习惯动作、招牌技能等辨识度元素

匹配到热门赛道时，使用该赛道的人设标签和金手指设定。

#### 世界观构建生成

按以下结构输出：

1. **世界基调**: 整体氛围和核心法则
2. **力量体系**: 修炼境界/异能分级/科技等级，含升级路径
3. **社会结构**: 势力分布、阶层划分、权力运作
4. **历史背景**: 影响当前格局的重大事件（2-3条）
5. **地理环境**: 核心区域和危险地带概述
6. **经济与资源**: 核心资源、流通方式、货币体系
7. **文化与禁忌**: 信仰、风俗、世界规则与违反后果
8. **悬念伏笔**: 世界中尚未揭露的谜题（2-3条）

匹配到热门赛道时，使用该赛道的世界观核心规则。

#### 综合方案

依次输出故事大纲 → 主要角色设定（主角+1-2个关键配角）→ 世界观框架，确保三者逻辑自洽、互相支撑。匹配到热门赛道时，三者均遵循赛道专属模板。

### Step 4A: 确保创意质量

- **避免俗套堆砌**: 可以使用经典元素，但必须加入至少一个反套路或创新点
- **内在逻辑自洽**: 力量体系、社会结构、角色动机之间不能矛盾
- **留有发展空间**: 设定中预留可扩展的悬念和伏笔
- **情感锚点明确**: 每套方案必须标注核心情感驱动力（爽/燃/虐/暖/悬）
- **网文节奏意识**: 考虑网文读者的阅读习惯，开头要有钩子，节奏要明快
- **赛道爽点完整**: 匹配赛道时，爽点结构的每个节点必须体现

### Step 5A: 输出

#### 对话输出

直接在对话中按上述结构输出，使用 Markdown 格式保持可读性。多版本批量生成时，每个版本用分隔线区分并标注方向标签。

#### 文件输出

当用户要求保存为文件时，使用 Write 工具生成 `.md` 文件，文件名格式：`小说灵感_<赛道/题材>_<日期>.md`。

生成文件后，使用 `present_files` 工具展示给用户。

## 模式二：爽文开头生成

### Step 1B: 确认需求

| 要素 | 是否必填 | 说明 | 默认值 |
|------|----------|------|--------|
| 主角姓名 | 必填 | 开头中使用的主角名字 | 无 |
| 爽点方向/赛道 | 必填 | 8大赛道 或 6大爽点方向 | 无 |
| 故事背景 | 可选 | 时代、地点、场景等背景信息 | 根据赛道自动匹配 |

### Step 3D: 拆解爆款内容

#### Step 3D-1: 赛道识别

#### Step 3D-2: 爽点结构提取

从输入内容中提取：

- 开场方式（对话/场景/独白/倒叙）

#### Step 3D-5: 差异化标记

- 需差异化部分
- 避免照搬点（版权红线）

### Step 4D: 生成同风格新内容

2. **保留节奏感** — 新内容的爽点密度、压抑释放比、钩子位置与原作一致
3. **同赛道同风格** — 使用同一赛道的专属爽点模板
4. **差异化创新** — 至少加入1个原作没有的创新点
5. **版权红线** — 不得使用原作的人物姓名、地名、招式名、特殊术语

- 检查新内容与原作的结构相似度是否达标但无版权问题
- 检查新内容的爽点是否与原作同等密度

## 增值能力详解（④⑤⑥ 纯前端独立工具实现，⑦ 所有模式自动执行）

> 注：④生成历史存档、⑤自定义模板保存、⑥爽点节奏检查、⑦章节续写均在独立 HTML 工具 `novel-generator.html` 中实现（localStorage + 前端启发式分析），无需 AI。⑦节奏检查在工具每次生成时自动附加报告。

### ④ 生成历史存档
- 每次生成（任意模式）自动写入 localStorage 键 `ng_history_v1`，最多保留 50 条（新记录置顶）。
- 记录字段：id、时间、模式名、标题、完整 Markdown 正文、合规报告 HTML、节奏报告 HTML、预览摘要。
- 用户进入「📚 历史·模板」标签页 → 「📜 生成历史」即可查看列表；每条支持：
  - **👁 查看/复用**：在结果区重新渲染该记录（含敏感词标红、合规报告、节奏报告）
  - **📋 复制**：复制纯文本正文到剪贴板
  - **🗑 删除**：从存档移除
- 适用场景：写手试了多个方向后，快速找回之前满意的灵感，不用重新生成。

### ⑤ 自定义模板保存
- 用户在任一模式选好赛道/方向/数量/字数/热门元素/补充要求后，进入「📚 历史·模板」→「💾 我的模板」，输入模板名点「保存当前参数为模板」，即存入 localStorage 键 `ng_templates_v1`。
- 模板保存完整参数组合（含赛道、子方向、数量、字数、热门元素勾选、补充文本、引流/续写开关等）。
- 下次进入「我的模板」点「✅ 套用」，自动切到对应模式、回填所有选择并激活生成按钮，一步到位。
- 示例模板名：「末世女主空间搞笑」「赘婿打脸引流」「签到无敌黄金三章」。

### ⑥ 爽点节奏检查（新手友好评分）
每次生成后自动对生成正文运行启发式分析，输出 100 分制报告（紫框），检查 4 项：
1. **开头300字内出现冲突/张力** — 前 300 字命中冲突词库（打脸/碾压/羞辱/危机等）则通过，否则扣 25 分并给建议。
2. **段落/章节结尾有钩子** — 末段命中钩子词库（？/悬念/然而/突然/更大的危机等）则通过，否则扣 20 分并给建议。
3. **爽点密度达标（≥2.5个/千字）** — 统计爽感词（打脸/震惊/逆袭/秒杀/封神等）出现频次，不足则扣 15 分并给建议。
4. **内容体量充足** — 正文 ≥300 字通过，否则扣 10 分。
- 评级：≥80 节奏达标可直接开写；60–79 局部可优化；<60 需重点调整。每项未达标都给出对应的新手修改建议。
- 标准阈值（300字/钩子/2.5密度）可按平台投稿要求调整，属可配置项。

### ⑧ 多平台风格适配（全局）
- 工具顶部「🎨 目标平台风格」选择器（通用/番茄/起点/晋江/七猫/知乎），全局生效。
- 用户选定平台后，模式一到五生成结果末尾自动附加「🎨 平台风格适配卡」，内容来自 `references/platform_style_submission.md` 的平台风格画像：
  - 节奏偏好（如番茄短章节高频钩子、起点中速重设定、晋江情感慢热）
  - 内容侧重（爽点直给 / 世界观严谨 / 感情线驱动 / 直给爽文）
  - 文风语气（网感直白 / 精致质感 / 情绪流细腻）
  - 避坑要点（如避免大段环境描写拖慢节奏、先审后发分级严格）
  - 配套节奏建议（每章字数区间、钩子间隔）
- 选择「通用」时不附加适配卡（保持原有均衡输出）。
- AI 对话模式中，若用户指定目标平台，应在生成时按对应画像调整节奏、侧重与语气。

### ⑨ 新书配套（模式六 · 一站式前期准备）
用户在「📦 新书配套」模式填写书名（可选，不填自动生成）、主角名（可选）、题材赛道（必选）、核心卖点（可选），点生成即产出三部分：
1. **📝 小说简介（三版）** — 短简介(~150字，投放入口/信息流)、中简介(~300字，作品页)、长简介(~500字，详情页)，语气按所选目标平台调整（番茄爆点直给、起点世界观、晋江情感钩子、七猫爽点直给、知乎回答体强反转钩子）。
2. **🖼 小说封面** — 按赛道生成配色 CSS 预览（书名+主角+赛道标签），同时产出可直接交给 AI 图像生成的提示词（含题材/书名/视觉风格/色调/无文字水印约束），并提供「复制提示词」按钮。真实 AI 封面由对话 skill 调用图像生成完成（提示词已预备好）。
3. **📮 投稿渠道推荐** — 基于题材+目标平台，对番茄/起点/晋江/七猫/飞卢/知乎六平台按匹配度排序，输出付费模式、核心受众、投稿要求、官方渠道表格，附变现提示与防诈骗声明（不提供任何具体私人联系方式）。
- 适用场景：写手生成完正文后，一站式搞定书名、简介、封面、投稿渠道，直接进入新书发布流程。
