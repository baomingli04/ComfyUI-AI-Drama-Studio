## 一、黄文关键字组合

每个场景开始前，先确定4个关键字：**地点、姿势、play、情绪氛围**。

| 关键字 | 作用 | 示例 |
|--------|------|------|
| 地点 | 决定场景细节和氛围 | 办公室、浴室、电梯、厨房 |
| 姿势 | 决定动作描写方向 | 后入、骑乘、壁穴、站立 |
| play | 决定核心动作 | 口交、颜射、绳缚、潮吹 |
| 情绪氛围 | 决定整体基调 | 羞耻、沉沦、温柔、激烈 |

**写作要求**：
- 一个场景至少锁定3-4个关键字，写之前先在脑子里过一遍
- 四个关键字不能互相矛盾：「温柔氛围」配「鞭打play」需要额外铺垫，否则读者出戏
- 关键字组合决定场景的「独特性」：同样的「办公室+后入」，加「羞耻」和加「沉沦」是完全不同的两篇
- 写之前问自己：这个场景和上一篇有什么不同？如果四个关键字都一样，场景就重复了

## 二、情绪节奏

黄文的情绪转折**由攻受双方的交流驱动**，不是由动作驱动。

**核心原则**：
- 对话配合play变动：play升级时对话变短/变急，play放缓时对话变长/变软
- 情绪转折必须有「触发事件」：一次拷问、一次催眠、一次插入、一次被看到
- 不能线性推进，要有「反复」：沉沦后突然清醒，清醒后又再次沉沦

**节奏四段**：
```
anticipation（期待/铺垫）→ escalation（升级）→ peak（高潮）→ resolution（释放/余韵）
```

| 阶段 | 写法 | 时长 |
|------|------|------|
| 期待 | 心跳加速、呼吸变粗、身体僵硬、环境细节放大 | 2-4段 |
| 升级 | 动作加快、对话变短、感官刺激叠加 | 3-5段 |
| 高潮 | 尖叫、颤抖、瘫软、失神、潮吹、释放 | 1-2段（短而烈） |
| 余韵 | 她看着自己身上的痕迹、她听到他的声音、时间感 | 1-2段 |

**写作要求**：
- 不能一直紧张，读者会累。每3-5段紧张后，要有1段「喘息」
- 高潮前要有「铺垫」，高潮时要有「释放」，高潮后要有「余韵」
- 情绪转折由「对话」或「一个动作」触发，不能凭空转变

## 三、丰富性与关键词查重

**核心问题**：写多了之后，同样的姿势、同样的地点、同样的play反复出现，读者会腻。

**查重方法**：
- 每写完一个场景，记录用了哪些「地点+姿势+play」组合
- 新场景开始前，对照记录，避免完全相同的组合
- 允许「同一地点换play」或「同一play换地点」，但不允许三个都重复

**丰富性来源**：
- 地点变换：从室内到室外、从私密到公共、从熟悉到陌生
- 姿势变换：从被动到主动、从常规到非常规
- play变换：从轻度到重度、从单一到组合
- 情绪变换：从抗拒到沉沦、从羞耻到期待

**写作要求**：
- 每篇（或每章）至少变换2个关键字
- 变换要有「递进」：不能跳太猛，要有过渡
- 在「变化」中保留「不变」：比如地点变了，但她的某个小动作（咬嘴唇、闭眼）保留，读者有连贯感

## 四、头脑风暴：从地点发散

不知道写什么场景时，从「地点」开始发散：

| 地点 | 可发散的姿势/play |
|------|-------------------|
| 桌椅 | 办公桌、餐桌、书桌、椅子靠背、桌下、桌边 |
| 厨房 | 料理台、冰箱旁、水槽边、地上（打碎东西后） |
| 学校 | 教室、天台、保健室、走廊、器材室、社团活动 |
| 地上/墙上 | 壁穴、跪地、靠墙、地板、地毯 |
| 交通工具 | 电梯、地铁、出租车后座、停车场、后备箱 |
| 浴室 | 淋浴、浴缸、洗手台、瓷砖墙 |
| 卧室 | 床、地板、窗边、衣柜、镜子前 |
| 办公室 | 办公桌、会议室、隔间、沙发、落地窗前 |
| 公共场合 | 公园长椅、便利店、厕所隔间、更衣室、温泉 |

**发散方法**：
1. 选一个地点
2. 问自己：这个地方有什么「限制」？（空间小、有人经过、有声音、有温度）
3. 限制就是「看点」：空间小→壁穴/桌子；有人经过→遮掩/屏息；有声音→不能出声
4. 限制决定姿势和play的选择

**写作要求**：
- 地点的「限制」要写出来，不能只写「在电梯里」，要写「电梯里还有三个人，她必须把腿夹紧」
- 地点的「细节」要参与事件：电脑屏幕弹出消息、窗外突然下雨、电梯到达楼层的提示音

## 五、画面感

黄文要「看得见」，不能只写「她爽了」。

**三个参考标准**：
- **动作参考动作片**：每个动作要有「起始→过程→结束」，不能跳。比如「他进入」要有：他俯身→她分开腿→他顶入→她咬住嘴唇
- **色香味参考恐怖片**：精液的颜色、潮吹的水花、汗珠的滚动、绳子的摩擦痕迹——这些视觉细节越「具体」越有冲击力
- **动作连贯性**：上一句的动作结束位置，就是下一句的起始位置。不能「她躺在床上」突然变「她站在窗前」

**写作要求**：
- 每个动作至少2个细节（身体部位+力度/速度/方向）
- 视觉细节要「具体」：不能只写「精液流下来」，要写「精液顺着大腿内侧滑到膝盖，在地板上积了一小滩」
- 动作连贯：用「然后」「接着」「与此同时」衔接，不要跳切

## 六、现实细节

黄文不是漫画，身体是「真的」。加入现实细节能大幅提升「沉浸感」。

| 现实细节 | 写法 |
|----------|------|
| 体毛 | 她腿上的细毛被汗水黏住、他胸口的硬毛蹭过她的皮肤 |
| 体重 | 他压在她身上的重量、她跪在地上膝盖的疼痛、他抱起她时手臂的酸 |
| 平衡 | 她站立时重心不稳、他进入时她往后仰、她骑乘时脚在发抖 |
| 体味 | 汗味、香水味、精液味、她身上的沐浴露味、他身上的烟味 |
| 不应期 | 他射完后的疲惫、她高潮后的敏感、他还没恢复她已经在求他再来 |
| 温度 | 他的体温、精液的温热、空调的冷、浴室的蒸汽热 |
| 声音 | 她咬住嘴唇没压住的声音、床板的吱呀声、水声、她的喘息声 |
| 时间 | 她发现已经过了一个小时、他看了一眼手表、窗外的天从亮变暗 |

**写作要求**：
- 每段至少1个现实细节，高潮段2-3个
- 现实细节要「融入动作」，不能罗列：「她感到他的重量压下来，腰上的旧伤隐隐作痛」
- 不应期和体重最容易被忽略，但最能制造「真实感」

## 七、心理弧线

所有类型的黄文都有一条心理弧线，**这是写好的关键**：

```
抗拒 → 挣扎 → 妥协 → 沉沦 → 主动
```

| 阶段 | 写法 | 读者感受 |
|------|------|----------|
| 抗拒 | 她拼命反抗，尖叫、哭泣、颤抖 | 建立「她不是天生骚」的认知 |
| 挣扎 | 她开始妥协，但内心还在抵抗 | 最揪心 |
| 妥协 | 她接受现状，但还在羞耻 | 开始「代入」 |
| 沉沦 | 她在痛苦/羞耻中找到快感 | 「爽」 |
| 主动 | 她开始主动迎合，甚至期待 | 「回味」 |

**写作要求**：
- 每个阶段至少1-2段，不能跳
- 阶段之间要有「触发事件」：一次拷问、一次催眠、一次插入、一次被看到
- 不能线性推进，要有「反复」：沉沦后突然清醒，清醒后又再次沉沦

## 八、反差

反差是黄文的「爽点」来源：

| 反差类型 | 示例 | 写作要点 |
|----------|------|----------|
| 身份反差 | 女社长被肛交、女教师被调教、护士被使用 | 先写她「高冷/正经」的一面，再写「沉沦」的一面 |
| 头身分离 | 嘴上说不要身体却很诚实 | 写「内心独白」和「身体反应」的矛盾 |
| 前后反差 | 催眠前高冷，催眠后顺从 | 写「洗脑前」的细节，再写「洗脑后」的变化 |
| 场景反差 | 在办公室/医院/学校被使用 | 写「正常场景」的细节，再写「异常事件」的插入 |
| 关系反差 | 被最亲近的人（丈夫/上司/老师）使用 | 写「平时关系」的细节，再写「现在」的对比 |

**写作要求**：
- 反差要「具体」：不能只写「她平时高冷」，要写「她平时开会时眼神像刀」
- 反差要「累积」：每加一层反差，爽点就加一层
- 反差要「回收」：在结尾或高潮时把之前埋的反差全部引爆

## 九、节奏与感官

### 9.1 节奏

黄文的节奏是「张弛有度」：

```
紧张（拷问/羞辱）→ 放松（喘息/温存）→ 更紧张（升级）→ 高潮（释放）
```

**写作要求**：
- 不能一直紧张，读者会累。每3-5段紧张后，要有1段「喘息」
- 高潮前要有「铺垫」：心跳加速、呼吸变粗、身体僵硬
- 高潮时要有「释放」：尖叫、颤抖、瘫软、失神
- 高潮后要有「余韵」：她看着自己身上的痕迹、她听到他的声音

### 9.2 感官

黄文要「五感俱全」，不能只写视觉：

| 感官 | 写作示例 |
|------|----------|
| 视觉 | 她身上的绳子、他脸上的表情、精液的颜色、潮吹的水花 |
| 听觉 | 她的尖叫、他的喘息、鞭子的声音、绳子的摩擦声、水声 |
| 触觉 | 鞭子抽在身上的灼热、绳子的勒紧、手掌的粗糙、精液的温热 |
| 嗅觉 | 汗味、香水味、精液味、血腥味、花香 |
| 味觉 | 她尝到的血腥味、精液的味道、她咬破嘴唇的铁锈味 |

**写作要求**：
- 每段至少2种感官，高潮段3-5种
- 不能罗列，要「融入动作」：「她闻到汗味，那是他的味道，也是她的味道」
- 嗅觉和味觉最容易被忽略，但最能制造「沉浸感」

### 9.3 词汇轮换

写多了之后，同样的词反复出现，读者会腻。每个部位/动作准备3-4个替代词：

| 部位/动作 | 轮换词 |
|-----------|--------|
| 胸 | 胸、胸口、双峰、乳、胸脯 |
| 腰 | 腰、腰肢、柳腰、腰线、腰窝 |
| 腿 | 腿、双腿、大腿、小腿、腿根 |
| 插入 | 进入、顶入、插入、挺进、贯穿 |
| 高潮 | 高潮、到达巅峰、释放、痉挛、失神 |
| 喘息 | 喘息、呼吸、呻吟、呜咽、抽气 |

**写作要求**：
- 同一个词在一篇内最多出现3次，超过就换
- 轮换词不能太文绉绉，要和整体风格匹配
- 在「重复」中用「变化」：同样的动作，用不同的词和角度写

## 十、调教类写作技法

### 10.1 调教的「耐心」

调教者要有「耐心 + 掌控感」，不能「急」，要「慢」。慢到读者都急了他还在「准备」。要「观察」她的反应，根据反应调整手段；要「说话」，用语言引导她认识自己的感觉；要「稳定」，不忽冷忽热，让她「有规律地」被使用。

```
他没有急着动手，
而是先给她戴上眼罩。
「闭上眼睛，」他的声音很轻，
「感受你的身体。」
她屏住呼吸，
心跳声在黑暗里被放大。
他等她的心跳慢慢平复，
才抬起第一根手指，
沿着她的锁骨，
慢慢地，慢慢地，往下。
「告诉我，」他说，
「这里，是什么感觉？」
她张了张嘴，
却发不出声音。
```

### 10.2 手段的「具体」

手段要「具体」，不能只写「他打了她」或「他亲了她」。每个手段至少2-3种感官，手段之间要有「递进」（从轻到重，从外到内），要有「节奏」（快慢交替）。

| 手段类型 | 具体描写 |
|----------|----------|
| 鞭打 | 皮鞭抽在臀上的声音、皮肤的灼热、留下的红痕、渗出的血丝 |
| 踩踏 | 脚底踩在胸口的重量、呼吸的困难、脚掌的粗糙、脚趾的抠压 |
| 电击 | 电流窜过全身的酥麻、肌肉的痉挛、牙齿的打颤、失控的尖叫 |
| 蜡烛 | 蜡油滴在皮肤上的灼热、凝固后的刺痛、滴落的节奏、她屏住呼吸 |
| 口塞 | 嘴被塞住的声音、唾液从嘴角流出、舌头的顶撞、求饶的口型 |
| 颈链 | 链条勒在脖子上的重量、呼吸的受限、金属的冰凉、他拉紧的力度 |
| 鼻钩 | 钩子穿过鼻翼的疼痛、被吊起的失重感、每次呼吸的拉扯、眼泪 |
| 亲吻 | 他嘴唇的温度、他舌尖的力度、她咬住他嘴唇的反应、她喉咙里的声音 |
| 手指 | 他手指的粗细、他插入时的节奏、她夹紧的力度、她听到的水声 |
| 插入 | 他进入时的重量、她身体的反应、她咬住枕头/肩膀/嘴唇、她发出的声音 |
| **享乐沉沦** | 通过高潮让她认识快感，在「爽」中放下防备。抗拒→好奇→沉溺→依赖→主动 |
| **羞辱打开心扉** | 通过羞耻让她放下「完美人设」。羞耻→崩溃→被接纳→卸下心防→主动 |
| **习惯化身性奴** | 通过重复让她「习惯」被使用。抗拒→麻木→习惯→期待→主动 |

### 10.3 绳缚的「艺术」（可选）

绳缚是「艺术」，不是随便绑。要写「绳子的走向、松紧、呼吸」。

**写作要点**：
- 绳子要「有走向」：从脚踝到小腿、从手腕到手臂、从肩膀到腰部
- 绳子要「有松紧」：松的时候她能动，紧的时候她连呼吸都困难
- 绳子要「有呼吸」：她呼吸时绳子会动，绳子动时她会疼
- 经典造型：「人降落伞」（四肢被绳子吊起，身体悬空）

**示例**：
```
绳子从她的脚踝开始，
沿着小腿内侧，绕过膝盖，
再沿着大腿外侧，一直绕到腰部。
每一圈都恰到好处地松紧——
松到她能感觉到自己的心跳，
紧到她连呼吸都要刻意控制。
他把她吊起来的时候，她悬在空中，
像一张被画满线条的画，
连挣扎都变成了一种舞蹈。
```

### 10.4 身份差调教（可选）

调教者通常是「上司 / 丈夫 / 老师」，利用身份差。

**写作要点**：
- 先写「平时」的身份关系：她叫他「老师」、他叫她「小X」
- 再写「现在」的身份反转：她跪在地上、他站在她面前
- 身份差越「日常」，反转越「爽」

## 十一、羞辱类写作技法

### 11.1 羞耻的「具体」

羞辱的核心是「让她在羞耻中沉沦」。羞耻要「具体」：

| 羞耻手段 | 具体描写 |
|----------|----------|
| 骂倒 | 他骂她的声音、她听到骂声时的脸红、她想反驳却发不出声 |
| 跪求 | 她跪在地上的声音、膝盖的疼痛、她抬头时的眼神 |
| 土下座 | 她额头触地的声音、她抬头时的眼泪、他扶她起来时的力道 |
| 服侍 | 她为他倒水、为他脱鞋、他享受的表情、她看到自己服侍时的羞耻 |
| 口交 | 她含住时的吞咽、他掐住她头发的力道、她听到自己发出的声音 |
| 颜射 | 精液喷在她脸上的声音、温度、她闭眼还是睁眼、她舔掉还是留下 |
| 精液涂抹 | 他用手把精液抹在她身上的动作、她摸到时的触感、她看到镜子里的自己 |

**写作要求**：
- 每个羞耻手段至少2-3种感官
- 羞耻要有「累积」：从轻度到重度，从她一个人看到有别人看到
- 羞耻要有「释放」：在高潮时把之前的羞耻全部释放

### 11.2 身份反差的「累积」

身份反差是羞辱类的核心：女社长、女教师、护士、女仆、人妻。

**写作要点**：
- 先写她「平时」的身份细节：她开会时的眼神、她批改作业时的专注、她打针时的专业
- 再写「现在」的反转：她跪在地上、她穿着女仆装、她被人使用
- 每加一层身份细节，反差就加一层
- 在结尾或高潮时，把之前埋的身份细节全部引爆

**示例**：
```
她平时开会时，眼神像刀，没人敢在她面前说错话。
现在，她跪在地上，眼神里全是水。
他想起她上周在会议上，
把一个新人的方案批得体无完肤，
现在，那个新人正站在她面前，
看着她被使用。
她听到新人的脚步声，
比听到任何声音都羞耻。
```

### 11.3 「嫌弃 + 调教」的高级羞辱

不是喜欢她，是「在厌恶中调教她」。

**写作要点**：
- 调教者要「嫌弃」：皱眉、撇嘴、叹气、说「你怎么这么脏」
- 但调教者要「使用」：嫌弃归嫌弃，手没停
- 她要「矛盾」：既羞耻于被嫌弃，又沉沦于被使用
- 这种矛盾比「纯爱」更「爽」

## 十二、催眠类写作技法

### 12.1 洗脑的「过程」

催眠的核心是「洗脑」，不是「催眠」。洗脑要有「过程」：

```
接触 → 暗示 → 重复 → 固化 → 触发
```

| 阶段 | 写法 |
|------|------|
| 接触 | 她第一次接触催眠手段（光线、声音、药物） |
| 暗示 | 催眠者给她「暗示」，她半信半疑 |
| 重复 | 暗示被重复，她开始接受 |
| 固化 | 暗示变成「本能」，她不需要思考就会反应 |
| 触发 | 一个特定的词/动作/场景就能触发她的「洗脑状态」 |

**写作要求**：
- 每个阶段至少1段，不能跳
- 「重复」阶段要有「递进」：从一次到两次，从半信半疑到完全接受
- 「触发」要在结尾或高潮时使用，引爆之前的铺垫

### 12.2 头身分离（最高级）

身体沉沦但头部清醒，嘴上说不要身体却很诚实。

**写作要点**：
- 写「内心独白」：她在想什么、她在抵抗什么
- 写「身体反应」：她的身体在做什么、她的身体在「背叛」她
- 用「一边...一边...」句式：「她一边喊着不要，一边夹得更紧」

**示例**：
```
她的头还在清醒，
她知道自己在做什么，
她知道他正在做什么，
她知道这「不对」。
但她的身体不听她的了。
她的腰在迎合，
她的腿在夹紧，
她的嘴在发出声音——
那是她平时绝不会发出的声音。
「不要...」她听到自己在说，
但她的身体，
比她的嘴诚实得多。
```

### 12.3 催眠前后反差

催眠前是强势女上司，催眠后是顺从性奴。

**写作要点**：
- 写「催眠前」的细节：她的眼神、她的语气、她的动作
- 写「催眠中」的过渡：她的眼神变软、她的声音变轻、她的动作变慢
- 写「催眠后」的反差：她主动靠近、她主动迎合、她主动求他

### 12.4 半清醒 + 半沉沦

插入时解除催眠的设定。

**写作要点**：
- 她在催眠中沉沦，但插入的瞬间会清醒
- 清醒后发现自己被插入，又羞耻又沉沦
- 这种「反复」比「一直沉沦」更「爽」

## 十三、放置类写作技法

### 13.1 时间感

放置类的核心是「时间感」：不是一次，是「持续一段时间」。

**写作要点**：
- 用「时间标记」：第一天、第三天、第一周、第一个月
- 写「变化」：她的反应从剧烈到平静、从抗拒到习惯
- 写「日常」：她被使用的「日常」
- 写「对比」：她「以前」的生活和「现在」的生活

**示例**：
```
第一天，她尖叫，她哭泣，她挣扎。
第三天，她还在抗拒，但声音小了很多。
第一周，她已经不挣扎了，
只是闭着眼，任由他摆布。
第一个月，
她开始期待他的脚步声。
```

### 13.2 「丈夫/家人在附近」

增加羞耻感的经典设定。

**写作要点**：
- 写「距离」：他就在隔壁、他就在楼下、他就在门外
- 写「声音」：她听到他的声音、他听到她的声音
- 写「假装」：她假装没发生、他假装不知道
- 写「发现」：她发现他知道了、他发现她变了

### 13.3 逐渐沉沦

从抗拒 → 麻木 → 习惯 → 期待。

**写作要点**：
- 每个阶段至少1段
- 每个阶段要有「触发事件」
- 「期待」阶段最「爽」：她开始主动迎合，甚至主动求他

## 十四、通用写作技巧

### 14.1 句式技巧

| 技巧 | 示例 | 效果 |
|------|------|------|
| 短句制造紧张 | 「她喊。他停。她更喊。」 | 节奏快，紧张感强 |
| 长句制造沉浸 | 「她听到自己的声音在空旷的房间里回荡，那声音陌生得像是另一个人的，又熟悉得让她想哭。」 | 沉浸感强 |
| 「一边...一边...」 | 「她一边喊着不要，一边夹得更紧。」 | 制造矛盾 |
| 倒装 | 「不是她想要，是她的身体，先于她的意识，做出了反应。」 | 强调「失控」 |
| 重复 | 「她逃。她逃。她逃。但门，已经锁了。」 | 制造绝望感 |
| 留白 | 「她没有说话。他只是看着。然后，他笑了。」 | 制造悬念 |

### 14.2 对话技巧

- **少说多听**：黄文里「听」比「说」重要。写她「听到」什么，比写她「说」什么更重要
- **短句对话**：黄文里的对话要「短」。长对话会打断节奏
- **对话 + 动作**：对话要「夹在动作里」，不能单独一段
- **内心独白**：用「内心独白」写她的「真实想法」，和「嘴上说的」形成对比

### 14.3 场景技巧

- **场景要「具体」**：不能只写「在房间里」，要写「在堆满文件的办公室里」
- **场景要「有细节」**：电脑、病历、学生、电脑屏幕、窗外的雨
- **场景要「参与」**：场景要「参与」事件，比如电脑屏幕突然弹出消息、窗外突然下雨

### 14.4 高潮技巧

- **高潮前铺垫**：心跳加速、呼吸变粗、身体僵硬、她开始出汗
- **高潮时释放**：尖叫、颤抖、瘫软、失神、潮吹
- **高潮后余韵**：她看着自己身上的痕迹、她听到他的声音、她发现时间已经过去很久
- **高潮后反差**：她恢复「平时」的样子，但读者知道「她变了」

### 14.5 结尾技巧

| 结尾类型 | 示例 | 效果 |
|----------|------|------|
| 开放式 | 她被困住，不知道什么时候结束 | 让读者「回味」 |
| 反转 | 她发现自己已经离不开 | 让读者「震惊」 |
| 悲剧 | 她被释放，但已经回不去了 | 让读者「心痛」 |
| 主动 | 她主动求他再来 | 让读者「爽」 |
| 日常 | 她恢复「平时」的样子，但读者知道「她变了」 | 让读者「细思极恐」 |

### 14.6 插入式play分类

按「侵入方式」分类，写的时候根据场景选择：

| 类型 | 包含 | 写法要点 |
|------|------|----------|
| 扩张类 | 手指→道具→阳具的递进 | 写「从紧到松」的过程，她的适应 |
| 抽插震动类 | 阳具、跳蛋、按摩棒 | 写「节奏变化」，快慢交替 |
| 开发新洞 | 肛交、二穴同入 | 写「疼痛→适应→快感」的转折 |
| 非侵入类 | 足交、乳交、按摩 | 写「外部刺激」的累积 |

## 十五、语言风格选择

不同风格的黄文，语言处理方式完全不同。写之前先定风格：

| 风格 | 特点 | 适用场景 | 示例 |
|------|------|----------|------|
| 古早小白派 | 直白、不修饰、动作为主 | 快节奏、纯爽文 | 「他进去了。她叫了。」 |
| 古典龙阳派 | 文雅、含蓄、意境为主 | 古风、慢热 | 「他俯身，如兰似蕙。」 |
| 日耽派 | 细腻、心理为主、对话多 | 日系、情感向 | 大量内心独白和对话 |
| 直男派 | 粗俗、直接、不装 | 男频、粗犷风 | 用词直接，不绕弯 |
| 耽美含蓄派 | 隐晦、暗示、留白多 | 耽美、文艺向 | 「他吻了她的喉结。」 |
| 海棠市井派 | 接地气、生活化、有烟火气 | 日常系、人妻系 | 用日常口语，有生活细节 |
| 海棠脔仙派 | 极致、详细、不回避 | 重口、详细向 | 所有细节都写，不跳过 |

**写作要求**：
- 整篇风格要统一，不能一篇里混用三种风格
- 风格决定「词汇选择」：直男派用「进去」，耽美含蓄派用「进入」，古典龙阳派用「俯身」
- 风格决定「节奏」：直男派节奏快，耽美含蓄派节奏慢
- 写之前先定风格，写的时候不跳风格

## 十六、写作检查清单

写完一段后，用这个清单检查：

- [ ] 四个关键字（地点/姿势/play/情绪）是否锁定且不重复？
- [ ] 心理弧线是否完整？（抗拒→挣扎→妥协→沉沦→主动）
- [ ] 反差是否具体？（不能只写「她平时高冷」）
- [ ] 节奏是否张弛有度？（不能一直紧张）
- [ ] 感官是否五感俱全？（不能只写视觉）
- [ ] 手段是否具体？（不能只写「他打了她」）
- [ ] 对话是否短句 + 动作？（不能长对话）
- [ ] 高潮是否有铺垫 + 释放 + 余韵？
- [ ] 词汇是否有轮换？（同一个词不超过3次）
- [ ] 现实细节是否到位？（体毛/体重/平衡/体味/不应期）
- [ ] 动作是否连贯？（上一句结束位置=下一句起始位置）
- [ ] 场景是否参与事件？（不能只是背景）
- [ ] 结尾是否有力？（不能草草收尾）
- [ ] 语言风格是否统一？（不能一篇混三种风格）
