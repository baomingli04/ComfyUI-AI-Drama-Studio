## 一、项目介绍

「视频提示词工作室」是一个把**小说 / 故事文本**转化为本地 ComfyUI 可用提示词的**结构化工作流技能**。

- **主线能力**：覆盖从世界观锚定、角色与参考图匹配、分镜与导演设计，到图片提示词生成、视频提示词生成的完整链路，最终驱动本地工作流出图、生视频。
- **独立工具能力**：内置若干可单独调用的工具功能（见「三、功能总览 · 独立功能」）。
- **设计定位**：本技能是「提示词结构工作室」——用清晰的层级与分明的职责，**减少漏读误读**。主文件只做导航地图，所有具体规则与写法拆到 `参考文档/` 由使用者自行填充。

## 二、使用需求

### 2.1 必须提供的三个目录（缺一项禁止开工）

调用本技能后，第一件事不是写提示词，而是先向用户要齐以下三个目录——**三者都给齐才开工，缺一项禁止动手**：

1. **工作目录（配置 + 产物根）**：所有配置文件与产出落此目录，脚本相对它读写。
2. **角色目录**：角色参考图所在，作为只读素材源。
3. **背景目录**：背景图所在，作为只读素材源。

- 没给齐必须先问，禁止凭空假设路径。
- 给齐后先初始化项目骨架（生成配置模板并把三目录登记进配置），再进入后续阶段。

## 三、功能总览

本技能按「功能」组织，每个功能独立、职责分明。以下功能按编号排列——先写功能 1，其余待补充。

### 功能 1：初始化工作目录

**做什么**：用户指定工作目录后，运行初始化脚本，生成第一个配置文件（及配套骨架文件），把目录关系与核心工作文件登记进去，作为整个项目的总入口。

**读哪个文档**：`参考文档/初始化文档.md`（初始化脚本怎么调、创建哪些文件、各字段含义、注意事项）

**第一个配置文件**：`工作配置.yaml`（位于工作目录），包含以下字段：
- 角色资源所在目录
- 背景资源所在目录
- 图片输出目录（默认置于工作目录下，可改）
- 视频输出目录（默认置于工作目录下，可改）
- 角色背景一览表（指向 `角色背景一览表.md`，所有的角色资源和现有的情节小说的人物对应的资源表）
- 剧情生成文件（指向 `剧情生成.md`，内含完整剧情）
- 提示词生成文件（指向 `提示词生成.md`，内含按剧情切割的每一段提示词；**本文件是主要工作文件**）
- 世界书（指向 `世界书.md`，功能 3 产出的世界观锚点，统一后续出图 / 出视频的背景基调）

**初始化脚本**：见 `py脚本/`（功能 1 专用）
- 传参三个目录：
  - 工作目录（**必传**）
  - 角色资源目录（可选）
  - 背景资源目录（可选）
- 脚本在工作目录生成 `工作配置.yaml` 及上述骨架文件。

**产出**：`工作配置.yaml` + `角色背景一览表.md` / `剧情生成.md` / `提示词生成.md` / `世界书.md` 的骨架。

> 初始状态说明：初始化后 `角色背景一览表.md` 仍为空，用户尚未提供 `剧情生成.md` 内容，`提示词生成.md` 也为空——三者由后续功能逐步填充。

### 功能 2：角色 / 背景文件夹图片重命名

**做什么**：对角色目录、背景目录里的图片文件，调用图片识别接口识别内容后自动重命名；**已按规范重命名的文件直接跳过**，不重复处理。

**输入**：读取 `工作配置.yaml` 中的「角色资源所在目录」「背景资源所在目录」。

**识别接口**：图片识别 / 反推端点 `http://192.168.31.131:8488`（llama.cpp 视觉）。接口繁忙或连续失败时改用 ComfyUI 的图片反推工作流。

**重命名脚本**：见 `py脚本/`（功能 2 专用）
- 支持多目录：用户直接 `--dir` 指定，或从 `工作配置.yaml` 读取「角色资源所在目录」「背景资源所在目录」。
- 对每个未重命名文件：调用识别接口 → 按规范生成新文件名 → 原地改名。
- 识别接口连续失败 → 自动改用 ComfyUI 图片反推工作流改名。
- 已按规范命名的文件：跳过。
- 改完（或已改过的）每张图：检查项目目录 `角色背景一览表.md` 是否已有该条目，没有就追加、有就跳过。

**重命名规范**：详见 `参考文档/图片重命名规范.md`（识别接口用法、角色 8 字段命名、背景场景命名、跳过判定、重名处理、禁止项、第七节运行指引）。本功能只按该规范执行，规则不在此展开。

**产出**：原地重命名后的图片文件（目录不变）；角色图另生成 `{原名}_反推.txt` 存档，所有的角色和背景都写到 `角色背景一览表.md` 。

### 功能 3：情节需求或者小说需求 → 导演剧本情节（需求/小说转剧本）

**做什么**：用户给出「情节需求」（一段梗概 / 想要的效果描述），按 `参考文档/需求转情节.md` 的规范，把它转写成**可拍摄的小说情节**——写成「导演的剧本」，不写比喻、不写心态；**同时按该文档的第八节生成《世界书》（世界观锚点）**，统一后续出图 / 出视频的背景基调。

**输入**：用户的情节需求文本（来自对话，或工作目录里的需求文件）。

**读哪个文档**：`参考文档/需求转情节.md`（定义格式红线：禁止比喻、禁止心态、只写导演剧本；含格式模板与示范样例；**第八节「世界书生成」定义世界观锚点的生成规则与格式**，功能 3 须一并产出）。

**产出**：小说情节文本——建议写入 `剧情生成.md`，将小说中的人物都枚举到 `角色背景一览表.md` 并且**按性别匹配**一个角色的对应文件夹（详见 `调用规范.md` §三「按性别匹配，替代随机」；即 `工作配置.yaml` 中「剧情生成文件」指向的完整剧情）；**同时产出 `世界书.md`（世界观锚点，统一后续背景基调）**，作为后续分镜 / 提示词的总依据。

### 功能 4：剧本 → 分镜（剧本转分镜）

**做什么**：基于功能 3 产出的导演剧本，拆成多段**单段时长 ≤ 14 秒**的电影分镜。每段要明确决定：用什么角色、用什么工作流、是否生成首尾帧、用什么背景、生成时长、使用什么声音、图片正向 / 负向提示词、视频正向提示词。

**输入**：`剧情生成.md`（功能 3 产出的完整剧情 / 导演剧本）。

**读哪个文档**：`参考文档/分镜规则.md`（定义每段字段、工作流选择逻辑、首尾帧决策、背景锁定、提示词结构等）。

**产出**：分镜表——建议写入 `提示词生成.md`（即 `工作配置.yaml` 中「提示词生成文件」指向的、按剧情切割的每段提示词；**本文件是主要工作文件**）。

### 功能 5：分镜 → 图片（首尾帧 + 背景生成）

**做什么**：读取 `提示词生成.md` 的分镜，批量出图——对其中「`是否生成首帧图片 = 是`」的段落用图片工作流（Qwen）生成**首帧图**（尾帧可选，仅 `--frames both` 才额外出尾帧）；对「`是否生成背景图片 = 是`」且无现成背景的段用文生图（Z-Image）生成**背景图**。所有生成文件地址**自动回写**到 `提示词生成.md`（无需手填）。

**输入**：`提示词生成.md`（功能 4 产出的分镜表，含每段 `是否生成首帧图片` / `是否生成背景图片` 标记、图片正 / 负向提示词、背景、角色）。

**执行脚本**：见 `py脚本/`（功能 5 专用；支持 `--config` / `--dry-run` / `--only 段1,段2` 等参数，输出位置取自 `工作配置.yaml` 的「图片输出目录」）。参数与字段映射详见 `参考文档/首尾帧生成规则.md`。

**读哪个文档**：`参考文档/首尾帧生成规则.md`（定义读取哪两个判定字段、人物一致性硬规则、提示词铁律「图片N的角色 / 图片N的场景、不提人名、无阴影无阴暗、背景空旷无人」、回写字段映射）。

**产出**：各段的首帧图（尾帧可选，默认不出）/ 背景图（落图片输出目录），文件名含段落号 / 场景ID；并回写 `场景背景图` / `背景图片存放位置` / `生成图片首帧地址`（`生成图片尾帧地址` 仅 `--frames both` 时回写）。

### 功能 6：分镜 → 视频（批量生成）

**做什么**：读取 `提示词生成.md` 的分镜，对每段按分镜指定的工作流生成视频——有首帧的段用首帧驱动（尾帧可选，缺省复用首帧为尾帧）；无首帧的段按对应视频工作流直出。

**输入**：`提示词生成.md`（分镜表）+ 功能 5 产出的首帧图（尾帧可选）+ 角色 / 背景图。

**读哪个文档**：`参考文档/分镜转视频.md`（定义字段读取对照、工作流路由、首尾帧对接、Ref2VA 的 `--images` 顺序、时长、mp 铁律、回写字段映射）。

**执行脚本**：按路由调用 `py脚本/` 下对应的视频执行脚本——`视频-首尾帧` 与 `视频-多参考` 各一个。生成后把成片绝对路径回写到 `提示词生成.md` 的 `生成视频地址`。参数与回写细节见 `参考文档/分镜转视频.md`。

**产出**：各段视频（落视频输出目录），文件名含段落号。

### 功能 7：指定分镜 → 视频（用户指段 + 自定义 mp）

**做什么**：用户指定若干分镜片段，并按自定义 **mp（分辨率 / 百万像素）需求**生成这些片段的视频——只处理指定段、用用户定义的 mp 覆盖默认输出尺寸（其余逻辑同功能 6）。

**输入**：`提示词生成.md` 中用户指定的分镜段号列表 + 用户定义的 mp 需求；其余输入同功能 6。

**读哪个文档**：`参考文档/分镜转视频.md`（功能 6 与功能 7 共用同一文档；功能 7 在其基础上「仅处理指定段 + 按用户 mp 透传 `--megapixels`」，mp 取值一律以用户指令为准，详见该文档 §五 mp 铁律）。

**执行脚本**：同功能 6 的视频执行脚本，仅 `--megapixels` 传用户指定的值、`--only` 对应段。

**产出**：指定片段的视频（按用户 mp 输出），落视频输出目录。

### 4.2 输出 / 配置文件（运行期生成于「工作目录」）

这些文件不在技能目录里，而是脚本在用户指定的工作目录下创建，随每个小说项目独立存在。

#### 4.2.1 配置文件
| 文件 | 字段 / 内容 | 创建方 |
|---|---|---|
| `工作配置.yaml` | 角色资源所在目录 / 背景资源所在目录 / 图片输出目录 / 视频输出目录 / 角色背景一览表 / 剧情生成文件 / 提示词生成文件 / 世界书 | `初始化工作目录.py`（功能 1） |

#### 4.2.2 数据 / 资产登记文件
| 文件 | 作用 | 写入方 |
|---|---|---|
| `角色背景一览表.md` | 唯一资产登记处，含三章节：**现有资源角色清单**（功能 2 写）/ **背景清单**（功能 2 写）/ **剧情角色清单**（功能 3 写） | `重命名.py`、功能 3 |

#### 4.2.3 生成产物（落图片 / 视频输出目录）
| 文件（命名模式） | 含义 | 生成方 |

### 4.3 文件关联 / 调用链（数据流）

```
初始化工作目录.py
   └─> 工作配置.yaml + 角色背景一览表.md(空) / 剧情生成.md(空) / 提示词生成.md(空) / 世界书.md(空)

重命名.py ──读 角色/背景目录──> 角色背景一览表.md(现有资源角色清单/背景清单) + {原名}_反推.txt

功能3 需求转情节 ──> 剧情生成.md + 世界书.md
   生成剧情角色表.py ──读 剧情生成.md+一览表──> 角色背景一览表.md(剧情角色清单)

功能4 分镜规则 ──读 剧情生成.md+世界书.md──> 提示词生成.md

生成首尾帧与背景.py ──读 提示词生成.md+一览表+工作配置.yaml
   └─> <场景ID>_背景.png / <段N>_首帧.png（尾帧可选，默认不出）
   └─> 回写 提示词生成.md(场景背景图/背景图片存放位置/生成图片首帧地址/生成图片尾帧地址[可选])

FL2VA首尾帧视频.py / Ref2VA多参考视频.py ──读 提示词生成.md+参考图
   └─> 视频成片
   └─> 回写 提示词生成.md(生成视频地址)
```
