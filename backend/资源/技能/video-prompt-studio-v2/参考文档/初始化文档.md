# 初始化文档

> **何时读**：执行「功能 1：初始化工作目录」时读。
> **读它干什么**：知道初始化脚本怎么调、会在工作目录生成哪些文件。
> **不读会漏什么**：不知道三目录参数、不知道生成了哪些骨架文件，后续功能找不到路径。

---

## 脚本功能说明（`初始化工作目录.py`）

**功能**：一句话——把用户给的「工作目录」初始化成项目根，生成配置文件 + 三份空骨架 + 默认输出目录，作为整个项目的入口。

### 输入（命令行参数）

| 参数 | 必填 | 含义 |
|---|---|---|
| `--工作目录` | **必传** | 配置与产物根目录；所有产物落这里 |
| `--角色资源目录` | 可选 | 角色参考图目录；不给则为空，后续填 |
| `--背景资源目录` | 可选 | 背景图目录；不给则为空，后续填 |

### 输出（在工作目录生成的内容）

| 文件 / 目录 | 说明 |
|---|---|
| `工作配置.yaml` | 8 个中文字段：角色资源所在目录 / 背景资源所在目录 / 图片输出目录 / 视频输出目录 / 角色背景一览表 / 剧情生成文件 / 提示词生成文件 / 世界书 |
| `角色背景一览表.md` | 含三章节标题（`现有资源角色清单` / `背景清单` / `剧情角色清单`）的空骨架，各节由对应功能填入条目 |
| `剧情生成.md` | 空骨架（功能 3 写完整剧情） |
| `提示词生成.md` | 空骨架（功能 4–7 的主要工作文件） |
| `世界书.md` | 空骨架（世界观锚点，功能 3 填充） |
| `图片/` | 默认图片输出目录（已建好） |
| `视频/` | 默认视频输出目录（已建好） |

### 行为说明（AI 直接照此预期）

- 三目录参数原样写进 `工作配置.yaml`；图片/视频输出目录默认置于工作目录下（路径已建好）。
- **不覆盖已有**：`工作配置.yaml` 已存在则跳过不重写；三份 `.md` 已存在则跳过不覆盖；只新建缺失的。
- 不联网、不调用任何识别接口，纯本地建文件。

### 调用示例

```
python 初始化工作目录.py --工作目录 "D:/proj/火影" --角色资源目录 "D:/char" --背景资源目录 "D:/bg"
```

> 仅 `--工作目录` 必传，角色/背景目录可后续手动填入 `工作配置.yaml`。
