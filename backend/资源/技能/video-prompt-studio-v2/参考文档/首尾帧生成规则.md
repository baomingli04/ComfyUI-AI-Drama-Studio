# 首尾帧生成规则（参考文档）

## 何时读 / 读它干什么 / 不读会漏什么

- **何时读**：功能 5 调用时——已拿到 `提示词生成.md` 分镜，要替需要出图的段落生成「首帧 / 尾帧」静帧图与「背景图」。
- **读它干什么**：按本规范读取分镜的判定字段，批量出图，并把生成文件地址**自动回写**到 md（不用手填）。
- **不读会漏什么**：首帧 / 尾帧 / 背景不一致 → 视频起止跳变、人物漂移、背景跳变；地址漏回写 → 功能 6 / 7 读不到图。

---

## 概念

- **首帧 / 尾帧**：视频-首尾帧工作流（MiniMax H3 FL2VA）所需的**起止两张静帧**。
  - 首帧 = 该段动作「起点」画面；尾帧 = 该段动作「终点」画面。
  - 首尾帧只锁起止，中间运镜由视频工作流补全。
- **背景图**：场景底图，由文生图（Z-Image）产出；多人同框时由 Qwen 把人物合成到背景上。

---

## 读取 提示词生成.md 的判定字段（决定要不要出图）

对 `提示词生成.md` 的每一个 `## 段<N>` 块，按以下两个标志位判定：

| 段字段 | 取值 | 含义 | 出什么 |
|---|---|---|---|
| `是否生成背景图片` | `是` | 本段背景无现成图，需要文生图现出 | 1 张背景图（命名 `<场景ID>_背景.png`） |
| `是否生成首帧图片` | `是` | 本段首帧需含人物且人物 ≤ 2、中途不换人，用图片工作流出首/尾帧 | 2 张：首帧 + 尾帧（`<段N>_首帧.png` / `<段N>_尾帧.png`） |

> - `是否生成背景图片 = 是` 且 `场景背景图` 已填（非空）→ **跳过**生成（视为现成图复用），不重复出。
> - `是否生成背景图片 = 否` 但 `场景背景图` 为空 → 配置矛盾，py 打印 `[背景][警告]`（不中断，该段相关帧将缺背景，需人工补背景或改配置）。
> - 同一 `场景ID` 在多段共用：第一段生成后回填 `场景背景图`，后续段自动复用，**不会重复出背景**。
> - `是否生成首帧图片 = 否` 的段（人物 > 2 / 无首帧人物 / 走 Ref2VA 不单独出首帧）→ 本功能不处理，留给功能 6 / 7。

---

## 人物一致性硬规则（首帧 ↔ 尾帧）

1. **同角色**：首帧与尾帧必须是同一角色，锚定 `角色背景一览表.md` 的「剧情角色清单 → 匹配资源角色（参考图）」参考图（由 py 经 `--image1 / --image2` 传入）。
2. **同背景**：必须用本段背景图（图片3），禁止两张背景不同。
3. **同服装 / 同发型 / 同肤色**：禁止首尾帧出现服饰、发型、肤色漂移。
4. **差异只在动作进度**：首帧 = 起点姿态，尾帧 = 终点姿态；其余视觉要素保持一致。
5. 双人同框：两人都需一致，仅姿态按起 / 止变化。

---

## 提示词写法铁律（生成首帧 / 尾帧 / 背景 都遵守）

> 核心：**提示词不提人名，只用「图片N」指代；具体描述人物占位与朝向**。人物真实长相由参考图负责，背景由背景图负责。

### A. 首帧 / 尾帧（Qwen 图片工作流，general 三图）

- 人物指代：**`图片1的角色` / `图片2的角色`**（绝不写「鸣人」「佐助」这种人名）。
- 背景指代：**`图片3的场景`**（绝不写场景名 / 建筑 描述）。
- 必须写清**人物占位**（左 / 右 / 前 / 后）+ **各自朝向**（看镜头 / 互看 / 侧脸 / 转头 / 回眸 / 低头…），否则模型自行排布、都正脸看镜头。
- **禁外貌 / 服装 / 背景环境描写**：这些由参考图负责，多写一个服装 / 场景词都算过量。只写「图片N + 占位 + 朝向 + 动作」指针。
- 示例（双角色首帧）：`图片1的角色在左、图片2的角色在右，以图片3的场景为背景；两人并肩而立，图片1的角色侧脸看向右侧、图片2的角色看向画面左侧（互看）`
- **无阴影无阴暗**：py 自动在正向提示词追加「画面无阴影无阴暗」（兜底；功能 4 写的提示词若已含则不再重复）。
- **保五官（Qwen edit 硬约束）**：py 自动在正向提示词注入「严格保留原图人物五官 / 脸型 / 发型 / 身材，人物干净」，负向注入「人物蜡黄 / 阴暗 / 脏」。目的：防止 Qwen 编辑把人物脸型 / 五官改崩，尤其在双人合成、多段复用同一参考图时。功能 4 写的提示词若已含则不再重复。

### B. 背景（文生图 Z-Image）

- 提示词 = 本段 `场景背景描述`（场景 / 时间 / 画风的文字描述）。
- py 自动强制追加：**「无阴影无暗影」+「空旷无人」**。
- **背景图必须空旷无人**：人物由 Qwen 合成阶段加，不在背景里出现。
- 适用情形：本段 `是否生成背景图片 = 是` 且无现成背景图时，由 py 调 Z-Image 出图。

---

## 资源图怎么传（py 自动完成，了解即可）

- **图片1 / 图片2** = 本段 `使用角色` 按顺序对应的资源参考图：
  - `使用角色` 采用**槽位格式**：
    ```
    使用角色: |
      图片1: 鸣人
      图片2: 佐助
    ```
  - py 读 `角色背景一览表.md` 的「剧情角色清单」，把「鸣人」映射成 `匹配资源角色（参考图）`（如 `char_naruto.png`），再到 `工作配置.yaml` 的 `角色资源所在目录` 取文件。
  - 单角色段：图片2 自动复用图片1（工作流要求三图参考必须有 image2）。
- **图片3** = 背景图：优先 `场景背景图`（现成文件），同段刚生成的 `<场景ID>_背景.png` 也作为候选。

---

## 执行：py 一键批量出图 + 自动回写

脚本：`py脚本/生成首尾帧与背景.py`（复用同目录 `Qwen出图.py` 出首/尾帧、`Z-Image文生图.py` 出背景）。

```bash
# 常规：按 工作配置.yaml 跑全部段
python 生成首尾帧与背景.py --config "D:/proj/工作配置.yaml"

# 只核对将要执行的任务，不出图、不回写
python 生成首尾帧与背景.py --config "D:/proj/工作配置.yaml" --dry-run

# 只处理指定段
python 生成首尾帧与背景.py --config "D:/proj/工作配置.yaml" --only 段1,段2
```

- `--comfy-url`：ComfyUI 地址（默认 `http://127.0.0.1:8188`）。
- `--comfy-output`：ComfyUI 输出根（默认自动探测 `D:/ComfyUI-aki-v3/ComfyUI/output` 等），用于把产物从 ComfyUI 盘拷到项目目录。

### 回写字段映射（py 自动写回 `提示词生成.md` 对应段）

| 段字段 | 什么时候写 | 写什么 |
|---|---|---|
| `场景背景图` | `是否生成背景图片 = 是` 且本段出背景后 | 背景图文件名（如 `木叶村口大道_背景.png`） |
| `背景图片存放位置` | 同上 | 背景图绝对路径 |
| `生成图片首帧地址` | `是否生成首帧图片 = 是` 出首帧后 | 首帧绝对路径 |
| `生成图片尾帧地址` | `是否生成首帧图片 = 是` 出尾帧后 | 尾帧绝对路径 |

> 回写幂等：已填则覆盖、未填则插入，可反复跑（不重复插入）；目标文件已存在则跳过生成。

### 落盘命名

- 背景：`<图片输出目录>/<场景ID>_背景.png`
- 首帧：`<图片输出目录>/<段N>_首帧.png`
- 尾帧：`<图片输出目录>/<段N>_尾帧.png`
- `图片输出目录` 取自 `工作配置.yaml`（默认工作目录下 `图片/`）。
