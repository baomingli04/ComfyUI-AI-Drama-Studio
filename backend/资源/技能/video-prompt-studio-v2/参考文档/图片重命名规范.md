# 图片重命名规范

> **何时读**：执行「功能 2：角色 / 背景文件夹图片重命名」之前必须读；写 `重命名.py` 或修改命名规则时也必须读。
> **读它干什么**：拿到本技能重命名的唯一权威规则——识别接口用法、角色 8 字段命名、背景场景命名、跳过判定、重名处理、禁止项。
> **不读会漏什么**：文件名字段顺序/分隔符写错、已改名文件被重复处理、肤色填成无区分度废话、角色/背景没写进 `角色背景一览表.md`。

---

## 一、识别接口

- 主接口：图片识别 / 反推端点 `http://192.168.31.131:8488`（llama.cpp 视觉）。
- 备用：接口繁忙时改用 ComfyUI 的图片反推工作流（`反推_图生提示词_中英双语 (1).json`）。
- 调用识别接口时，用结构化反推提示词强制模型按「字段名：值」逐行输出，解析为命名所需属性。

## 二、角色目录 — 8 字段命名

- **格式**：`{视图}_{年龄}_{服饰}-{服饰颜色}_{肤色}_{姿势}_{发型}_{发色}_{背景}.png`
- **分隔符**：字段间用下划线 `_`；「服饰」与「服饰颜色」之间用短横 `-`；不使用全角横线。
- **视图**：原文件名含「三视图 / 多角度 / 多视图」→ `多角度视图`，否则 `单一视图`。
- **字段取值**：
  - 年龄（含性别，如「年轻女性」）
  - 服饰（如「红衣」）
  - 服饰颜色（如「红色」）
  - 肤色（从 白皙 / 偏白 / 偏黄 / 小麦色 / 古铜色 / 深棕 / 黝黑 中取最贴切）
  - 姿势（如「持刃戒备」）
  - 发型（如「长直发」）
  - 发色（如「乌黑」）
  - 背景（如「古庙正殿夜景」）
- **跳过判定**：文件名以 `单一视图_` 或 `多角度视图_` 开头 → 视为已改名，跳过。
- **反推存档**：原始反推文本存档为 `{原名base}_反推.txt`（可据此还原原名）。

## 三、背景目录 — 场景命名

- **格式**：`{场景描述}_背景.png`
- **场景描述**：识别接口提取的环境 / 场景文字（如「古庙正殿夜景」）。
- **沿用已有场景名（重要）**：若文件 stem 已是可读中文场景描述（含 CJK、且非 `ScreenShot` / `IMG` / 时间戳等无意义编号），视为已含场景描述，**直接补 `_背景` 后缀、不再识别**——尊重用户手起的场景名，避免被 AI 识别覆写成更差的名字；仅当 stem 为无意义编号 / 截图名时，才调用识别接口生成场景描述。
- **跳过判定**：文件名以 `_背景.png` 结尾 → 视为已改名，跳过。

## 四、重名处理

- 目标名已存在则追加 `_2` / `_3` … 避免覆盖。

## 五、禁止项

- 肤色不得填「健康 / 正常 / 自然 / 普通肤色」等无区分度废话。
- 识别失败或字段不足则保留原名并跳过。

## 六、产出

- 原地重命名后的图片文件（目录不变）。
- 角色图另生成 `{原名}_反推.txt` 存档（受 `--no-txt` 控制）。
- 所有角色和背景都写入 `角色背景一览表.md`。
- 角色条目格式：`- \`相对路径\` | 角色（性别）`（相对路径含 `男/女/角色名` 文件夹，供下游 `生成剧情角色表.py` 按性别匹配）。

---

## 七、运行 `重命名.py`（指引 AI）

> 本功能由 `py脚本/重命名.py` 实际执行。AI 按本段调用，命名规则以上面一～六为准，不要另立。**本段已列清输入/输出/行为，AI 无需读脚本源码即可直接调用。**

### 脚本功能

对指定目录下的图片逐张识别 → 按一～六规则重命名（角色 8 字段 / 背景 `{场景描述}_背景`），并把结果回写 `角色背景一览表.md`。已规范命名的文件自动跳过（可断点续跑）。

### 输入（命令行参数）

| 参数 | 必填 | 含义 |
|---|---|---|
| `--config` | 二选一 | `工作配置.yaml` 路径；从中读角色/背景目录 + 决定一览表所在目录 |
| `--dir` | 二选一（可重复） | 用户直接指定目录；`角色:<路径>` / `背景:<路径>` 指定类型，不加前缀默认按角色。**指定子集目录（如某角色子目录）时，只重新处理该子集涉及的角色/背景子块，其余子块从一览表原样保留，不会冲掉整节**；不给 `--dir` 或给的正是完整资源根目录则全量重建 |
| `--project-dir` | 可选 | `角色背景一览表.md` 所在目录；不给则取 `--config` 所在目录，无 config 取各 `--dir` 公共父 |
| `--comfy-url` | 可选 | ComfyUI 地址，默认 `http://127.0.0.1:8188` |
| `--backend` | 可选 | 远程识别端点，默认 `http://192.168.31.131:8488` |
| `--consecutive` | 可选 | 识别接口连续失败几次转 ComfyUI，默认 `3` |
| `--no-fallback` | 可选 | 远程失败不回退 ComfyUI（不推荐） |
| `--timeout` | 可选 | 单图等待秒数，默认 `120` |
| `--dry-run` | 可选 | 只预览不改名、不写一览表 |
| `--no-txt` | 可选 | 不写 `{原名}_反推.txt` 存档 |
| `--no-rename` | 可选 | 仅按目录重建「现有资源角色清单 / 背景清单」（登记相对路径），**不改名、不调用识别接口**；用于恢复/对齐清单（如 `--dir` 子集跑坏整节后用全量 `--config --no-rename` 重建） |

> 至少要提供 `--config` 或至少一个 `--dir`，否则脚本报错退出。

### 输出（直接产物）

| 产物 | 说明 |
|---|---|
| 原地重命名的图片 | 目录不变，文件名按规则改；重名追加 `_2`/`_3` |
| `{原名}_反推.txt` | 每张图的识别/反推原始文本（默认写，`--no-txt` 关闭） |
| `角色背景一览表.md` | 项目目录里，每张改名成功的图**追加一行**（已有该文件名则跳过，不重复） |

### 行为说明（AI 直接照此预期）

- **识别后端与回退**：主用 `http://192.168.31.131:8488`（llama.cpp 视觉，快）；**连续失败达阈值（默认 3 次）后，后续统一改用 ComfyUI 图片反推工作流改名**（慢但稳，不卡死）。
- **跳过判定**：文件名以 `单一视图_` / `多角度视图_`（角色）或 `_背景.png`（背景）结尾 → 视为已改名，跳过。
- **回写一览表（必做）**：每张图改完（或已规范命名）→ 检查一览表是否已有该文件名条目；没有就追加、有就跳过下一张。
- **单实例锁**：脚本自带头文件锁，同一时间只允许一个实例跑，避免 ComfyUI 队列堆积。
- 依赖 `视觉识别.py` 与 `反推提示词.py`（回退链路），二者已在 `py脚本/` 内。

### 调用示例

```
# 从配置读角色/背景目录（推荐）
python 重命名.py --config "D:/proj/工作配置.yaml"

# 用户直接指定多个目录（混角色/背景）
python 重命名.py --dir "角色:D:/char" --dir "背景:D:/bg" --project-dir "D:/proj"

# 只预览、不改名
python 重命名.py --config "D:/proj/工作配置.yaml" --dry-run
```
