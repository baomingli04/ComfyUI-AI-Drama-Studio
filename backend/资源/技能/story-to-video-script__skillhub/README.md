# Story To Video Script

把小说段落 / 故事文本转换为「直接拿去小云雀（Seedance 2.0 / 2.5）生成视频」的生产包。

输入一段小说，产出**一份纯 Markdown 生产包**：角色 / 场景 / 物品资产卡（文生图提示词）+ 分镜表（每个镜头的完整提示词）+ 人物场景一致性方案。复制粘贴即可去小云雀生成视频。

## 特性

- **故事直出**：贴一段小说段落，自动拆解为可生产的视频剧本
- **创意简报 intake**：基于故事内容对 8 个关键问题给出预测选项 + 推荐项，不懂专业名词也能 30 秒定稿
- **版本自适应**：生成前询问 Seedance 2.0 / 2.5，自动切换时长上限与引用语法（2.5 用 `@[Character: C01]` 命名标签，2.0 用 `@图片N` 数字引用）
- **一致性方案（头条）**：资产卡（文生图建立一致性基底）+ 引用硬锚点 + 风格统一参数 + 尾帧续接，破「人物每镜头漂移」难题
- **视听语言内置**：景别 / 运镜 / 光影 / 构图 / 节奏 / 蒙太奇六杠杆映射表，避免「会动的 PPT」
- **明确报错（不静默失败）**：版本混用（E1）、跳过必问项（E2/E3）、输入过短过长（E4/E5）、输入类型不符（E6）、引用编号错位（E7）均有标准报错与修复指引
- **输入长度边界**：100–800 字标准单集；<100 字走迷你模式；>2400 字自动分集，先判定再执行
- **快速查找索引**：`references/faq.md` 关键词→答案速查表，想找具体问题不用翻全文

## 怎么用

1. 安装：把本仓库放入 `~/.workbuddy/skills/`（或直接导入 `story-to-video-script.zip`）
2. 给 WorkBuddy 贴一段小说段落
3. 按创意简报点选 8 项（每项有推荐，跳过即用默认）
4. 拿到生产包 → 打开小云雀「沉浸式短片（Seedance 2.0 / 2.5）」：
   - 先用资产卡的文生图提示词生成角色 / 场景 / 物品参考图
   - 上传参考图，按分镜表逐条复制最终提示词生成视频

