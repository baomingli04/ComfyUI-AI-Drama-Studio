# 视听语言六杠杆（Cinematic Techniques）

分镜"像电影"还是"像会动的 PPT"，差的就是视听语言，不是模型或提示词长度。生成每个镜头前先问："这一拍要让观众看哪里、感受到什么？"再选对应杠杆。

## 1. 景别分层（引导视线与情绪）

| 景别 | 作用 | 何时用 |
|------|------|--------|
| 远景 | 交代环境、规模 | 开场建立世界 |
| 全景 | 交代人物与空间关系 | 入场 / 离场 |
| 中景 | 交代动作 | 大多数叙事 |
| 近景 | 传递情绪 | 反应、对话 |
| 特写 | 放大细节 | 关键物 / 表情转折 |
| 大特写 | 极致张力 | 眼神、手握紧、水滴 |

递进用法：远景 → 中景 → 近景 → 特写，逐步把观众拉进情绪。

## 2. 运镜 → 情绪

| 运镜 | 情绪 / 功能 |
|------|------------|
| 推镜头 | 放大情绪、逼近真相 |
| 拉镜头 | 孤独感、揭示信息、抽离 |
| 跟镜头 | 代入感、同行 |
| 环绕镜头 | 主角感、压迫 / 崇拜 |
| 上摇 | 气势、仰望 |
| 下摇 | 坠落、俯视弱势 |
| 希区柯克变焦 | 心理冲击、失衡 |
| 手持晃动 | 紧张、纪实、混乱 |
| 缓慢移镜 | 克制、诗意 |
| 一镜到底 | 沉浸、连贯 |

慢推克制、快推爆发；节奏平 = 全程匀速 + 镜头一直动，必须用前摇 / 停顿 / 留白制造张弛反差。

## 3. 光影 → 情绪

| 光 | 情绪 |
|------|------|
| 逆光 | 英雄感、浪漫、神秘 |
| 顶光 | 压迫、权力 |
| 底光 | 诡异、恐怖 |
| 侧光 | 内心冲突、雕塑感 |
| 硬光 | 张力、冷峻 |
| 柔光 | 治愈、温柔 |
| 丁达尔光 | 史诗、神圣 |
| 蝴蝶光 | 主角感、商业质感 |

光影方向 / 光比 / 色温可控：体积光、反光、补光层次写进提示词。

## 4. 构图 → 作用

| 构图 | 作用 |
|------|------|
| 中心构图 | 主角、稳定 |
| 三分法 | 呼吸感、自然 |
| 对角线 | 张力、动势 |
| 对称 | 权力、仪式感 |
| 引导线 | 视线引导 |
| 框架式 | 旁观感、偷窥感 |
| 前景遮挡 | 空间感、电影感（记得写"虚化"） |

## 5. 节奏 = 情绪推进速度

- 慢铺垫：长镜头、少切、留白
- 快压迫：短镜头、快切、手持
- 先压抑再释放：低动态蓄积 → 高潮爆发
- 反差最敏感：情绪停顿 / 环境节奏 / 镜头留白制造张弛

## 6. 蒙太奇制造意义

同一画面接不同镜头产生不同含义：时间蒙太奇（成长）、情绪蒙太奇（共振）、平行蒙太奇（双线）、联想蒙太奇（隐喻）。

## 7. 活人感三招

- 客观镜头改**过肩 POV + 前景虚化**
- **情绪表情拆细节**：面部情绪 = 嘴角 + 眼部 + 面部；完整情绪 = 表情 + 手部 + 身姿 + 视线
- **配音真实感**：用标点控语气、写"发声方式"而非"情绪词"、给场景与动机（场景 + 人物状态 + 发声方式 + 台词）

## 8. 情绪弧线（每个镜头组必备）

开场（建立氛围）→ 发展（紧张上升）→ 高潮（情感峰值 / 关键揭示）→ 释放（解决或悬念）。只堆情节点、没有情绪进展 = 流水账。
