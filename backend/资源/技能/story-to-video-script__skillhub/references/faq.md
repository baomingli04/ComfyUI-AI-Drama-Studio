## 二、常见问题（Q&A）

### Q1 我给的输入不是小说段落，能用吗？
**不能硬用。** 本 skill 只处理"叙事性文字"。输入类型不符合时按 When To Use 的"不适用"分支处理：
- 完整剧本 / 台词稿 → 提示用户先转写成叙事段落（补画面描写）
- 一句话灵感 / 大纲要点 → 提示先扩写
- 议论文 / 说明文 / 新闻稿 → 明确不适用
报错参考 E6。

### Q2 内容太长或太短怎么办？
| 输入长度（约） | 处理 |
|---|---|
| < 100 字 | 提示"输入过短"，二选一：① 用户补充细节；② 迷你模式只出 1 个关键镜头（报错 E4） |
| 100 – 800 字 | 标准单集，正常五步流水线，产出 1 段 |
| 800 – 2400 字 | 提示"内容较长"，自动切分为多个完整弧线 / 多集，每集独立分镜 |
| > 2400 字 | 提示"超过单次上限"，请分段提供或按章节分批（报错 E5） |

### Q3 我把关键问题都跳过了，会怎样？
- **Q4 模型版本：无默认值，跳过会停下追问（E2），不选不继续。**
- Q1 风格 / Q2 情绪 / Q3 平台：跳过 = 用推荐项，生产包标注"（默认）"（E3）。
- 建议至少确认 Q4 + Q1（风格最影响画面观感），其余可跳过。

### Q4 2.0 和 2.5 到底选哪个？
- 想要 **30 秒长镜头、多语言口型、命名标签引用（`@[Character: C01]`）** → 选 **2.5**
- 只要 **15 秒短片段、简单引用** → 选 **2.0**
- 拿不准就选 2.5（能力更全，语法升级版）。

### Q5 我的故事里角色很多，会怎样？
资产卡会自动编号 C01、C02…，每个主要角色都出卡；分镜里含人物镜头必须引用对应角色卡（2.5：`@[Character: Cxx]`；2.0：`@图片N`）。角色过多（>8）会提示精简或分批处理，避免参考图超上限。

### Q6 输出结果里引用编号对不上（E7）？
交付前跑质量检查清单（`seedance-guide.md` §10）：所有分镜引用的 C/S/P 编号必须在资产卡中存在，含人物镜头 100% 引用角色卡。发现对不上 → 补卡或改引用，不允许带着错号交付。

## 三、错误编号 E1–E7 对照与修复（报错速查）

| 编号 | 报错提示（统一格式） | 修复方法 |
|---|---|---|
| **E1** | `⚠️ [E1] 版本混用：检测到 2.5 命名标签与 2.0 数字引用同时出现，引用语法必须全包统一` | 回到 Step 1 Q4 重确认版本，整体重写全部引用 |
| **E2** | `⚠️ [E2] 模型版本未确认：Q4 无默认值，禁止跳过` | 停下追问版本，用户不选就不继续 |
| **E3** | `⚠️ [E3] 以下必问项已跳过，将使用推荐默认值：Q1 风格 / Q2 情绪 / Q3 平台` | 正常产出并标注"（默认）"，末尾附"如需更贴合可补充修改"提示 |
| **E4** | `⚠️ [E4] 输入过短（约 N 字），不足以支撑完整分镜` | ① 补充细节；② 迷你模式只出 1 镜头 |
| **E5** | `⚠️ [E5] 输入过长（约 N 字），超过单次上限 2400 字` | 自动切分多集 / 请用户分段 |
| **E6** | `⚠️ [E6] 输入不是小说段落：当前为[剧本/灵感/说明文]` | 按不适用分支：提示改写或拒绝 |
| **E7** | `⚠️ [E7] 一致性检查失败：分镜引用了 C03 但资产卡只有 C01–C02` | 交付前跑质量清单，补卡或改引用 |
