# 创意简报问答库（Intake Question Bank）

Step 1 的执行依据：收到小说段落后，**先快速通读解析**（人物气质、场景氛围、情节走向、情绪峰值），然后对每个问题给出 **3–4 个从段落推断的预测选项 + 1 个推荐项**（附一句话理由，如"因为段落里是雪夜复仇戏"）。用户点选 / 修改 / 跳过。

## 通用规则

- 预测选项**必须从段落内容出发**，不许空泛套模板；推荐项附理由："因为段落里…"。
- 所有选项用**大白话**，专业词后跟括号解释（如"电影感写实（像电影实拍，光影讲究）"）。
- 用户跳过的项 = 用推荐项，生产包"制作参数"里标注"（默认）"。
- **必问项 Q4 无默认值、必须问；Q1–Q3 有推荐项、可跳过**：跳过 Q4 → 停下追问（错误 E2）；Q1–Q3 全跳过 → 用推荐项并标注"（默认）"（错误 E3）。详见 SKILL.md"错误处理"与 `references/faq.md`。
- 用户选定后，把答案翻译成提示词参数（见各题映射），写入生产包"制作参数"。
- 一张表呈现全部问题，别连珠炮一问一答。

## Q1 视觉风格 / 画风（必问）

问法：这画面走哪种质感？
预测依据：故事类型（古风 / 现代 / 科幻 / 奇幻 / 现实）+ 场景描写（水墨意象 / 霓虹 / 写实细节）

选项模板（按段落贴合度排序，选 3–4 个）：
- 电影感写实：像电影实拍，光影讲究、人物真实 [现实题材 / 强情绪戏]
- 唯美动画：像动漫 / 国漫，线条干净、色彩鲜明 [奇幻 / 治愈 / 古风]
- 水墨国风：像水墨画，留白写意 [古风 / 武侠 / 诗词意境]
- 赛博 / 科技感：霓虹冷光、未来都市 [科幻 / 都市夜]
- 复古胶片：颗粒、暖调、年代感 [年代文 / 怀旧]

映射：→ 所有资产卡与分镜的**风格前缀**（必须全程一致）

## Q2 视频目的 + 想让观众留下的情绪（必问）

问法：这段做出来是为了啥，想让观众什么感觉？
预测依据：情节走向（燃点 / 泪点 / 爽点 / 治愈点）+ 结局氛围 + 情绪曲线峰值

选项模板：
- 燃：热血爆发、情绪顶上 [战斗 / 逆袭 / 高光戏]
- 泪：感人催泪 [牺牲 / 离别 / 和解]
- 爽：逆袭打脸、解气 [反转 / 反击]
- 悬疑：钩子悬念、意犹未尽 [谜团 / 留白]
- 温馨：日常治愈 [温情小片段]

映射：→ 基调 → 光影（逆光英雄 / 柔光治愈 / 顶光压迫）+ 配乐风格 + 节奏

## Q3 发布平台 / 画幅（必问）

问法：发哪个平台？（直接决定竖横）
预测依据：内容形态——短视频剧情默认竖屏

选项模板：
- 抖音 / 快手 9:16 竖屏（默认推荐）
- B站 / 视频号 16:9 横屏
- 小红书 9:16 或 3:4
- 电影宽幅 2.35:1（走质感大片）

映射：→ 构图与比例，写入每个分镜 prompt 的限定信息

## Q4 模型版本（必问）

- Seedance 2.0：15 秒单段、`@图片N` 数字引用
- Seedance 2.5：30 秒单段、`@[Character: C01]` 命名标签、多语言口型

无预测必要，直接两个选项让用户选（版本差异见 seedance-guide.md §0）。

## Q5 节奏（推荐问）

问法：整体节奏快还是慢？
预测依据：段落信息密度 + 情节紧张度

选项模板：
- 快切紧凑：短镜头连击、爽感强 [动作 / 反转密集]
- 电影慢镜：长镜头留白、情绪沉浸 [情感戏 / 氛围向]
- 均衡：张弛有度 [常规叙事]

映射：→ 运镜档位（快推 / 缓慢移镜）+ 分镜密度 + 动态参数

## Q6 对白 / TTS 口型同步（推荐问）

问法：要不要配音说话？
预测依据：段落是否有对话 / 内心独白

选项模板：
- 要配音（对话驱动，口型同步）：人物开口说话，提示词嵌入对白时间轴
- 旁白解说（OS / VO）：画外音讲故事，画面配合旁白
- 纯画面 + 字幕：无 TTS，信息靠画面与后期字幕

附问：对白语言（普通话 / 方言 / 其他），2.5 支持多语言口型。

映射：→ 是否写对白时间轴、声线设计（音色 / 年龄感 / 情绪质感）

## Q7 音乐 / 音效（推荐问）

问法：声音怎么配？
预测依据：段落氛围 + 是否有动作音效点

选项模板：
- 原声环境音：风声雨声、环境底噪，真实沉浸 [写实向]
- 情绪配乐：BGM 烘托，关键点卡情绪 [剧情向]
- 静音 ASMR：极简音效，治愈感 [治愈 / 好物向]

映射：→ 分镜【声音】块设计（配乐风格 + 音效清单）

## Q8 参考图（可选，一致性外挂）

问法：有没有现成的人物 / 场景图？
选项：上传角色图 / 上传场景图 / 都没有（用资产卡从零生成）

映射：有图 → 资产卡直接以图为基底，提示词写"参考此图保持 XX 特征"。

## 收尾开放补充

最后加一句："还有要补充的吗（核心梗 / 目标受众 / 必须避免的内容）？"——用户不说就跳过。
