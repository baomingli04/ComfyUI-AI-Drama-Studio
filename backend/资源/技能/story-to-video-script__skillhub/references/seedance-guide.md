# 小云雀 / Seedance 2.0 / 2.5 平台规范与提示词铁律

本文件是所有分镜提示词的底层约束。生成任何 prompt 前逐条核对。

## 0. 版本差异（2.0 vs 2.5，生成前先问用户）

| 维度 | Seedance 2.0 | Seedance 2.5 |
|------|--------------|--------------|
| 单次直出时长 | 15 秒 | 30 秒 |
| 参考素材上限 | 12 个 | 50 个（30 图 + 10 视频 + 10 音频） |
| 引用语法 | `@图片N` / `@视频N` / `@音频N`（数字编号） | 同上 + `@[Character: X]` / `@[Location: S]` / `@[Prop: P]` 命名标签 |
| 时间戳稳定性 | 较弱，强口型场景才用秒数，其余用"镜头N"排序 | 较稳，可用秒数时间轴 |
| 多语言口型 | 无 | 支持 |

- **2.5 专属**：`@标签` 命名引用、30 秒直出、50 参考、多语言口型。
- **2.0 等价做法**：参考图照传，引用改用数字 `@图片N`；时长按 15 秒规划；时间戳不强制，用"镜头1/镜头2"按事件顺序组织（口型同步强需求仍用秒数）。
- 本 skill 所有 `@[Character/Location/Prop]` 命名写法**仅当用户确认用 2.5 时输出**；用 2.0 时自动降级为 `@图片N` 数字引用。
- **版本一经确认，全包统一，禁止混用**：若检测到同一份提示词里同时出现 `@[Character: C01]` 与 `@图片N`，判定为版本混用（错误 E1），停下重确认版本后整体重写。详见 SKILL.md"错误处理"。

## 1. 平台能力边界

- 模型：**Seedance 2.0 / 2.5**（生成前问用户选哪个）。入口：创作 → 模式 → **沉浸式短片（Seedance 2.0 / 2.5）**。2.5 单次直出 30s、2.0 为 15s，其余差异见 §0。
- 单次直出时长：**30 秒**（2.0 仅 15s）。新场景先用 4–8s 验证风格，再拉满所选版本上限（2.0 15s / 2.5 30s）。
- 参考素材上限：**2.5 为 50 个**（30 图 + 10 视频 + 10 音频）；**2.0 仅 12 个**。
- 模式特性：**视听一体**——生成画面的同时原生生成音效 / 环境音 / 配乐，支持口型同步与情绪匹配。声音设计是一等公民，不是附属。
- 画幅比例：9:16 竖（抖音 / 快手）、16:9 横（B站 / 视频号）、1:1（封面）。
- 多语言口型同步、局部编辑、视频延长、白模预演、绿幕编辑均已支持。

## 2. 沉浸式短片黄金公式（八维，逐项填充，缺一不可）

```
[主体描述] + [画面运动描述] + [音效互动] + [台词] + [音色描述] + [运镜/环境] + [风格修饰] + [限定信息]
```

- 主体描述：谁 / 什么在画面里，外观与状态
- 画面运动描述：主体怎么动、怎么变化
- 音效互动：与画面同步的声音（碰撞、风声、呼吸、环境音）
- 台词：角色说的话（按时间轴嵌入，见铁律 4）
- 音色描述：谁的声音、年龄感、情绪质感
- 运镜 / 环境：镜头怎么动、在什么光线下
- 风格修饰：画风 / 色调 / 质感关键词
- 限定信息：比例、时长、无字幕等硬约束

## 3. @标签命名引用（仅 Seedance 2.5 支持；2.0 改 `@图片N` 数字引用，见 §0）

> 2.5 用命名标签锁定一致性；若用户选 2.0，本节的 `@[Character: C01]` 等全部替换为 `@图片N` / `@视频N` / `@音频N` 数字编号（参考图照样上传）。

上传参考图 / 视频 / 音频后，在提示词里用 `@` 唤起选择器，插入**结构化标签**引用素材：

```
@[Character: C01]   角色参考（人物样貌 / 妆造锁定）
@[Location:  S01]   场景参考（环境 / 光线锁定）
@[Prop:      P01]   道具参考
@[Motion Style: 慢推]  运镜风格参考
@[Audio: A01]       声线 / 配乐参考
```

用法要点：
- 每个含人物的镜头**必须** `@[Character: Cxx]` 引用其资产卡；场景镜头 `@[Location: Sxx]`。
- 标签名与资产卡编号一一对应（C01 / S01 / P01…）。
- 纯文字描述人物易漂移，@标签引用参考图才是硬锚点。

## 4. 时间戳提示词（长镜头节奏控制）

用时间轴块组织长镜头，防止后半段漂移到未脚本行为（下方示例按 15s 规划；选 2.5 时按比例扩展到 0–30s）：

```
0-3秒：[场景建立] - [镜头运动]，[画面描述]，[环境音效]
4-8秒：[主体引入] - [镜头运动]，[动作]，[动作音效]，角色A（情绪）："[对白]"
9-12秒：[高潮] - [镜头运动]，[情绪爆发]，[视觉冲击 + 同步音效]
13-15秒：[结尾] - [镜头运动]，[最终画面]，[余韵]
```

规则：
- 每个时间戳块**只描述一个连续动作弧线**，不塞 4–5 个不相关动作。
- 摄像机指令放在块的**最后**，不埋中间。
- 对白嵌入对应秒数（见铁律 4）。
- 参考耗时：单集分镜视频生成约 7 分钟。

## 5. 动态参数模板

| 类型 | 动态强度 | 动态范围 | 运镜 |
|------|----------|----------|------|
| 人像 | 极低 | 局部画笔动态 | 关闭 / 微弱摇镜 |
| 风景 | 中低 | 轻微局部动态 | 轻微摇镜 / 移镜 |
| 国风静物 | 极低 | 极小范围动态 | 关闭 |
| 动作 / 战斗 | 中高 | 主体大动作 | 快推 / 跟随 |

避坑：单次只以一种动态为主，不叠加"高运镜 + 高动态"；只涂需要动态的小范围区域；低动态强度防乱晃变形。

## 6. 通用提示词模板

- 人像：`人物形象 + 表情神态 + 场景 + 自然光影 + 写实高清 + 五官精致 + 比例`
- 风景：`风景主体 + 自然环境 + 柔和光线 + 写实细节 + 治愈氛围 + 比例`
- 静物国风：`物品/场景 + 古风意境 + 柔和光影 + 静谧氛围 + 高清细节`
- 公式骨架：`主体 + 表情 + 场景 + 光影 + 画质`

## 7. 铁律全集（必守）

**铁律 0 平台与模式**：沉浸式短片 = 视听一体，声音是一等公民；八维黄金公式逐项填充。

**铁律 1 时长与分段**：段时长 ≈ `对白句数 × 1.3s + 画面节拍数 × 0.8~1.5s`。密集场景（9+ 节拍 / 6+ 对白）拆 2 段，拆分点选 hook 断点（疑惑 / 反转 / 情感峰值）。版本对白句数：15s（2.0）控 3–4 句，30s（2.5）控 6–8 句。新版模型对精确秒数支持不稳时，改用"镜头 1 / 镜头 2"按事件顺序组织（口型同步强需求仍保留秒数）。

**铁律 2 续接陷阱**：视频延长时 `@视频1` 的视觉元素被当强锚点续渲，要其消失须三重加固：①顶部加【关键差异指令】显式禁止"绝对不出现 XXX"；②用时间轴描述替代视觉锚点；③【参考】区注明"@视频1 仅用于色调 / 服饰 / 光线衔接，视觉元素以本 prompt 为准"。

**铁律 3 无字幕**：每个 prompt 开头第一句只写 `画面无任何字幕。`，删掉旧版冗长禁令。对白默认走 TTS 配音。

**铁律 4 对白排版**：对白按时间点嵌入对应时间轴分镜段（如 `6-9秒：…角色A（为难）："怎么分呢？"`）。【声音】块只放声线 / 配乐 / 音效，绝不集中堆对白，否则 TTS 与口型错位。

**铁律 5 审核规避**：删所有负面关键词，改正向描述（"少女俏皮无邪"替"严禁性感"）。"年龄 + 性别"组合高风险，中性化（"年轻女孩"）。避免暴露 / 黑暗 / 不适内容。

**铁律 6 TTS 配音陷阱**：叠字 / 谐音 / 方言尾音（"咕咕嘎嘎""欧润吉"）易念崩，改用画面表情 / 音效替代或交稳定角色承担；特殊读音词保留原文 + 拼音标注。

**铁律 7 动作可分性**：用"摔 / 取 / 递"替"掰断 / 剥瓣"等易崩形变动作；优先单一直白大动作。反常规物理动作（反向开合、非常规角度切割）先预判模型先验，用结果态镜头规避。

**铁律 8 双人手部混淆**：递 / 交易场景明确"POV 手臂无饰品，与 XXX 严格区分"，逐项锁定各自手部特征。

**铁律 9 输出排版**：每次修改后输出**完整版完整 prompt**，不只给局部片段；生成的分镜 prompt 正文不用长破折号，用空行 / 【方括号区块】分段。

**铁律 10 多模态声线锁定**：有真实参考音频用 `@[Audio: A01]` 锁定音色；文字声线档案作备份。

**铁律 11 视听语言优先**：见 `references/cinematic-techniques.md`。六杠杆：景别分层、运镜服务情绪、光影塑造故事、构图控制情绪、节奏 = 情绪推进、蒙太奇制造意义。

**铁律 12 提示词即视觉语言 / 去 AI 感**：结构 `情绪 + 主体 + 光线 + 镜头 + 细节`，具体 > 简短，用专业词。抽象词量化，词序即优先级（主体最前、光影中段、抽象词末尾）。去 AI 感 = 别太干净（加前景遮挡写"虚化"、做减法、剪词）。

## 8. 分镜最终提示词模板（直接套用）

> 2.5 用命名标签 `@[Character: C01]`；2.0 把同名引用换成 `@图片1` / `@图片2` … 数字编号（见 §0）。时长按所选版本填 15s / 30s。

```
画面无任何字幕。

[风格描述]，<时长 15s/30s 按所选版本填>，9:16竖屏，[整体氛围]

0-3秒：[场景建立] - [运镜]，[画面描述]，[环境音效]
4-8秒：[发展] - [运镜]，[动作]，[动作音效]，角色A（情绪）："[对白]"
9-15秒：[高潮→释放] - [运镜]，[情绪爆发]，[视觉冲击 + 同步音效]，[余韵]

【声音】[配乐风格] + [关键音效] + [各角色声线，对白已在时间轴内]
【参考】@[Character: C01] 角色一致性，@[Location: S01] 场景一致性，@[Prop: P01] 道具
```

## 9. 续接与多集

- 上一集结尾帧记录主体 / 背景 / 光线 / 构图 / 氛围，下一集开场匹配。
- 延长拼接：开头用 `将@视频N 延长Ns`（N 为上集视频参考编号）并上传上集作视频参考（配合铁律 2 三重加固）。
