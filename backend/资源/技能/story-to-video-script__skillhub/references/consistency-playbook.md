# 一致性方案（Consistency Playbook）

本 skill 的头条功能。叙事类 AI 视频最易翻车的是"人物 / 场景每镜头都变样"。纯文字描述锁不住一致性——小云雀靠**两条硬锚点**解决：资产卡（文生图建立基底）+ 引用（2.5 用 `@[Character: C01]` 命名标签 / 2.0 用 `@图片N` 数字引用，把基底钉进每个镜头）。

## 1. 为什么纯文字会漂移

Seedance 对"戴蓝帽的年轻女子"每代都会自由发挥，几镜头后帽子颜色、脸型、发型全变。文字是概率引导，不是锁定。解决方案：**先出图、再出片、用引用钉死**（2.5 用 `@标签` 命名引用 / 2.0 用 `@图片N` 数字引用，见 `seedance-guide.md` §0）。

## 2. 双柱结构

```
文字故事
  └─> Step3 资产卡（文生图提示词）→ 在小云雀生成角色/场景/物品参考图
        └─> Step4 每个镜头引用这些图（2.5: `@[Character: C01]`；2.0: `@图片N`）→ 硬锚定一致性
```

## 3. 资产卡写法

统一编号：`C01..` 角色 / `S01..` 场景 / `P01..` 道具。每张卡两份内容。

### 角色卡（C0x）— 给多角度，建立"三视图"基底

```
### C01 — 林晚（女主）

文生图提示词（正面）：
电影感写实风格，25岁亚洲女性，过肩黑长直发，杏仁眼，左眼角一颗小痣，
穿米白色宽松针织衫，右手戴银色细链手镯，自然光，半身近景，8k

文生图提示词（侧面/全身）：[同上但换角度与景别，保持服饰/标志物一致]

一致性锁定描述（供 @标签 引用）：
@[Character: C01] = 黑长直发 + 左眼角痣 + 米白针织衫 + 右手银链手镯   （2.5 命名标签；2.0 写作 `@图片1`）
```

要点：
- 为每个主要角色生成**正面 + 侧面 + 全身**至少 3 张参考图，覆盖不同角度，避免单一角度过拟合。
- 给角色定**专属视觉标志物**（颜色 / 配饰 / 发型 / 伤疤），并在锁定描述里写清，后续 @标签 一引就稳。
- 不同集 / 不同时空（如受伤后、换装）单独建卡 `C01b`，描述妆造差异。

### 场景卡（S0x）— 空场景锚点

```
### S01 — 沧州草料场·雪夜

文生图提示词：
电影感写实，黄昏雪夜，木质草料棚，积雪厚覆屋顶，远处枯树林，
冷蓝色调，微弱月光从左上打入，空无人物，广角全景，8k

一致性锁定描述：
@[Location: S01] = 雪夜 + 木草料棚 + 冷蓝调 + 左上月光   （2.5 命名标签；2.0 写作 `@图片2`）
```

要点：场景图**不含人物**，作为空场景锚点，保证每集同一地点光线 / 构图一致。

### 物品卡（P0x）

```
### P01 — 林冲长枪

文生图提示词：
写实质感，丈八蛇矛，枪尖寒光，红缨，木杆纹理清晰，纯黑背景，产品级打光，8k
```

## 4. 引用语法在工作流里的用法（2.5 命名标签 / 2.0 数字编号）

- **2.5**：资产卡图上传后，分镜提示词里 `@[Character: C01]` / `@[Location: S01]` / `@[Prop: P01]` 命名引用。
- **2.0**：同样上传资产卡图，引用改用数字 `@图片N` / `@视频N` / `@音频N`（见 `seedance-guide.md` §0）。
- **含人物的镜头必须引角色卡**；场景镜头引场景卡；出现关键道具引物品卡。
- 标签名与资产卡编号严格对应，错号即失效。

## 5. 风格统一参数（防整套片子画风分裂）

在"制作参数"与每个分镜里固定以下四项，全程不变：
- 模型：Seedance 2.0 / 2.5（按用户选择固定，全程不混用）
- 画质：统一 8k / 写实或选定画风前缀
- 动态参数：同类镜头用同一档（见 seedance-guide.md §5）
- 运镜档位：同一情绪用同一种运镜语言

所有资产卡的"风格前缀"必须一致（如统一"电影感写实风格"），否则图与片对不上。

## 6. 尾帧续接（破 30 秒魔咒 / 跨集连贯）

- 每集生成后记录**结尾帧**：主体姿态、背景、光线、构图、氛围。
- 下一集开场匹配上一集结尾帧；延长拼接用 `将@视频N 延长Ns`（N 为上集视频参考编号）+ 上传上集作视频参考（配合铁律 2 三重加固：顶部禁项指令 + 时间轴替代视觉锚点 + 参考区注明仅用于色调/服饰/光线衔接）。

## 7. 跨镜头一致性自查表（交付前勾）

- [ ] 每个主要角色都有 ≥3 张多角度参考图（资产卡）
- [ ] 每个常驻场景都有空场景锚点图（S0x）
- [ ] 含人物的镜头 100% 引用角色资产卡（2.5: `@[Character: Cxx]`；2.0: `@图片N`）
- [ ] 场景镜头引用场景资产卡（2.5: `@[Location: Sxx]`；2.0: `@图片N`）
- [ ] 角色标志物（配饰 / 发型 / 颜色）在锁定描述与分镜中一致
- [ ] 风格前缀在全部资产卡 + 分镜中一致
- [ ] 跨集结尾帧 → 开场帧已对齐
- [ ] 动态参数 / 运镜档位未按镜头随意跳变

## 8. 示例：一致性翻车 vs 稳住

❌ 翻车：分镜只写"一个穿白衣服的女孩在雪里跑"，3 镜头后衣服变米色、发型变短。
✅ 稳住：资产卡出 `C01` 三视图 → 每镜头 `@[Character: C01]`，衣服 / 发型 / 银链全程不变。
