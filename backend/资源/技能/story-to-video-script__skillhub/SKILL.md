# Story To Video Script

## Overview

把小说段落 / 故事文本转换为"直接拿去小云雀（Seedance 2.0 / 2.5）生成视频"的生产包。输出一份纯 Markdown 文档，包含三部分核心产物：角色 / 场景 / 物品**资产卡**（文生图提示词，建立一致性基底）、**分镜表**（每个镜头的完整生成提示词）、以及贯穿全局的**人物 / 场景一致性方案**。

本 skill 的主战场是"小说段落"输入（非完整剧本、非一句话灵感）。生成前**先做创意简报 intake**：基于故事内容对每个关键问题给 3–4 个预测选项 + 推荐项，用户点选即定稿（问答库见 `references/intake-questions.md`）。模型版本（2.0 / 2.5）在 intake 中必问——两者时长上限与引用语法不同（见 `references/seedance-guide.md` §0），据此自动适配：2.5 用 `@[Character: C01]` 命名标签，2.0 用 `@图片N` 数字引用。

## When To Use（触发条件）

**触发场景**：
- 用户给出小说段落、故事、情节片段，想做成 AI 视频
- 用户提到小云雀 / Seedance / 沉浸式短片 / AI 短剧 / 分镜 / 视频脚本
- 用户表达"故事转视频""小说推文视频""把这段做成片""给我每镜头的提示词"

**输入长度规则（先判定再执行，见 faq.md Q2）**：

| 输入长度（约） | 判定 | 处理方式 |
|---|---|---|
| < 100 字 | 过短（灵感碎片） | 明确提示"输入过短"，给两个选项：① 用户补充细节；② 按"迷你模式"只出 1 个关键镜头 |
| 100 – 800 字 | 标准单集 | 正常五步流水线，产出 1 段（15s/30s）分镜 |
| 800 – 2400 字 | 超单集容量 | 明确提示"内容较长，自动切分为 N 个完整弧线/多集"，每集独立分镜；或请用户圈定重点段落 |
| > 2400 字 | 过长 | 明确提示"超过单次处理上限（2400字）"，请用户分段提供或按章节分批处理 |

**不适用（明确拒绝或先改写，不要硬出结果）**：
- 输入是**完整剧本 / 台词稿**（无画面描写）→ 提示先转写成叙事段落
- 输入是**一句话灵感 / 大纲要点**（非叙事段落）→ 提示先扩写
- 输入是**非叙事内容**（议论文 / 说明文 / 新闻稿）→ 明确不适用，不要强行分镜
- 用户要的是**单张图片 / 纯文案 / 图文笔记**而非视频 → 不触发本 skill

## Platform

小云雀（字节剪映团队出品）网页版 `xyq.jianying.com` 或 App，视频模型 **Seedance 2.0 / 2.5**（生成前问用户选哪个）。入口：创作 → 模式 → **沉浸式短片（Seedance 2.0 / 2.5）**。平台能力边界、版本差异、黄金公式、引用语法、时间戳、动态参数与铁律摘要见 `references/seedance-guide.md`，必须逐条遵守。

## Workflow

输入以"小说段落"为主。按五步流水线执行，每一步的产物都进入最终 Markdown 生产包。

### Step 1 — 创意简报（选项式预测 intake）

用户先给故事内容（小说段落）。收到后**先快速通读解析**（人物 / 场景 / 情节 / 情绪基线），然后对每个 intake 问题给出 **3–4 个从段落推断的预测选项 + 1 个推荐项**（附一句话理由，如"因为段落里是雪夜复仇戏"），用**大白话**表述，专业词后跟括号解释。用户点选 / 修改 / 跳过（跳过即用推荐项，生产包标注"（默认）"）。

intake 问题（一张表呈现，别一问一答）：
1. 视觉风格 / 画风
2. 视频目的 + 想让观众留下的情绪
3. 发布平台 / 画幅比例
4. 模型版本（2.0 / 2.5，必问）
5. 节奏偏好
6. 是否对白 + TTS 口型同步 + 对白语言
7. 音乐 / 音效偏好
8. 参考图（可选，一致性外挂）

完整问答库、预测规则与"选项→提示词参数"映射见 `references/intake-questions.md`。确认后把答案翻译成提示词参数（风格前缀 / 基调 / 比例 / 时长 / 运镜档位 / 声线），写进生产包"制作参数"。
**跳过处理**：Q4 版本必问、无默认值，跳过则停下追问（见错误处理 E2）；Q1–Q3 可跳过，用推荐项并标注"（默认）"，全部跳过时按 E3 提示。

### Step 2 — 解析小说段落

承接 Step 1 的快速通读，做完整解析，从段落中抽取并列出：
- **人物清单**：姓名、年龄感、外貌、服饰、标志物（配饰 / 发色 / 伤疤 / 随身物）
- **场景清单**：地点、时段、天气、光线、氛围
- **物品清单**：推动情节的关键道具
- **情节节拍**：按时间 / 情绪推进拆成连续动作弧线
- **情绪曲线**：开场 → 发展 → 高潮 → 释放

### Step 3 — 生成资产卡（一致性基底）

为每个实体生成文生图提示词，统一编号：`C01..` 角色 / `S01..` 场景 / `P01..` 道具。角色卡给出多角度（正面 / 侧面 / 全身）提示词。每卡包含：文生图提示词 + 一致性锁定描述（供 Step 4 的 @标签 引用）。格式与方法见 `references/consistency-playbook.md`。

### Step 4 — 分镜表（每镜头完整提示词）

把情节节拍拆成镜头序列。每个镜头输出一组字段，最后汇成一条**可直接粘贴进小云雀的最终提示词**：
- 镜头号 / 时间轴（`0-3秒`…）
- 景别 + 运镜（推 / 拉 / 摇 / 移 / 跟 / 环绕 / 希区柯克变焦 / 特写 / 远景）
- 画面描述（具体视觉语言，非"信息堆砌"）
- 对白（标注 `os` 内心独白 / `vo` 画外音 / 带情绪）
- 音效 / 配乐（视听一体，动作节拍配同步音效）
- 动态参数（强度 + 局部动态 + 运镜档位）
- **【最终提示词】**：八维黄金公式 + 时间戳 + 角色/场景引用（**2.5：`@[Character: C01]` / `@[Location: S01]` / `@[Prop: P01]`；2.0：`@图片N` / `@视频N` / `@音频N` 数字引用**）

完整模板见 `references/seedance-guide.md`。

### Step 5 — 一致性方案（头条功能）

输出一份执行清单，把"人物 / 场景不漂移"从口号变成可操作步骤：如何把资产卡图作为参考图上传、如何用 @标签 锁定角色 / 场景 / 运镜风格、风格统一参数怎么填、尾帧续接怎么做、跨镜头一致性自查表。详见 `references/consistency-playbook.md`。

## 错误处理与兜底（不静默失败）

> 原则：**任何"得不到预期结果"的情况，先明确报错，再给兜底方案**，不悄悄输出残缺结果。报错格式统一为：
> `⚠️ [E编号] 描述问题 → 修复方法`。所有错误处理细节见 `references/faq.md`。

| 编号 | 触发场景 | 明确报错提示 | 兜底 / 修复 |
|---|---|---|---|
| **E1** | 版本混用：同一份提示词里同时出现 `@[Character: C01]` 与 `@图片N` | `⚠️ [E1] 版本混用：检测到 2.5 命名标签与 2.0 数字引用同时出现，引用语法必须全包统一` | 停下，回到 Step 1 Q4 重新确认版本，按所选版本**整体重写**全部引用 |
| **E2** | 用户跳过版本问题（Q4 必问） | `⚠️ [E2] 模型版本未确认：Q4 无默认值，禁止跳过` | 停下追问版本；用户不选就不继续产出 |
| **E3** | 用户跳过多项关键问题（Q1–Q3） | `⚠️ [E3] 以下必问项已跳过，将使用推荐默认值（生产包已标注"默认"）：Q1 风格 / Q2 情绪 / Q3 平台` | 正常产出但每个默认项都标注；产出末尾附一行"如需更贴合，可补充修改 XX 项后重跑" |
| **E4** | 输入过短（< 100 字） | `⚠️ [E4] 输入过短（约 N 字），不足以支撑完整分镜` | 给两选项：① 用户补充细节；② 迷你模式只出 1 个关键镜头 |
| **E5** | 输入过长（> 2400 字） | `⚠️ [E5] 输入过长（约 N 字），超过单次上限 2400 字` | 自动切分多集并告知；或请用户分段提供 |
| **E6** | 输入类型不符（剧本 / 灵感 / 非叙事） | `⚠️ [E6] 输入不是小说段落：当前为[剧本/灵感/说明文]，本 skill 只处理叙事段落` | 按 When To Use"不适用"分支处理：提示改写或拒绝 |
| **E7** | 资产卡编号与分镜引用对不上 | `⚠️ [E7] 一致性检查失败：分镜引用了 C03 但资产卡只有 C01–C02` | 交付前跑质量检查清单（seedance-guide §10），补卡或改引用，保证编号一一对应 |

**兜底总原则**：报错后必须给出可执行的下一步（选项式），不让用户面对空结果；报错不阻塞时（E3 属"可继续"），照常产出但显式标注。

## Output Format

产出一份纯 Markdown 生产包（便于复制粘贴进小云雀），结构固定为：

```
# [标题] — 视频生产包

## 一、故事解析
核心梗 / 梗概 / 情绪曲线

## 二、制作参数
风格 / 目的情绪 / 平台比例 / 版本 / 时长 / 节奏 / 对白 / 音乐（用户跳过的标"默认"）

## 三、资产卡
### 角色 C01..  (文生图提示词 + 一致性锁定描述)
### 场景 S01..
### 物品 P01..

## 四、分镜表
| 镜头 | 时间轴 | 景别运镜 | 画面描述 | 对白 | 音效 | 动态参数 | 最终提示词 |
(每个镜头一条完整最终提示词)

## 五、一致性执行方案
参考图上传顺序 / @标签 用法 / 风格统一参数 / 尾帧续接 / 自查表
```

## Iron Rules（生成任何提示词前必须逐条核对）

- 每个分镜 prompt **开头第一句**固定写：`画面无任何字幕。`
- 对白**按时间点嵌入时间轴**对应秒数；【声音】块只放声线 / 配乐 / 音效，不堆对白
- 时长核对：`对白句数 × 1.3s + 画面节拍数 × 0.8~1.5s`；密集场景（9+ 节拍 / 6+ 对白）拆成 2 段
- 抽象词量化（`梦幻 = 低饱和 + 软光源 + 长焦压缩`），要去掉某效果写"无 X"
- 审核规避：删负面词改正向描述；"年龄 + 性别"组合中性化（用"年轻女孩"替"15岁少女"）
- 动作避坑：用"摔 / 取 / 递"替"掰断 / 剥瓣"等易崩形变动作
- 视听语言：用景别 / 运镜 / 光影 / 构图 / 节奏 / 蒙太奇服务情绪，详见 `references/cinematic-techniques.md`
- 一致性：含人物的镜头必须引用角色资产卡（**2.5：`@[Character: Cxx]`；2.0：`@图片N`**）；场景必须引用场景资产卡

完整铁律与模板见 `references/seedance-guide.md`；一致性专项见 `references/consistency-playbook.md`。
