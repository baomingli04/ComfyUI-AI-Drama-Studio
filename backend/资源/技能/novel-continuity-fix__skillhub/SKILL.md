# 小说章节衔接问题检查与修正

## 触发条件
当用户发现小说某章节与前文衔接不上、提到前文未发生的情节、或需要修正章节开头与前一章结尾的衔接时触发。

## 工作流程

### 1. 定位问题
- 读取用户指定的章节文件
- 识别问题句子（如"价格战""赢了官司"等前文未出现的情节）
- 提取前文最后一章的结尾内容

### 2. 检查前文
- 使用Grep搜索全文，确认是否确实缺少该情节
- 如果全文存在该情节但距离较远，说明是衔接不当，需要修正当前章节的表述
- 如果全文都不存在该情节，说明是作者错误，需要删除或改写该表述

### 3. 修正当前章节
- 将突兀的表述改为与前一章结尾直接衔接的内容
- 确保不再暗示前文未发生的情节
- 保持古风格式（不使用双引号、不使用破折号；对话提示可用冒号，但不可使用冒号+双引号组合）
- 保持人物行为一致

### 4. 检查全文残留
- 使用Grep再次搜索问题关键词，确保当前章节已无任何相关残留
- 检查是否还有其他类似问题

### 5. 更新报告和记忆
- 更新该章节的修改报告
- 在工作日志中追加修正记录
- 说明前文是否真实存在该情节，以及为什么需要修正

### 6. 字数检查（如需要）
- 如果修正后字数不足，补充符合规划的内容
- 目标：≥4900字（本项目标准）

## 常见衔接问题及修正方法

### 问题1：当前章节开头提到前文未发生的具体事件
**示例**：第25集开头"打赢价格战之后"，但第24集没有价格战。
**修正**：改为"向长安寄送样品之后"，因为第24集确实在布局长安。

### 问题2：当前章节暗示前文有某种竞争/冲突，但前文没有
**示例**："他们下一次不会再走价钱这条路"
**修正**：改为"他们下一次不会再走明面上的路子"，避免暗示价格战。

### 问题3：地名不一致
**示例**：前文说"长安"，当前章节突然说"京城"
**修正**：统一为"长安"

### 问题4：人物状态不一致
**示例**：前文人物受伤，当前章节突然行动如常
**修正**：补充恢复过程的描写，或调整当前章节的情节

### 问题5：新对手/新势力突然出现，前文无铺垫
**示例**：第25集正文多次出现"宋家工坊"，但正式修改版1-24集中从未出现宋家工坊与林家的正面冲突，仅在备份/旧版文件中出现。
**修正**：
1. 使用Grep在正式章节（已完成/1-15、已完成/16-30等）中搜索该对手名称
2. 如果正式章节中无铺垫，则不应在当前章节提前引入该对手
3. 将其替换为前文已有充分铺垫的对手（如许炎昱）或泛化表述（如"长安世族"）
4. 替换后再次搜索，确保当前章节不再残留该未铺垫对手名称

### 问题6：新角色/人名突然出现，前文无铺垫
**示例1**：第26集突然提到"阿福是澜兮新提拔的账房先生"，但第25集及之前从未铺垫此角色；且"阿福"一名已在第9/11/18集中用于反派许炎昱/谢晖烟的心腹。
**示例2**：第25集突然让"淮歆编入随行护卫队伍"，但规划文件中淮歆应在第37集才初遇刃暮，此前正式修改版中从未出现淮歆。
**修正**：
1. 使用Grep搜索该人名，确认是否在前文正式修改版中出现过
2. 对照规划文件，确认该角色的出场集数是否早于设定
3. 如果未铺垫、人名冲突、或出场时间早于规划，则不应在当前章节突然引入
4. 将其替换为前文已有铺垫的人物，或删除该角色，或改为泛化表述
5. 替换后再次搜索，确保当前章节不再残留未铺垫人名

### 问题7：地点/背景设定突然出现，前文无铺垫
**示例**：第26集出现"从益州到苏州""见过益州的古朴"，但大纲明确林澜兮为"苏州缂丝商人之女"，且1-25集正式修改版中从未铺垫三兄妹有在益州生活的经历。该设定与第28、29集中的"益州市集""在益州的时候"等描述共同构成背景冲突。
**修正**：
1. 使用Grep搜索该地点名，确认是否在前文正式修改版、大纲、规划文件中出现过
2. 如果前文无铺垫，或该地点设定与大纲/人物体系矛盾，则不应在当前章节突然引入
3. 将其替换为已有铺垫的地点（如苏州、杭州、扬州、长安），或改为泛化表述（如江南、南方）
4. 替换后再次搜索，确保当前章节不再残留该未铺垫地点
5. 若同一地点在后续章节也有类似错误，应一并检查修正

### 问题8：跨集人物关系进度矛盾
**示例**：第28集诗凰已与欧阳澜多次对话（知道名字、家世，澜兮还让她"继续接触"），但第34集却说"第一次和欧阳澜正式说上话"，两集直接冲突。
**修正**：
1. 对照规划文件，确认该人物的出场进度安排（初遇→再遇→正式合作→感情线确立）
2. 确定哪一集是"正式说上话"的节点，将前文中的直接对话降级为"远远看到""微微一笑""从旁人处打听名字"等非接触描写
3. 同步修改后文中的过渡句（如"一直没见过本人"→"远远见过几次但没正式说上话"）
4. 注意修正性别代词（如欧阳澜为男性，不应使用"她"）
5. 修正后通读两集相关段落，确认进度衔接合理

## 注意事项
- 检查时要区分"正式修改版文件"和"备份/旧版文件"，不应以备份文件中的情节作为当前正文的依据
- 修正时要保留原文的核心信息（如林家名声高涨、需要北上等）
- 不要完全删除重要情节，而是改写为与衔接合理的情节
- 修正后必须再次搜索问题关键词，确保彻底清除
- 如果前文确实存在该情节，要向用户说明，避免造成误解

## 工具使用
- Read：读取章节文件和前文结尾
- Grep：搜索问题关键词和前文情节
- Edit：修改具体问题
- Write：生成/更新修改报告
- Bash：统计字数

## 输出
1. 修正后的章节文件
2. 更新后的修改报告
3. 工作日志记录
