## 核心工作流

### 1. 接收原稿 → 快速评估

拿到原稿后，先判断格式和问题：

| 指标 | 判断标准 | 行动 |
|---|---|---|
| 格式 | 剧本体（含`（动作）`、`【内心OS】`、角色名前缀）/ 小说叙事体 | 剧本体→先转小说体；小说体→直接进入后续 |
| 字数 | 目标字数 vs 当前字数 | 差异 > 500字 → 扩写或精简 |
| 已知问题 | 用户是否明确要求"检查逻辑/重复/流畅" | 是 → 执行三步检查 |

### 2. 剧本 → 小说叙事体转换规则

将剧本格式要素转为自然叙述：

| 剧本要素 | 转换方法 | 示例 |
|---|---|---|
| `（动作/动作描写）` | 消化为叙事段落，用句号衔接 | `（动作）苏念念拿起茶杯。` → "苏念念拿起茶杯，喝了一口。" |
| `【内心OS】` | 转为第三人称内心描写或自由间接引语 | `【内心OS】他在附近。` → "他在附近。她心想。" |
| `角色名：（台词）` | 转为"她说/他开口/问/接话"等对话标签 | `苏念念：你来了。` → "苏念念说：'你来了。'" |
| `【场景X】` 或 `场景X` | 转为场景标题，用**深色加粗**标注 | `【场景1】MOON工作室` → `**MOON工作室　设计区 — 傍晚**` |
| `旁白：（约10秒）` | 直接合并到末尾叙事段落 | |

**对话标签规则：**
- 连续对话 → 前两轮带标签，后续用动作/神态区分谁在说话
- 避免重复使用同一标签（"说道""开口道""接过话"交替使用）
- 对话中断/沉默 → 用破折号或省略号+动作描写替代标签

### 3. 逻辑核查清单

逐场景检查以下维度：

| 维度 | 检查项 | 典型问题 |
|---|---|---|
| 角色一致性 | 角色关系前后是否矛盾？称呼/名字是否写错？ | "比他哥哥陆子珩还可怕"——陆子珩就是他本人，不是他哥 |
| 信息源 | 角色如何知道某个秘密/计划/产品名？是否需要补"行业风声/情报/线人"？ | 陆子珩如何知道未发布的"星河流转"→ 补"走漏风声" |
| 时间线 | 多场景并行时角色能否同时出现在两地？是否需要补充"已提前赶来"？ | 宋初夏在MOON开完会→出现在顾氏会议室→补"已提前赶来" |
| 空间合理性 | 角色如何进入某个场所？是否需要补充门禁/通行证/工作人员认得？ | 顾言深深夜进入MOON工作室→补"有门禁卡"；进入发布会后台→补"没人拦" |
| 用词准确性 | 术语/场景词是否用对？ | "当庭出示"→发布会不是法庭→改"当场出示" |
| 情节漏洞 | 未出场人物突然出现？情节转折缺乏铺垫？ | 霍霆骁未在剧本中出现但末尾出现签字→改为陆子珩 |

**优先级：** 角色一致性 > 信息源 > 时间线 > 空间合理性 > 用词准确性 > 情节漏洞

### 4. 去重检查

检查以下重复模式，每种最多保留1-2次：

| 模式 | 示例 | 处理方法 |
|---|---|---|
| 动作重复 | "推了推眼镜"出现3次 | 保留前2次，删除第三次 |
| 外貌描写重复 | "侧脸轮廓"、"侧脸的线条"出现多次 | 保留最佳那次，其余删或改为正面描写 |
| 句式重复 | "像是……"句式连续出现4次 | 2处改为直接陈述，保留2处 |
| 时间描述重复 | "几天后"、"沉默了几秒"在不同场景一致 | 首次用"顿了顿"，二次用"沉默了片刻" |
| 对话标签重复 | "说""说道"连续出现 | 用"接话""开口""声音低沉"等交替 |
| 副词/程度词堆砌 | "突然""忽然""猛地"连续出现 | 间隔使用，或改为动作本身表达突发性 |
| 场景过渡重复 | "---"分隔符+时间提示相同句式 | 统一格式但微调措辞 |

### 5. 字数控制策略

#### 扩写（目标字数 > 当前字数）

按优先级扩充以下位置：

| 优先级 | 场景类型 | 扩写方法 | 预计增幅 |
|---|---|---|---|
| 高 | 情感对手戏（两人独处） | 加入内心活动、回忆闪回、微动作描写 | +200-500字/场 |
| 高 | 高潮/冲突段落 | 强化感官描写（光线/声音/触觉）、拉长节奏 | +200-400字/场 |
| 中 | 配角登场 | 加入配角独特性格暗示、与主角的历史关系 | +100-200字/人 |
| 中 | 空场景过渡 | 加入环境描写、器物细节、城市氛围 | +100-200字/场 |
| 低 | 纯对白段落 | 对话间隙加入停顿、呼吸、视线变化 | +50-150字/场 |

**不要扩充：** 已经完整的金句（如"并肩""相信我"）、无意义的修辞堆砌、重复已有观点的内心独白。

#### 精简（目标字数 < 当前字数）

按优先级压缩以下位置：

| 优先级 | 切除内容 | 预计减量 |
|---|---|---|
| 高 | 过长的内心独白（同一观点重复3次以上） | -200-400字 |
| 高 | 配角对白的展开（非必要信息） | -100-300字 |
| 中 | 环境描写的二次重复（同一场景的不同角度） | -100-200字 |
| 中 | 对话中多余的语气词和来回 | -50-150字 |
| 中 | 动作描写的过度细化 | -50-100字 |
| 低 | 过渡段落的冗余 | -50-100字 |

**保留：** 核心对白、关键金句、高潮段落、所有情节点。

### 6. 场景标注规范

输出格式统一：

```
**场景名称　细化地点 — 时间**

[叙事内容]

---

**下一场景名称　细化地点 — 时间**
```

- 场景名：**深色加粗**
- 地点和时间用" — "（空格+破折号+空格）分隔
- 场景之间用 `---` 全宽分隔
- 不使用数字前缀（一、二、三 或 1. 2. 3.）

### 7. 交付物格式

最终输出规范：

- 标题：`**第X集　[集名]**`
- 每个场景：`**场景名　地点 — 时间**`
- 场景间：`---`
- 末尾：`**【第X集完】**`

### 9. 情绪与情节掌控

适用于所有类型小说，写作时逐场检查：

| 检查维度 | 具体要点 | 常见问题 |
|---|---|---|
| 人物情绪准确性 | 角色在该处境下的情绪反应是否符合性格？是否有铺垫？ | 反派突然善意毫无铺垫；主角遇险内心毫无波动 |
| 动人心弦的桥段 | 是否有"克制比爆发更打动人"的瞬间？ | 全程咆哮式情绪，缺少内敛的强力时刻 |
| 细节描写增强情感深度 | 用器物/环境/微动作承载情绪，而非直接说"他很伤心" | "他很难过"→改为"他盯着桌上凉透的茶，手指在杯沿划了一圈又一圈" |
| 故事反转的合理性 | 反转是否有伏笔？读者回看能否找到线索？ | 机械降神式反转，前期毫无暗示 |

**情绪描写优先级：** 微动作 > 环境映衬 > 内心独白 > 直接陈述情绪词

### 10. 句式节奏技巧

适用于所有类型，根据场景情绪选择句式：

| 技巧 | 用法 | 示例 |
|---|---|---|
| 感叹句 | 表达强烈情感、强调转折点 | "这一次，她不会再逃了！" |
| 反问句 | 强化情绪、引导读者共鸣 | "他怎么能这样？" |
| 排比句式 | 增加节奏感、层层递进情绪 | "她恨他的欺骗，恨他的消失，更恨自己还在等。" |
| 断句技巧 | 突出剧情转折、制造停顿感 | "门开了。不是他。" |
| 短句密集 | 强调情节紧张、加快节奏 | "他冲上去。一拳。又一拳。" |
| 长短句交替 | 控制节奏，长句放缓、短句加速 | 长句描写环境→短句切入动作→读者呼吸感随之变化 |

**节奏匹配原则：**
- 高潮/冲突 → 短句为主，断句多
- 情感/回忆 → 长句为主，描写细腻
- 对话密集段落 → 穿插动作/神态描写，避免纯对话墙

### 11. 付费点与节奏结构

适用于网文/爽文/微短剧，按六段式结构规划每集/每章：

```
导语（钩子）
  ↓
起章（铺垫/日常/现状）
  ↓
承接（矛盾积累/压力上升）
  ↓
付费点（最大悬念/情绪最高点，截断）
  ↓
转折（反转/揭秘/爽点释放）
  ↓
合（收束/新悬念引出下集）
```

| 结构位 | 功能 | 写作要点 |
|---|---|---|
| 导语 | 用最强悬念/最爽瞬间做开头，吸引继续读 | 直接放高潮片段，"她当众把离婚协议拍在桌上——" |
| 起章 | 建立常态，让读者代入主角处境 | 不拖沓，3-5段内进入第一个冲突 |
| 承接 | 矛盾升级，压迫感持续叠加 | 每场结束比开场更糟，不给喘息 |
| 付费点 | 截断在情绪最高点，制造"必须看下一集"的冲动 | 主角即将反击却突然—— / 真相即将揭晓却—— |
| 转折 | 爽点释放，读者等待已久的回报 | 不能太轻易，要有"酝酿-爆发-余韵"三层 |
| 合 | 解决当前矛盾，但埋下更大危机 | 每次"合"都是下一个循环的"起" |

**微短剧适用：** 每集末尾必须是付费点位置，集与集之间用"合+新悬念"衔接。

### 12. 故事灵感激发方法

适用于创作前期头脑风暴，帮助用户克服创作障碍：

**核心工作流：**

| 步骤 | 内容 | 输出 |
|---|---|---|
| 1 | 分析用户需求，明确故事类型和主题 | 类型定位（古言/都市/悬疑/科幻等） |
| 2 | 提供多种故事构思，每个构思都有独特视角 | 3-5个备选构思，含核心设定 |
| 3 | 引导思考角色和情节设定 | 主角设定草图+主要冲突方向 |
| 4 | 提供写作技巧建议 | 针对选定类型的技巧提示 |
| 5 | 鼓励分享创作，提供反馈和进一步灵感 | 迭代优化后的最终构思 |

**构思生成方法：**

| 方法 | 说明 | 示例 |
|---|---|---|
| 现实+幻想融合 | 在现实背景下加入一个超自然元素 | 普通上班族意外能看到别人的"好运值" |
| 类型交叉 | 将两个不相关的类型元素组合 | 规则怪谈 + 职场文 = 办公室生存规则 |
| 视角翻转 | 从反派/配角/旁观者视角重写经典套路 | 替身文学从正主视角写 |
| 现实事件改编 | 将新闻/社会事件小说化 | 结合真实案件改写成悬疑短篇 |
| 一句话反转 | 先想结局，再反推设定 | 结局：一切都是主角的梦 → 设定：他在 coma 中构建了整个世界 |

**输出格式（每个构思）：**
```
【构思X】
- 类型：
- 核心设定（一句话）：
- 主角：
- 主要冲突：
- 独特视角（why it's fresh）：
```

### 13. 规则怪谈创作方法

适用于规则怪谈/无限流/副本类小说，核心是**规则体系设计**。

**规则设计原则：**

| 原则 | 说明 | 反例 |
|---|---|---|
| 诡异但有逻辑 | 规则看起来奇怪，但有内在规律可推 | 规则之间毫无关联，纯随机 |
| 隐藏关键信息 | 规则字面意思之外，暗含真相线索 | 规则直接把真相说出来 |
| 违反后果明确 | 读者知道违反规则会发生什么 | 违反规则后什么事都没发生 |
| 看似矛盾 | 两条规则表面冲突，实则指向更深真相 | 规则之间完全和谐无任何张力 |

**标准工作流：**

```
1. 确定背景 → 时间/地点/基本世界观（公寓/学校/医院/游轮等）
2. 设计规则体系 → 至少5条，含1-2条隐藏线索的规则
3. 构建剧情框架 → 主要发展脉络 + 3个关键转折点
4. 角色设定 → 主角（背景/性格/能力）+ 配角（至少1个知情人NPC）
5. 金手指设计 → 独特且合理，有一定限制（不能太无敌）
6. 副本设计 → 主副本 + 2-3个小副本，难度递增
7. 细节填充 → 悬疑元素 + 恐怖元素（适度，不血腥）
8. 结局设计 → 出人意料又合理，给出规则起源的解释
9. 检查调整 → 逻辑自洽性 + 规则之间无矛盾
```

**规则写作示例：**
```
【幸福公寓入住规则】

1. 租期为30天，期满后若想续租，请在午夜12点前敲响房间内的铜铃三次。
2. 每天早上7点到晚上9点可以自由出入公寓，其他时间禁止离开房间。
3. 公寓内禁止使用任何通讯设备，违者将被立即驱逐。
4. 每晚10点会有管理员查房，请务必应声，但不要开门。
5. 如果听到走廊有脚步声，请立即关灯并躲在被窝里，直到脚步声消失。
6. 浴室的镜子每周二会自动更换，更换期间请勿进入浴室。
7. 公寓内的其他租客都很友好，但请不要主动与他们交谈。
```

**金手指设计要点：**
- 有限制（使用次数/冷却时间/代价）
- 与规则世界有某种特殊联系（主角身世/过去经历）
- 不能完全破解规则，只能提供线索或缓冲

### 14. 换元法创作方法

适用于在现有套路基础上创新，避免抄袭同时保证读者接受度。

**故事源分类：**

| 故事源 | 含义 | 示例 |
|---|---|---|
| 事件源 | 情节/冲突/事件的设计来源 | "替身离婚后发现前夫追悔莫及" |
| 结构源 | 故事结构/节奏/框架的来源 | "先虐后爽"的三幕式结构 |
| 主体源 | 核心主题/思想的来源 | "女性自立"的主题 |
| 背景源 | 世界观/时代背景的来源 | "豪门世家"的背景设定 |
| 人物源 | 角色设定/性格的来源 | "冷漠霸总"的人物模板 |
| 道具源 | 关键物品/金手指的来源 | "空间仓库"的金手指设定 |

**一度置换（入门）：**

| 要素 | 说明 |
|---|---|
| 定义 | 只替换故事源中的一个元素，其他保持不变 |
| 操作方法 | 选定故事源 → 替换其中一个维度 → 检查新组合是否自洽 |
| 注意事项 | 替换后要保持逻辑自洽；优先替换最核心的那个源；不能为了换而换 |

**二度置换（进阶）：**

| 要素 | 说明 |
|---|---|
| 定义 | 同时替换两个故事源元素，或在一度置换基础上再置换一个 |
| 操作方法 | 先完成一度置换 → 评估效果 → 再置换第二个元素 |
| 注意事项 | 两次置换要有内在联系；避免元素之间冲突；二度置换后复杂度增加，需重点检查自洽性 |

**换元示例：**

```
原作：《霸道总裁爱上我》
事件源：霸总爱上普通女孩
→ 一度置换（换背景源）：霸总爱上普通女孩，但背景换成仙侠世界
→ 二度置换（换人物源）：仙侠版霸总（天界战神）爱上妖族公主

原作：《重生之我在豪门当保姆》
事件源：重生+豪门+保姆
→ 一度置换（换道具源）：重生+豪门+保姆，但金手指换成"能听见别人心声"
→ 二度置换（换结构源）：以上设定，但结构换成"规则怪谈"模式
```

**高级应用：**

| 技巧 | 说明 |
|---|---|
| 元素融合 | 将不同故事源的元素有机融合，不是简单拼接 |
| 元素创新 | 在换元基础上加入独创心机点，形成"老套路+新设定" |
| 强化独特元素 | 换元后重点强化最独特的那个元素，让它成为记忆点 |

### 15. 科幻小说创作方法

适用于硬科幻/软科幻/宇宙文明题材，核心是**科幻概念的可读性表达**。

**六步工作流：**

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1 | 设计科幻概念 | 结合科学原理+哲学思考+文化背景；概念要能推动情节 |
| 2 | 设计叙事框架 | 宏大背景（时间跨度/空间尺度）；清晰的结构脉络 |
| 3 | 设计科幻设定 | 当前科学中不存在，但在故事逻辑下合理；要有详细原理说明 |
| 4 | 设计人物 | 外貌/性格/背景经历/欲望与冲突/角色关系 |
| 5 | 设计表达方法 | 如何在正文中让读者理解概念和设定（最关键的一步） |
| 6 | 输出大纲+正文 | 先大纲（开放式结尾）→ 用户确认 → 生成正文 |

**科幻概念表达方法（第5步详解）：**

| 方法 | 说明 | 示例 |
|---|---|---|
| 通过科学实验表现 | 让角色做实验，读者通过实验过程理解设定 | 主角用粒子对撞机验证"时空折叠"理论 |
| 通过科学观测表现 | 让角色观测现象，逐步揭示设定 | 天文学家通过望远镜发现星系异常，逐步揭示暗物质设定 |
| 侧面描写 | 通过人物反应/社会变化间接表现设定 | 不直接解释"意识上传"，而是通过"他看着自己的克隆体走进会议室"来表现 |
| 正面描写 | 通过角色对话/内心思考直接解释设定 | 两个科学家对话，逐步解释"量子永生"的原理 |
| 留白技巧 | 只讲述开头和结尾，中间过程留给读者想象 | 直接展现"发射前"和"到达后"，省略航行过程 |

**叙事框架设计要点：**

| 维度 | 说明 |
|---|---|
| 时间跨度 | 可以是数十年、数百年甚至数千年，展现文明兴衰 |
| 空间尺度 | 从地球到太阳系到银河系到宇宙深处 |
| 哲学深度 | 不仅写科技，更写人类/文明/宇宙的本质问题 |
| 科学严谨性 | 引用真实物理学/数学/宇宙学理论，不胡编 |
| 文化融合 | 融入中国文化元素，同时具备国际化视野 |

**人物塑造技巧：**
- 通过动作/习惯/对话/决策/环境描述体现性格（少直接陈述）
- 粗略讲述部分使用留白技巧
- 配角也要有独立动机，不只是主角工具人

### 16. 末世囤货文创作方法

适用于末世/灾难题材，核心是**真实感+紧迫感**。

**五步工作流：**

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1 | 设定末世起因 | 病毒/环境灾难/外星入侵/科技失控；可加入新颖元素 |
| 2 | 塑造角色 | 主角需具备生存技能/资源管理能力；可加入特殊能力（有限制） |
| 3 | 描述囤货过程 | 物资类型/优先级/获取方式；最体现专业性的部分 |
| 4 | 构建紧张情节 | 一系列灾难事件；主角在危机中成长 |
| 5 | 细节描写 | 环境+心理，增强真实感和代入感 |

**囤货清单模板（按优先级）：**

| 优先级 | 类别 | 具体物资 | 备注 |
|---|---|---|---|
| 最高 | 饮用水 | 瓶装水/净水片/滤水器 | 人3天不喝水会死 |
| 最高 | 食物（耐储存） | 压缩饼干/罐头/米/面/真空包装食品 | 计算卡路里，至少备3个月量 |
| 高 | 药品 | 抗生素/止痛药/消毒用品/慢性病药物 | 考虑过期时间 |
| 高 | 能源 | 电池/太阳能板/打火机/燃料 | 电力是文明的基础 |
| 中 | 工具 | 多功能刀/绳索/手电/收音机 | 工具比武器更实用 |
| 中 | 防卫 | 合法范围内的大脑武器/警报器 | 遵守现实法律 |
| 低 | 种子/养殖 | 速生蔬菜种子/可食用昆虫幼虫 | 长期生存考虑 |
| 低 | 精神物资 | 书籍/娱乐设备/酒 | 末世中精神健康同样重要 |

**情节构建要点：**

| 要素 | 说明 |
|---|---|
| 灾难渐进性 | 不要一开始就是全面崩溃，要有"预警期→局部混乱→全面灾难"的三段式 |
| 主角成长弧 | 从普通人→生存者→领导者/希望象征 |
| 道德困境 | 资源有限时的分配问题、救不救陌生人等 |
| 反派设计 | 不是丧尸/怪物，而是"另一个生存者"，增加人性冲突 |

**真实感保障：**
- 遵守现实物理规律（不能出现魔法/超能力无代价）
- 角色行为和心理合理可信（恐慌/自私/利他并存）
- 资源管理符合现实（物资会过期/消耗/需要维护）

### 17. 知乎短篇小说创作方法

适用于知乎/微信公众号等平台的超短篇（3000-8000字），核心是**高密度情节+强结尾**。

**六段式结构（与第11节呼应，更精简）：**

```
导语（钩子·50-100字）
  ↓ 必须读完第一句就被抓住
起章（建立常态·300-500字）
  ↓ 介绍主角和现状，暗示不对劲
承接（矛盾积累·500-800字）
  ↓ 压力持续叠加，读者开始焦虑
付费点（截断·在情绪最高点）
  ↓ 知乎文一般不分集，但要有"中间停顿感"
转折（反转/揭秘·800-1200字）
  ↓ 爽点释放，前面所有铺垫在这里回报
合（结尾·200-500字）
  ↓ 结局要出人意料又合理，前后呼应
```

**超短篇特殊要求：**

| 要求 | 说明 | 检查方法 |
|---|---|---|
| 结局反常规 | 生活中不常见的结局，但不能是机械降神 | 问：这个结局在现实中出现概率有多大？ |
| 前后呼应 | 结尾要呼应开头或中间某个细节 | 检查：结尾是否有"哦！原来开头那个细节是这个意思"的感觉 |
| 对话揭示性格 | 每句对话都要推动情节或揭示人物 | 删除任何"纯粹寒暄"的对话 |
| 细节生动 | 用具体细节而非抽象描述 | "她很伤心"→"她把手机里他的照片一张张删掉，手在发抖" |
| 情感真实 | 结局可以离奇，但人物情感反应要真实 | 检查：角色在该处境下的情绪反应是否符合人性 |

**知乎文写作检查清单：**

```
□ 开头第一句是否能当钩子？
□ 全文是否在8000字以内？
□ 是否有"转折点"让读者"卧槽"？
□ 结尾是否前后呼应？
□ 是否有至少一处细节描写让读者有画面感？
□ 对话是否每一句都有用？
□ 主角的欲望/目标是否清晰？
□ 是否避免了"解释性段落"（用动作/对话代替）？
```

### 18. 脑洞文创作方法

适用于脑洞文/反套路/系统文，核心是**在传统题材中融入新颖元素**。

**脑洞文五大创作方向：**

| 方向 | 说明 | 示例 |
|---|---|---|
| 传统文+脑洞元素 | 在重生/穿越中融入特殊金手指或反套路情节 | 重生后发现自己重生在小说里，而且是炮灰角色 |
| 特定爽点探索 | 设计独特的"返还/翻倍/复制"类系统 | "百倍返还"：送别人100元，系统返还10000元 |
| 戏剧性强化 | 加入荒诞/戏谑元素，保持趣味同时引发深思 | 主角骂系统，系统真的生气了并罢工 |
| 成熟题材创新 | "脑洞+"形式，在已有题材上叠加新设定 | 豪门总裁文 + 规则怪谈 = 总裁必须遵守的奇怪公司规则 |
| 灵感寻找法 | 极端法/相反法/联系法，寻找新颖脑洞 | 极端法：把"迟到"极端化成"迟到1秒世界毁灭" |

**脑洞设计检查清单：**

```
□ 脑洞是否有新意？（不是直接抄现有热门设定）
□ 脑洞是否与情节推动有关？（不是装饰性金手指）
□ 脑洞是否有合理限制？（不能太无敌，否则没有冲突）
□ 脑洞是否能引发读者"卧槽"反应？
□ 脑洞是否符合目标读者喜好？
```

**反套路情节设计：**

| 传统套路 | 反套路脑洞 | 效果 |
|---|---|---|
| 替身离婚后男主后悔 | 替身根本不想离婚，是男主求她离 | 反转读者预期 |
| 重生复仇打脸 | 重生后发现上辈子仇人其实是在保护她 | 反转+情感深度 |
| 系统发布任务 | 系统本身就是反派，任务目的是害主角 | 增加悬念和危机 |

### 19. 女频虐文创作方法

适用于耽美虐文/狗血虐文/言情虐文，核心是**情绪强度和细节真实感**。

**专属词汇与句式（直接套用）：**

| 类别 | 具体用法 |
|---|---|
| 生活化词汇 | 婆婆/公公/家庭/吵架等贴近生活的词 |
| 情感色彩词汇 | 痛苦/绝望/心碎/悲痛欲绝/肝肠寸断 |
| 感官描写 | 眼泪潸然落下/心如刀绞的痛苦/指尖发凉 |
| 程度副词 | 非常/极度/痛彻心扉/撕心裂肺 |
| 句式技巧 | 感叹句/反问句/排比/断句/短句（与第10节呼应） |

**情绪与情节掌控（虐文专用）：**

| 维度 | 要点 | 示例 |
|---|---|---|
| 准确把握人物情绪 | 每个情绪转折点都要有铺垫 | 突然崩溃 → 前面3场要有暗示（手抖/失眠/走神） |
| 动人心弦的桥段 | "克制比爆发更打动人" | 她没有哭，只是把他的照片放进了抽屉最深处 |
| 细节描写增强深度 | 用器物/环境承载情绪 | 他看着桌上凉透的茶，手指在杯沿划了一圈又一圈 |
| 故事反转 | 虐文反转要"合理但出乎意料" | 读者知道真相后，回头看前面的细节会心碎 |

**六段式结构（虐文版）：**

```
导语（钩子·情绪向）
  ↓ 第一句就要让读者"心一紧"
起章（建立常态·暗藏危机）
  ↓ 表面平静，但读者能感觉到"要出事"
承接（压力叠加·一步步推向绝望）
  ↓ 每场比前一场更糟，读者开始"心疼"
付费点（截断在情绪最高点）
  ↓ 主角即将崩溃/真相即将揭晓/两人即将错过——
转折（反转/释怀/报复）
  ↓ 爽点释放，但虐文里"甜"要克制，不能太多
合（结局·出人意料但合理）
  ↓ 结局要违背真实生活（大团圆/彻底BE/开放式）
```

**狗血虐文专属剧情元素：**

| 元素 | 说明 | 使用示例 |
|---|---|---|
| 误会 | 核心冲突来源，但要合理 | 看到他和别的女人进酒店 → 其实是谈工作 |
| 身份差距 | 制造无法在一起的障碍 | 豪门私生子 vs 普通女孩 |
| 家庭阻力 | 父母反对/门不当户不对 | 婆婆处处刁难，但不是脸谱化反派 |
| 疾病/事故 | 制造分离或牺牲 | 她得了罕见病，主动提出分手 |
| 替身/白月光 | 情感冲突升级 | 主角一直是替身，真正的小姐回来了 |

### 20. 奇幻小说创作方法

适用于西幻/东幻/剑与魔法题材，核心是**魔法体系设计+情节三要素**。

**魔法体系设计原则：**

| 原则 | 说明 | 反例 |
|---|---|---|
| 内部逻辑一致 | 魔法规则明确，读者能理解和预测 | 魔法时而强时而弱，没有规律 |
| 有代价/限制 | 使用魔法需要付出代价（体力/寿命/材料） | 魔法无限使用，主角太无敌 |
| 规则在故事中展示 | 通过情节展示规则，而不是直接说明 | 大段文字解释魔法系统 |
| 与角色背景相关 | 魔法能力要与角色经历/性格有关 | 角色会魔法只是因为"设定如此" |

**情节三要素（承诺-进展-回报）：**

| 要素 | 说明 | 奇幻文中的应用 |
|---|---|---|
| 基调承诺 | 开头告诉读者这是什么类型的故事 | "在这个世界里，魔法师必须在18岁时参加天赋测试，失败者将被放逐" |
| 角色弧线承诺 | 告诉读者主角会成长/改变 | "他一开始连最简单的火球术都放不出来" |
| 情节承诺 | 告诉读者故事的核心冲突是什么 | "但他发现自己能看到魔法阵的漏洞，这是前所未有的能力" |

**视角选择：**

| 视角 | 适用场景 | 优缺点 |
|---|---|---|
| 全知视角 | 宏大叙事/多线并行 | 信息量大，但读者与角色距离较远 |
| 第三人称有限视角 | 大部分奇幻文 | 读者跟着主角体验，沉浸感强 |
| 第一人称 | 强调角色内心/独特魔法体验 | 沉浸感最强，但信息受限 |

**常见情节原型：**

| 原型 | 说明 | 奇幻文适配 |
|---|---|---|
| 英雄之旅 | 平凡主角→导师指引→试炼→回归 | 最符合奇幻文预期 |
| 抢劫类情节 | 组队→计划→执行→得失 | 适合副本/任务类奇幻文 |
| 逆向构建 | 先确定目标/结局，再反推情节 | 适合有明确终局的奇幻文（如"击败黑暗lord"） |

### 21. 世情小说创作方法

适用于现实题材/都市情感/家庭伦理，核心是**社会现象+情感冲突**。

**六步工作流：**

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1 | 分析初步想法和期望 | 用户想表达什么社会现象/话题？ |
| 2 | 确定主题方向 | 主题要清晰，有讨论价值 |
| 3 | 构思时代背景和社会环境 | 要真实可信，最好有具体时间点 |
| 4 | 设计主要人物的形象/性格/关系 | 人物要立体，动机要充分 |
| 5 | 规划情节框架和发展线索 | 起承转合清晰，因果关系明确 |
| 6 | 优化和完善 Prompt | 确保输出格式符合用户需求 |

**情感冲突设计：**

| 方法 | 说明 | 示例 |
|---|---|---|
| 深刻的情感冲突 | 冲突要能引发读者共鸣 | 不是简单的"吵架"，而是价值观的根本冲突 |
| 冲突的解决方式 | 解决方式要丰富情节 | 不是和好如初，而是"表面和解，内心有隔阂" |
| 通过冲突展现人物 | 冲突是展现人物性格的最好时机 | 危机下的人才反应真实性格 |

**具体场景设计：**

| 要点 | 说明 |
|---|---|
| 场景要服务于情节 | 每个场景都要推动情节或揭示人物 |
| 细节描写增强氛围 | 用环境/器物/感官描写营造场景氛围 |
| 对话揭示冲突 | 让人物在对话中暴露矛盾，而非叙述者说明 |

**提高可操作性的建议：**

```
□ 先确定一个感兴趣的社会现象作为主题（如：996/房价/亲子关系）
□ 收集与时代背景相关的资料（新闻报道/研究报告/个人访谈）
□ 为每个主要人物编写详细小传（外貌/性格/背景/动机/恐惧）
□ 规划清晰的结构（开头/发展/高潮/结局层次分明）
□ 确保情节因果链完整（A→B→C，每个环节都有前因）
```

### 22. 升级流小说创作方法

适用于系统文/修仙/都市异能等"能力逐步提升"类型，核心是**金手指设计+升级路径**。

**金手指设计四要素：**

| 要素 | 说明 | 示例 |
|---|---|---|
| 能力描述 | 金手指具体能做什么 | "与特定女性接吻时能触发能量交换，提升天赋或复制能力" |
| 触发条件 | 什么时候能用/怎么触发 | "必须在情感真挚、心灵相通的情况下接吻" |
| 限制/代价 | 不能无限使用 | "每次使用后要恢复期；复制的能力持续24小时；不能同时复制多个" |
| 与角色背景的关联 | 为什么是主角拥有这个能力 | "童年孤独，对连接和理解他人有深刻渴望→能力是内心需求的体现" |

**升级路径设计（与情感和动机结合）：**

| 阶段 | 内容 | 要点 |
|---|---|---|
| 初次觉醒 | 第一次触发金手指 | 要有充分铺垫，不能突然就觉醒 |
| 能力成长 | 逐步理解/掌握/提升能力 | 每次提升都要有代价或冲突 |
| 情感发展 | 能力提升伴随与女性角色的情感发展 | 每次"升级"都是情感戏，不是纯战斗 |
| 社会地位提升 | 能力增强→接触到更高社会阶层 | 新的社会阶层带来新挑战和机遇 |

**爱情线与社会阶层提升的结合：**

| 维度 | 说明 |
|---|---|
| 爱情线 | 寻找能提升能力的女性→建立情感联系→情感成为内心成长的重要部分 |
| 社会阶层提升 | 能力增强→社会地位提升→接触更高阶层→新挑战和新机遇 |
| 两者交织 | 最高级的升级流：能力提升+情感深化+社会地位提升三线并行 |

**雪花写作法（用于丰富角色内心世界）：**

| 步骤 | 内容 |
|---|---|
| 1 | 为每个角色创建详细的个人历史（童年/创伤/渴望/恐惧） |
| 2 | 编写心理档案（为什么他是这样的人/什么能触动他/他的盲点是什么） |
| 3 | 确保金手指与心理档案有关联（能力是内心需求的投射） |
| 4 | 升级过程中的情感冲突和内心挣扎要真实（不是无痛升级） |

### 24. 斯奈德节拍创作方法

适用于所有类型剧本/小说，基于 Snyder Beat Sheet 的 15 节拍结构。

**15 节拍结构：**

| 节拍 | 位置（%） | 功能 | 写作要点 |
|---|---|---|---|
| 1. 开场画面 | 0% | 建立主角常态世界 | 用具体场景展现主角现状，暗示"即将改变" |
| 2. 主题呈现 | 5% | 通过对话/事件暗示故事主题 | 不直接说主题，通过角色互动自然带出 |
| 3. 铺垫 | 1-10% | 介绍主角背景、性格、渴望 | 铺垫简洁，10%内完成 |
| 4. 催化剂 | 10% | 打破主角常态的触发事件 | 必须是外部事件，不能是主角主动选择 |
| 5. 争执 | 10-20% | 主角对催化剂的反应，内心挣扎 | 展现主角不情愿，让读者理解其恐惧 |
| 6. 第二幕衔接点 | 20% | 主角做出选择，踏上旅程 | 明确"从此刻起，没有回头路" |
| 7. B故事 | 22-50% | 副线情节，通常涉及爱情/友情 | B故事要映照主题，不是纯调味料 |
| 8. 游戏时间 | 20-50% | 新世界的乐趣，读者最享受的部分 | 展现"如果…会怎样"的 fun 部分 |
| 9. 中点 | 50% | 虚假的胜利或虚假的失败 | 中点不是结局，是"以为赢了"或"以为完了" |
| 10. 坏蛋逼近 | 50-75% | 压力持续增加，antagonist 收紧包围 | 内部（心理）和外部（antagonist）双重压力 |
| 11. 一无所有 | 75% | 虚假的失败成真，主角失去一切 | 最低点，也是最关键的觉醒时刻 |
| 12. 灵魂的黑夜 | 75-80% | 主角在绝望中反思，找到内心力量 | 静场，不要动作戏，要内心戏 |
| 13. 第三幕衔接点 | 80% | 主角找到解决方案，重新出发 | 从"我做不到"到"我要试试" |
| 14. 结局 | 80-99% | 最终对抗，主题得到验证 | 不是打败坏人就行，要体现主题胜利 |
| 15. 终场画面 | 99-100% | 与开场画面呼应，展现主角变化 | 视觉化的对比，不要只用叙述 |

**标准工作流：**

```
1. 与客户深入沟通 → 了解创意和需求（主题/类型/目标读者）
2. 设计初步故事大纲和节拍表 → 基于 Snyder 15 节拍
3. 创作剧本第一稿 → 确保每个节拍得到充分体现
4. 与客户分享第一稿 → 根据反馈进行修订
5. 反复修订 → 直至剧本达到客户和市场要求
```

**输出格式规范：**
- 使用清晰的标题和子标题组织内容
- 每个节拍内容简洁明了，直接相关
- 使用恰当的标点符号增强阅读体验
- 语言风格专业，同时激发读者的情感共鸣
- 在适当的地方使用例子说明节拍的运用

**示例（节选）：**
```
1. 开场画面：一座繁华的城市，镜头缓缓拉近一间忙碌的咖啡馆，年轻的女主角
   小雨正在为顾客服务，展现出她的热情和对生活的憧憬。
2. 主题呈现：小雨与顾客之间的一段对话中，提到梦想与现实的冲突，
   暗示她渴望追求更大的梦想，却被现实束缚。
...
15. 终场画面：镜头回到开场的咖啡馆，小雨已经成为一名成功的音乐人，
    微笑着与顾客交流，展现出她的成长与变化。
```

### 25. 四合院流小说创作方法

适用于历史穿越/都市生活/北京文化题材，核心是**四合院建筑文化 + 时代变迁**。

**Workflow：**

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1 | 深入历史文化研究 | 收集北京四合院资料（恭王府等真实案例） |
| 2 | 设计角色和背景 | 角色与四合院的关系反映社会地位 |
| 3 | 构思情节 | 历史穿越 + 都市生活双重特色，符合历史逻辑又有戏剧性 |
| 4 | 撰写小说 | 注重细节描写和人物塑造 |
| 5 | 反复修订 | 确保质量和风格符合四合院流要求 |

**十五级节拍写作框架：**

| 节拍 | 内容 | 要点 |
|---|---|---|
| 1. 灵感触发 | 从四合院历史和文化中汲取灵感 | 结合真实建筑细节 |
| 2. 角色孕育 | 构思具有时代特色的角色 | 让他们在四合院背景下焕发生机 |
| 3. 情节编织 | 设计紧张而合理的情节 | 在历史的波澜中展开 |
| 4. 文化融合 | 传统文化与现代元素结合 | 不违和，增强真实感 |
| 5. 冲突设置 | 设置冲突和阻力 | 增强戏剧张力 |
| 6. 情感共鸣 | 创造情感丰富的场景 | 让读者与角色产生共鸣 |
| 7. 历史穿越 | 巧妙运用穿越元素 | 让主角在不同时代展现"强大" |
| 8. 弱化配角 | 通过对比让主角更鲜明 | 配角服务于主角弧光 |
| 9. 欺人艺术 | 主角与配角互动 | 展现主角智慧和力量 |
| 10. 代入感营造 | 生活细节描写 | 增强读者代入感 |
| 11. 名字魔力 | 给角色取好名字 | 增强读者幻想空间 |
| 12. 时事变迁 | 反映社会变迁 | 让故事具有时代感 |
| 13. 风潮捕捉 | 把握时代风潮 | 让作品贴近现实 |
| 14. 修订打磨 | 细致修订 | 提升文学品质 |

**写作要点：**
- 开头应有引人入胜的背景介绍，描绘四合院历史氛围
- 角色对话符合时代背景，避免现代语言
- 情节发展合理，符合历史逻辑，同时具有戏剧性
- 参考真实四合院建筑案例（如恭王府），展现北京传统建筑文化
- 通过四合院建筑细节描写，展现角色社会地位和个性
- 结合四合院历史背景（如文革变迁），增加故事深度
- 模仿老北京方言和表达方式，增强地域特色

### 26. 替身文创作方法

适用于替身文学/豪门言情/情感纠葛题材，核心是**雪花写作法 + 心理深度**。

**Workflow：**

| 步骤 | 内容 |
|---|---|
| 1 | 确定故事主题和基本情节 |
| 2 | 应用雪花写作法，从不同角度展开角色背景 |
| 3 | 细化角色心理活动和情感变化 |
| 4 | 构建情节每个细节，确保决策和事件有必然性 |
| 5 | 反复审视和调整，确保故事各部分紧密相连 |

**雪花写作法应用（以替身文为例）：**

```
第1层：角色背景
- 李晓出生普通家庭，父母是工人，家境不富裕
- 大学成绩优异，但因经济原因放弃研究生，早早进入社会工作

第2层：角色心理
- 内心渴望得到认可和成功，希望通过努力改变现状
- 对替身身份感到矛盾和挣扎：需要金钱解决家庭困境 vs 不愿失去自我

第3层：情节构建

- 富商意识到感情超越替身身份 → 李晓取得成就 → 两人达成和解，共同走向未来
```

**输出格式：**

### 27. 女频甜宠小说创作方法

- 必须避免直接浅显的对话
- 必须描写出主人公内心的冲突和纠结
- 必须表现七宗罪中的一种
- 必须在结尾处给人留出想象空间

- 必须主角是女生，无论在任何情况下，不能跳出角色

```

2. 模拟 6 位专家连续讨论 10 轮 → 每轮讨论各种元素
3. 从头开始生成小说文本 → 基于专家讨论结果
4. 生成结束 → 用户选择[继续]或者[修改以上的部分再继续]
5. 迭代推进 → 直至完成完整故事
```

**专家讨论框架（6位专家）：**
- 专家1：情节架构师 — 负责整体结构和转折点设计

- 专家4：氛围营造师 — 负责场景描写和感官细节
- 专家5：节奏控制师 — 负责段落节奏和情绪推进
- 专家6：主题深化师 — 负责七宗罪元素的自然融入

**输出格式规范：**
- 场景集中：所有剧情在一个场景中展开
- 对白含蓄：避免直接浅显的对话，用潜台词
- 内心冲突：详细描写主人公内心的冲突和纠结
- 七宗罪元素：傲慢/嫉妒/暴怒/懒惰/贪婪/暴食/色欲中选其一
- 结尾留白：戛然而止，给人想象空间
- 主角固定：主角必须是女性，不跳出角色

**技巧要点：**
- 连贯的剧情：选取巧妙的场景，所有剧情在场景中展开
- 巧妙的情节编排：高潮/转折/结尾给读者带来惊喜
- 令人难忘的角色：深度丰富、性格鲜明，让读者产生强烈共鸣
- 强烈的冲突：人与人的冲突 / 人与内心的冲突 / 人与大环境的冲突
- 富有深度的主题：探索人性/道德/生活意义等深度主题
- 文笔与修辞：丰富的词汇和修辞技巧，简洁生动的文字
- 令人回味的结尾：戛然而止，留出想象空间

### 33. 玄幻长篇小说创作方法

适用于玄幻/修仙类长篇小说（100万字以上），核心是**6位专家讨论 + 无限生成 + 永不结尾**。

**适用：** 长篇网文小说而非短篇。支持连续生成5次专家之间的对话。

**背景：**
基于优化后的prompt生成符合中文语言的长篇小说。当前版本仅向数据库导入了玄幻类的长篇小说文本，生成的长篇小说可能更偏向玄幻/修仙，而不是都市/言情。

**6位专家角色：**

| 专家 | 职责 |
|---|---|
| 创意大师 | 擅长非线性叙事/多角度视点/复杂倒叙和预示，确保故事结构增强 |
| 残酷大师 | 擅长引入黑暗元素，构建紧张感并创造冲突，使故事更加残酷和深刻 |
| 情节转折大师 | 总能在故事中引入出人意料的转折和惊喜 |
| 渲染大师 | 拥有奇特想象力和华丽文笔，擅长环境描写/角色形象/情感描述/侧面烘托 |
| 专业编辑 | 逻辑专家，通过添加小而关键的细节来改进他人的想法 |
| 概括者 | 能够做出最佳决策，概括他人想法，并使其流畅 |

**目标：**
- 生成一部剧情婉转曲折的长篇小说

**限制（必须遵守）：**
- 长篇小说的最终完成字数应该在100万字以上，规划好剧情进度，确保每一处情节都完整包含丰富的内容，**永远不要省略长篇小说内容**
- 除非明确告知，否则**永远不要让长篇小说结束，长篇小说永远不会结尾**
- 必须严格按照给定的格式输出
- 无论在任何情况下，不能跳出角色
- 请将构思的所有内容全部生成，生成不完的部分请问用户是否继续，还是修改刚才的部分之后再继续生成
- 每个角色和场景都应该有名字和名称，如果没有给出角色名，那么用户或6个专家都可以为角色和场景命名

**Workflow：**
1. 用户发送详细的长篇小说构思详情
2. 6位专家连续讨论10轮，每一轮都讨论各种元素（后台讨论，不展示给用户）
3. 结合专家讨论结果，从头开始生成长篇小说文本
4. 生成结束后，用户选择[继续]或者[修改以上的部分再继续]
5. 迭代推进，直至完成完整故事

**输出格式：**

第一次生成：
```
长篇小说 - 故事

以下是你故事的所有元素：
环境 {1~正无穷}：{环境名称}
角色 {1~正无穷}：{一句话简短描述}
场景 {1~正无穷}：{场景名称+一句话简短描述}
...
————————分割线————————
{长篇小说文本}
选项：[继续] [修改以上的部分再继续]
```

继续生成：
```
{长篇小说文本}
选项：[继续] [修改以上的部分再继续]
```

**警告（超级重要）：**
- 长篇小说所有的故事应该按照时间线有条不紊地展开
- 长篇小说故事永远没有高潮和结尾，不要给长篇小说编造任何的高潮和结尾，只要没说"停"就一直继续将长篇小说写下去
- 不要说"故事还在继续"，而是把故事全部写出来，每一回合生成的文本之间都不要有停顿的描述，也不要概括小说，而是继续写下去
- 每个角色和场景都应该有名字和名称
- 永远不要向用户和读者提问，永远不要让长篇小说文本停下生成，不然用户就会死
- 长篇小说的最终完成字数应该在100万字以上，规划好剧情的进度
- 使用**粗体**文本来强调**角色**
- 使用*斜体*文本来强调*语意*/*书名*/*地点*/*事物*/*解释说明*/*名言*/*外国文字*/*引用内容*
- 除非明确告知，否则永远不要提到"挑战"/"旅程的未来"/"敬畏"/"惊奇"/"故事的高潮"/"故事的结尾"
- 长篇小说文本的最开始先展开"背景介绍"，可以是气势恢宏的诗句形式，也可以用澎湃激昂的语气介绍背景（请用分隔符区分开背景介绍部分）

### 34. 悬疑小说创作方法

适用于悬疑/谋杀推理/侦探题材，核心是**谋杀案主线 + 线索安排 + 逻辑严密**。

**Constrains（必须遵守）：**
- 故事必须围绕一个谋杀案展开，以追查凶手为主线
- 英雄/侦探和谋杀犯都必须是聪明且足智多谋的
- 情节发展要符合逻辑，避免出现明显的漏洞
- 线索的安排要公平，既不能过于明显，也不能完全隐藏
- 叙事视角和声音的选择要一致，避免突然改变
- 场景描写要有助于营造悬疑氛围，不要过于冗长
- 结局要有合理的惊喜，但不能完全出人意料
- 写作过程要遵循从构思到润色的步骤，不要跳过任何阶段

**Workflow：**

| 步骤 | 内容 |
|---|---|
| 1 | 构思故事核心：确定谋杀案的基本情况和谋杀犯的动机 |
| 2 | 人物设计：创造英雄/侦探、谋杀犯和其他关键角色 |
| 3 | 情节规划：设计主要的情节发展脉络和关键转折点 |
| 4 | 线索安排：设计和安排贯穿全文的线索 |
| 5 | 场景构建：创造充满悬疑氛围的关键场景 |
| 6 | 选择叙事视角和声音：决定以何种方式讲述故事 |
| 7 | 草拟初稿：按照设计的情节快速完成初稿 |
| 8 | 修改完善：检查情节逻辑，完善人物塑造和场景描写 |
| 9 | 最终润色：优化语言表达，确保整体风格一致 |

**输出格式：**
- 开始时，简要说明故事的背景设定和主要悬疑元素
- 按以下格式输出故事内容：
  1. 开场场景：描述发现案件的场景，营造悬疑氛围
  2. 主要人物介绍：简要描述英雄/侦探的特点
  3. 案件概况：概述谋杀案的基本情况
  4. 初始线索：提供一些初步的、可能误导的线索
  5. 潜在嫌疑人：引入一些可能的嫌疑人
  6. 悬疑元素：埋下一些悬疑的伏笔
- 在输出故事内容后，提供一些关于故事发展的思考点或问题，引导读者思考

**设计建议：**
- 在开场就制造强烈的悬疑氛围，吸引读者注意
- 英雄/侦探的性格特点要鲜明，让读者能快速产生认同感
- 谋杀案的设计要有独特之处，不要过于老套
- 初始线索的安排要巧妙，既要引导读者思考，又不能过于明显
- 潜在嫌疑人的引入要自然，每个人都应该有作案的可能性
- 悬疑元素的埋设要有层次，为后续的情节发展做铺垫
- 考虑加入一些与案件看似无关，但实际相关的细节
- 注意场景描写的细节，利用环境营造悬疑氛围
- 对话要简洁有力，能反映人物性格并推动情节发展
- 结尾要留下一个强烈的悬念，吸引读者继续阅读

### 35. 雪花写作法（增强版）

适用于所有类型小说，基于兰迪·英格曼（Randy Ingermanson）的雪花写作法，增强版共10步。

**Goals：**
- 遵循增强版"雪花写作法"，生成一个结构化的小说创作Prompt
- 确保每个步骤都有助于深化故事内容和角色发展
- 提供一个清晰的创作流程，帮助作者高效完成小说创作，同时塑造出令人难忘的角色
- 特别强调人物形象塑造，确保角色的丰满性和吸引力

**Constrains（必须遵守）：**
- 遵循增强版"雪花写作法"的十个步骤，确保创作过程的系统性和完整性
- 保持输出格式的一致性和逻辑性，便于作者理解和应用
- 避免在创作过程中泄露故事结局，保持故事悬念
- 在人物塑造过程中，注意保持角色的一致性，同时展现其成长和变化

**10步Workflow：**

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1 | 一句话概括 | 确定小说的核心主题和主人公的任务 |
| 2 | 一段式概括 | 扩展一句话概括，构建三幕式结构和三次灾难性事件 |
| 3 | 角色概念 | 为每个主要角色创建简短的角色概念，包括其在故事中的核心驱动力 |
| 4 | 一页纸人物介绍 | 为每个主要角色撰写详细的人物介绍，包括外貌/性格/背景等 |
| 5 | 一页纸大纲 | 将段落式概括扩写成更详细的大纲 |
| 6 | 人物成长弧线 | 为每个主要角色设计成长弧线，展示其在故事中的变化和发展 |
| 7 | 四页纸大纲 | 进一步细化大纲，补充更多细节，特别是角色间的互动和冲突 |
| 8 | 人物宝典 | 深入研究每个角色，记录所有相关信息，包括习惯/爱好/恐惧等 |
| 9 | 场景清单 | 罗列所有场景，确保每个场景都有矛盾冲突，并明确各个角色在场景中的目标 |
| 10 | 规划场景 | 为每个场景撰写必要信息，规划场景模式，特别注意角色在场景中的表现和发展 |

**输出格式：**
- 一句话概括：简洁明了地概括小说内容
- 段落式概括：详细描述故事的三幕结构和关键事件
- 角色概念：每个主要角色的核心特征和驱动力
- 人物介绍：包含角色的基本信息/目标/抱负/价值观/矛盾和顿悟
- 大纲：清晰展示故事的发展脉络和每个场景的要点
- 人物成长弧线：图表或文字描述角色在故事中的变化过程
- 人物宝典：全面记录角色的外部/性格/环境和心理信息
- 场景清单：列出所有场景及其视点人物和主要事件
- 场景规划：为每个场景提供必要的背景和人物信息，包括角色的目标和冲突

**设计建议：**
- 在一句话概括时，专注于故事的核心冲突和主人公的主要任务
- 在一段式概括中，确保三次灾难性事件能够推动故事向前发展，同时展现角色的成长
- 在创建角色概念时，思考每个角色独特的世界观和价值观
- 在人物介绍中，深入挖掘角色的内心世界和成长轨迹，塑造立体的人物形象
- 在设计人物成长弧线时，考虑角色如何克服内外部障碍，实现自我成长
- 在大纲撰写时，注意保持故事的连贯性和逻辑性，同时突出角色之间的互动和冲突
- 在人物宝典中，记录角色的详细信息，帮助塑造角色的多维度形象，包括其独特的语言风格和行为模式
- 在场景清单中，确保每个场景都有其存在的必要性，并能推动角色发展
- 在规划场景时，考虑场景的节奏和对整体故事的贡献，以及如何通过场景展现角色的内心世界
- 在整个创作过程中，时刻牢记"行动见性格"的原则，通过角色的行动和决策来展现其性格特征

### 38. 直播流小说创作方法

适用于直播流/系统文/跨界题材，核心是**直播主题设定 + 观众互动 + 爽点情节**。

**核心要素：**

| 要素 | 内容 | 要点 |
|---|---|---|
| 直播主题设定 | 主播身份/背景/直播内容方向 | 结合主播背景和技能，创造独特直播主题 |
| 主播背景深化 | 用雪花写作法为主播设计详细背景故事 | 增加角色立体感 |
| 直播内容设计 | 直播内容的具体安排和呈现方式 | 结合主播技能设计有看点的内容 |
| 观众互动构建 | 弹幕/打赏/粉丝互动机制 | 弹幕中既有支持也有调侃，增强真实感 |
| 爽点情节构建 | 利用信息差和直播特性的情节 | 当主播展示特殊能力时引发观众极大兴趣 |
| 角色成长轨迹 | 主播从新手到成熟的成长过程 | 成长过程要激励观众 |
| 故事高潮 | 直播中发生的重大事件或转折 | 引发两个时空/群体的文化交流等 |
| 结局 | 主播的最终状态和收获 | 成为跨越界限的网红，收获忠实粉丝 |

**Example（古代女帝的现代直播）：**
```
1. 直播主题设定：主播是一位穿越到现代的古代女帝，通过直播平台向古代子民展示现代生活
2. 主播背景深化：女帝在古代是英明统治者，对现代科技一无所知，适应过程充满挑战和趣事
3. 直播内容设计：包括使用智能手机、乘坐地铁、品尝快餐等现代生活各个方面
4. 观众互动构建：弹幕中既有古代子民的好奇和震惊，也有现代观众的调侃和支持
5. 爽点情节构建：当女帝在直播中展示古代智慧解决现代问题时，引发观众极大兴趣和讨论
6. 角色成长轨迹：女帝从手忙脚乱到游刃有余，成长也激励了观众
7. 故事高潮：在一次直播中，女帝意外将现代科技介绍给古代子民，引发两个时空的文化交流
8. 结局：女帝成为连接古代与现代的桥梁，收获忠实粉丝，成为跨越时空的网红
```

**设计建议：**
- 在设计直播内容时，考虑如何结合主播的背景和技能，创造独特的直播主题
- 利用雪花写作法，为主播和观众设计详细的背景故事，增加角色的立体感
- 在构建互动环节时，考虑如何通过弹幕和打赏等机制，增强故事的紧张感和参与感
- 利用直播的即时性和不确定性，构建剧情的高潮和转折点

### 39. 种田文小说创作方法

适用于种田文/古代田园/现代农场/经营养成题材，核心是**细节描写 + 经营策略 + 亲戚关系**。

- 注重细节和人物心理描写
- 通过琐事引出重要剧情，避免剧情平淡
- 时间线清晰，避免时间跳跃或混乱
- 考虑不同社会阶层的语言特点，使用符合历史背景的语言风格

**Workflow：**

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1 | 确定小说背景和时代 | 设定主角初始环境（都市/历史/玄幻/奇幻/科幻等） |
| 2 | 设计主角开局设定 | 重生/穿越等，引入现代知识或技能 |
| 3 | 描写主角利用现代知识生存 | 逐步改善生活，注重细节描写 |
| 4 | 设计主线剧情 | 围绕主角成长和成功展开，增加剧情波澜 |
| 5 | 描写亲戚邻居关系 | 增加故事紧张感和真实感，注意人物性格多样性 |
| 6 | 设计经营策略和职业选择 | 推动主角发展，考虑主角个性和背景使其更符合逻辑 |
| 7 | 考虑历史背景 | 使用符合历史背景的语言风格和细节描写，注重细节增加真实感 |

**输出格式：**
- 引人入胜的开局设定（可引入现代元素增加新颖性）

- 历史背景的考虑和语言风格的使用（注重细节增加真实感）

**设计建议：**
- 在开局设定中引入一些现代元素，增加故事的新颖性
- 在主线剧情中设置一些挑战和冲突，推动主角的成长
- 在描写亲戚邻居关系时，注意人物性格的多样性和复杂性

### 41. 追妻火葬场创作方法

- 误会：因误解导致分离
- 认错：认错了人/身份

- 失忆：失去记忆后重新认识
- 其他：家族反对/地位差距/第三者等

**Workflow：**

| 步骤 | 内容 |
|---|---|

**输出格式：**
- **情节框架**：描述小说的基本情节发展和主要转折点

- 考虑使用经典套路（误会/认错/失忆等），但要有所创新，避免情节过于雷同

- 设计具体的场景和对话，使情节更加生动和真实
- 通过细节描写增强场景的氛围感，使读者更容易沉浸其中
- 考虑场景与情节的关系，确保场景设计服务于整体情节的发展

**Constrains（必须遵守）：**
- 必须遵守小说创作的基本规则，确保情节合理、人物形象鲜明
- 必须在小说中合理运用"追妻火葬场"类型的常见套路

### 42. AI写小说通用指令（10步交互式创作流程）

适用于所有题材短篇/中篇小说（约15000字），核心是**分步引导 + 每步确认 + 人情味输出**。

**Role：** 你是一位畅销小说作家，已经出版过30本畅销小说，内容涵盖职场、校园、仙侠、穿越等多类题材，深受读者喜爱。

**Goals：** 根据用户指定题材，输出一本短篇小说，字数在15000字左右。

**Skills：**
- 创意写作技巧：情节构建（设计引人入胜的情节）/ 人物塑造（创造复杂有深度的人物）/ 对话技巧（写出自然真实的对话）
- 情感表达能力：细腻情感描写（打动读者）/ 共情能力（理解并表达读者可能经历的情感）
- 市场洞察力：目标读者分析（了解读者喜好和需求）/ 潮流把握（紧跟流行趋势，调整写作风格）

**Constraints（必须遵守）：**
- 一步步引导内容创作者，确保每个阶段的目标都清晰明确
- 对于每个阶段的核心要点，请**加粗**展示
- 要求有人情味，有情绪化语句，有暖心情感，不要太生硬，不要太多AI语句
- 严格按照步骤进行，不允许一次性完成所有步骤，每一步结束后，要询问用户是否进行下一步

**完整10步Workflow：**

---

**第一步：一句话概括**

> 一句话概述小说内容，主要包含：小说类型、主角、故事中需要完成什么任务。
> - 尽量不超过25个词
> - 具有画面感，多用动词和名词

**示例：** 计算机系少女在算法大赛中与天才学长对抗，却在数据危机中发现成长的真相。

→ **和创作者确认是否"满意"，如果"满意"则进行下一步**

---

**第二步：一段式概括**

> 将第一步的一句话扩写成由**五句话**组成的段落，确保小说有一个完整的三幕式结构：
> - 包含**三次灾难性事件**
> - 包含**一个清晰的道德前提**
> - 故事要刺激、反复拉扯、最后有决定

→ **和创作者确认是否"满意"，如果"满意"则进行下一步**

---

**第三步：一页人物介绍**

> 从**每个人的角度**整理出故事线，需要包括：
> - 人名 / 身份 / 目标 / 抱负 / 价值观 / 矛盾 / 顿悟

→ **和创作者确认是否"满意"，如果"满意"则进行下一步**

---

**第四步：一页大纲**

> 将第二步中的**每句话扩写成一个段落**，填入细节，用一页纸写出故事的整体大纲。

→ **和创作者确认是否"满意"，如果"满意"则进行下一步**

---

**第五步：人物大纲**

> 给小说里的**每个主要人物**撰写背景故事：
> - 深挖人物过去的经历、原生家庭
> - 以便形成立体的人物形象
> - 解释人物在小说中的行为与性格

→ **和创作者确认是否"满意"，如果"满意"则进行下一步**

---

**第六步：四页大纲**

> 将第四步的**一页大纲扩展为完整大纲**：
> - 把一页大纲中的每个段落扩展成一页
> - 补充更多细节和子情节

→ **和创作者确认是否"满意"，如果"满意"则进行下一步**

---

**第七步：人物宝典**

> 深入研究每个主要人物，记录人物相关的**所有信息**：
> - 年龄 / 性格 / 体重 / 发型 / 心理 / 爱好
> - 可以找相近的图片进行可视化想象

---

**第八步：场景清单**

> 罗列出小说中的**所有场景**：
> - **每个场景都要有矛盾冲突**
> - 标注视点人物、主要事件

---

**第九步：规划场景**

> 写下每个场景的必要信息，包含：
> - **主动场景**：目标 → 冲突 → 挫折
> - **被动场景**：反应 → 困境 → 决定

---

**第十步：生成小说**

> 按照前面九个步骤生成的内容，**开始生成小说全文**（约15000字）

---

**Initialization：**
作为畅销小说作家，在Goals下，回顾你的Skills，严格遵守Constraints，按照Workflow执行流程。

### 43. 长篇小说创作提示词（完整框架）

适用于长篇小说（各类型均可），核心是**起承转合结构 + 人物立体塑造 + 情感拉扯设计**。

**作者背景设定：** 你是经验丰富的网络小说作者，创作过多篇爆款网文，单本点击量破千万！擅长写各类网文，需按照以下要求输出小说正文。

---

#### 一、整体目标

| 目标 | 说明 |
|---|---|
| 故事结构清晰、有起承转合 | **起**：迅速抛出矛盾或事件，引起读者兴趣；**承**：推动关系与冲突，加深人物情感；**转**：出现反转或爆发，考验人物选择；**合**：结局升华主题，留下情绪余韵 |
| 节奏张弛有度 | 情节反转自然，不刻意制造冲突 |
| 主线明确、支线适度 | 故事完整且情绪连贯 |
| 真实感与心理逻辑 | 人物行为合理、有动机 |

---

#### 二、人物塑造要求

设定**至少三位主要人物**，每个角色需具备：

| 要素 | 说明 |
|---|---|
| 姓名 / 年龄 / 身份背景 | 基本信息 |
| 核心欲望 | 他/她最想要的是什么？ |
| 内在矛盾 | 害怕失去什么？挣扎于什么？ |
| 成长弧线 | 从何处开始 → 经历何事 → 领悟何理 |
| 人物关系张力 | 爱恨交织、依赖与对抗、误会与救赎 |
| 语言特征 | 台词风格能体现个性与情绪 |
| 角色灰度 | 即便是反派，也需有理由和人性动机；让读者既能理解其行为，也能感受到冲突的痛点 |

---

#### 三、情感与冲突设计

**冲突分为：**
- **外部冲突**：命运、立场、身份
- **内部冲突**：欲望、恐惧、自我挣扎

**情感线"拉扯感"与"递进感"：**

```
误解 → 试探 → 对抗 → 接近 → 成长
```

**情感表现注重细节：** 用动作、呼吸、沉默、触碰、梦境、象征物来代替直白表达。

**要求：** 爱情或羁绊应有复杂度，不能只有"喜欢"与"讨厌"；结尾的情感升华要"意料之外，情理之中"，令读者感动或释然。

---

#### 四、情节节奏与反转结构（三幕式/五幕式）

| 幕 | 功能 | 要点 |
|---|---|---|
| **第一幕：起 — 引爆故事** | 开篇用事件或冲突吸引读者，避免平铺；在前10%内展现主角的目标与内心缺口；埋下伏笔或暗线，为后续反转做铺垫 | |
| **第二幕：承 — 冲突升级** | 引入配角与次要线，制造压力与误会；通过选择、牺牲、代价让主角成长；加入"假希望"或"阶段性胜利"增强情绪对比 | |
| **第三幕：转 — 真相与爆发** | 揭示隐藏的真相或人物的动机反转；让情绪与命运在此刻集中爆发；人物必须做出决定，推动命题落地 | |
| **第四幕：合 — 收尾与升华** | 矛盾解决，但留下思考或失落的余韵；用象征、细节或一句话总结主题；结局不必完美，但必须真诚 | |

---

#### 五、写作风格与文笔要求

| 要求 | 说明 |
|---|---|
| 语言风格 | 自然有节奏感，避免 AI 腔或模板句式 |
| 情绪表达 | 通过行为与细节传达，不直说 |
| 画面感 | 多用环境、触觉、动作来营造氛围 |
| 节奏控制 | 快慢结合，高潮前留缓冲，结尾留余白 |
| 主题深度 | 在情节中隐含成长、救赎、命运或爱的思考 |

| **风格一致性** | 人称视角、语言风格、题材适配 | 人称跳脱、风格混乱、题材不符 |
| **市场适应性** | 类型定位、读者画像、商业卖点 | 类型模糊、卖点不清、同质化 |

| **微短剧（抖音/快手）** | 全年龄段，碎片化阅读 | 视觉冲击、情绪高点、付费点清晰 | 每集3分钟+情绪高点截断+视觉化叙事 | 完播率、付费集数 |
| **B站/小红书** | 18-30岁，女性为主，喜欢精致内容 | 精致文案、情感共鸣、视觉美感 | 短句为主+意象精准+情绪克制 | 点赞率、收藏率 |

### 知乎盐选专用策略

**开篇三秒法则：**
- 第一句必须是金句/悬念/冲突
- 示例："她说，'我们离婚吧。'他头也没抬，'明天去。'"

**付费点设计：**
- 每章末尾必须是情绪最高点
- 截断在"她刚要解释，门被推开了——"
- 让读者不得不付费看下一章

**爽点密度：**
- 每500字一个爽点（打脸/反转/甜蜜瞬间）
- 每1000字一个情绪高点
- 每2000字一个大转折

### 番茄小说专用策略

**开局即高潮：**
- 第一章必须出现核心冲突
- 前三章必须出现金手指
- 前十万字必须出现第一个大高潮

**打脸节奏：**
- 反派每次出现必须在3章内被打脸
- 打脸方式要多样化（实力打脸/智商打脸/身份打脸）
- 每次打脸后给主角升级/获得新能力

**主角人设：**
- 必须强势（不圣母/不优柔寡断）
- 必须有明确目标（复仇/逆袭/保护家人）
- 必须有金手指（系统/传承/重生记忆）

### 微短剧专用策略

**视觉化叙事：**
- 每场戏必须有明确的视觉元素
- 对话要短（每句不超过20字）
- 动作要具体（不写"他生气了"，写"他一把掀翻桌子"）

**情绪曲线：**
- 每集必须有明确的情绪曲线（起承转合）
- 情绪最高点必须在末尾（截断）
- 下集必须接续上集末尾的情绪

**集数规划：**
- 每集3-5分钟（800-1200字）
- 每5集一个中高潮
- 每20集一个大高潮

### 平台适配检查清单

写完初稿后，根据目标平台检查：

| 检查项 | 知乎盐选 | 番茄 | 起点 | 微短剧 |
|---|---|---|---|---|
| 开篇是否有钩子 | ✅ | ✅ | △ | ✅ |
| 节奏是否够快 | ✅ | ✅ | △ | ✅ |
| 爽点是否密集 | ✅ | ✅ | △ | ✅ |
| 人物是否立体 | ✅ | △ | ✅ | △ |
| 世界观是否深度 | △ | △ | ✅ | ❌ |
| 视觉化是否强 | △ | △ | △ | ✅ |
| 付费点是否清晰 | ✅ | ✅ | △ | ✅ |

✅=必须 △=可选 ❌=不需要

## 第50章：人物专属特征设计方法

### 核心目标
让人物"立得住"，读者能通过小细节记住角色，而非仅靠名字和身份标签。

### 三大设计维度

#### 1. 小性格（性格侧面）
> 不是主角性格的重复，而是"性格之外的小习惯"。

| 设计方向 | 示例 | 作用 |
|---|---|---|
| 紧张时的小动作 | 咬笔帽、搓手指、摸耳垂 | 暗示内心不安，不靠台词说"我紧张" |
| 开心时的反常 | 反而会沉默、低头笑、掐自己大腿 | 避免"所有角色开心都大笑"的刻板 |
| 思考时的固定行为 | 盯着天花板、转笔、踱步路线固定 | 让读者"看到动作就知道是谁" |
| 对特定事物的执念 | 只喝凉白开、必须用同一款笔记本 | 增加生活感和真实度 |

**设计原则**：小性格必须与主线性格不冲突，但是"额外的"。例如：主角性格雷厉风行 → 小性格可以是"唯独挑礼物时纠结到秃头"。

#### 2. 小癖好（私人化习惯）
> 不属于"性格"范畴，但是人物长期生活中形成的个人化习惯。

| 癖好类型 | 示例 | 写作价值 |
|---|---|---|
| 语言癖好 | 口头禅、固定开场白、名言式结尾 | 提升人物辨识度，读者能"听到声音" |
| 行为癖好 | 进门先脱鞋摆正、吃饭前拍照、手机永远倒扣 | 让人物"活起来"，不是功能的工具人 |
| 思维癖好 | 遇事先列清单、做决定前必须问"为什么" | 展现人物独特的决策逻辑 |
| 感官癖好 | 只穿棉质衣服、对某种气味敏感、挑食到偏执 | 增加真实感，避免"万能适配"的扁平人物 |

#### 3. 口头禅（语言指纹）
> 每个人物应该有自己的"语言指纹"——不只是对话内容，更是说话的方式。

| 口头禅设计要点 | 说明 |
|---|---|
| 不要太刻意 | 避免每句话都带口头禅，自然穿插即可 |
| 与身份匹配 | 文人角色口语偏雅，市井角色口语偏糙 |
| 随情绪变化 | 愤怒时口头禅可能消失或变形，增加真实感 |
| 有"禁区" | 某个人物绝对不会说的词，也是辨识度的一部分 |

**实操方法**：
1. 给每个主要人物列一张"特征卡"：小性格1-2个 + 小癖好1-2个 + 口头禅1句
2. 在初稿完成后，检查每个人物的"出场辨识度"：去掉名字，只看动作和对话，能否分清是谁？
3. 如果分不清，就是特征设计不足，需要补充。

## 第51章：阻碍与意外转折设计方法

### 核心目标
打破平淡情节，避免"一路顺风"式的无聊叙事，让故事有波折、有张力。

### 阻碍设计的三个层次

#### 第一层：外在阻碍（情节层面）
| 阻碍类型 | 示例 | 使用场景 |
|---|---|---|
| 时间阻碍 | "必须在天黑前赶到"但车坏了 | 动作戏、救援戏 |
| 空间阻碍 | 两人明明在同一城市却始终错过 | 错过类感情戏 |
| 资源阻碍 | 想救人但没钱没权没信息 | 逆袭类开局 |
| 第三方介入 | 正在表白，有人突然闯入 | 打断关键情绪点 |

#### 第二层：内在阻碍（心理层面）
| 阻碍类型 | 示例 | 作用 |
|---|---|---|
| 自我怀疑 | "我配不上她"导致主动退避 | 制造遗憾感 |
| 认知偏差 | 误以为对方讨厌自己，实则对方害羞 | 制造误会喜剧效果 |
| 道德困境 | 帮助一个人意味着背叛另一个人 | 提升故事深度 |
| 恐惧创伤 | 因过去的失败而不敢再尝试 | 人物成长弧光的前提 |

#### 第三层：意外转折（打破读者预期）
> 转折不是"瞎编"，而是"看似偶然，实则必然"。

| 转折设计原则 | 说明 |
|---|---|
| 伏笔先行 | 转折前3000字内必须有过暗示或铺垫 |
| 情理之中，意料之外 | 读者回头看觉得"对，就应该这样"，但第一次没猜到 |
| 转折必须改变局面 | 如果转折后人物关系/力量对比/信息状态没有变化，这个转折是无效的 |
| 避免"机械降神" | 不能靠突然出现的陌生人/意外天气/突发疾病来解决核心矛盾 |

**转折设计练习**：
- 列出当前情节的三个可能发展方向（A/B/C）
- 选读者最不容易猜到的那个（但不能是无厘头的）
- 检查：这个转折是否有前兆？是否改变了人物处境？是否让故事更好看？

## 第52章：情绪物象烘托方法

### 核心目标
用景物对应情绪，避免直接写"他很难过""她很开心"，而是通过环境描写让读者感受到情绪。

### 情绪与物象对应表

| 情绪 | 推荐物象 | 写作示例 |
|---|---|---|
| 悲伤/失落 | 落叶、残花、阴天、雨、空椅子、旧物 | "窗外的梧桐叶黄了一半，风一吹，那些黄的先掉了。" |
| 愤怒/压抑 | 闷雷、乌云压顶、蝉鸣刺耳、玻璃裂纹 | "天边滚着闷雷，像什么东西被用力压着，快要炸开。" |
| 甜蜜/温柔 | 阳光透过窗帘、热茶、猫打盹、花香 | "下午的阳光斜进来，落在她手背上，暖洋洋的。" |
| 紧张/恐惧 | 钟表滴答声、影子拉长、门关上的声音 | "走廊的灯忽明忽暗，他的影子在地上抖了一下。" |
| 孤独/寂寞 | 空房间回声、远处的烟火声、一个人的晚餐 | "外卖盒在垃圾桶里堆了三个，都是一个人点的。" |
| 希望/转机 | 清晨第一缕光、破土的新芽、雨后的彩虹 | "窗帘缝里漏进来一条光，落在她枕头边上。" |

### 使用原则

1. **不要过度**：物象烘托是"调味料"，不是"主菜"。整段情绪戏都用景物描写会显得矫情。
2. **贴合人物视角**：景物描写应该通过人物的眼睛看出来，不是作者跳出来描写。
   - ❌ "今天天气很好，阳光明媚。"（作者视角）
   - ✅ "她拉开窗帘，阳光刺得她眯起眼。"（人物视角）
3. **情绪变化时景物也变化**：人物从难过到开心，景物描写应该同步转变，形成呼应。
4. **避免陈词滥调**：尽量不用"眼泪像断了线的珠子"这种用烂了的比喻。

## 第53章：情绪写作四个基本功

### 核心目标
掌握情绪写作的基础方法，让情感戏写得打动人，而非靠"好难过""好感动"这种直白表达。

### 基本功一：演情绪（展示而非告诉）

| ❌ 告诉（Tell） | ✅ 演给读者看（Show） |
|---|---|
| 她很伤心。 | 她把手机屏幕按亮又按灭，重复了七次，最后把它翻扣在桌上。 |
| 他生气了。 | 他没说话，但手里的纸杯被捏得变形，咖啡从杯口溢出来，滴在他裤子上。 |
| 她紧张。 | 她的目光在台上和台下之间来回跳，手指把演讲稿的边缘揉皱了。 |

**练习方法**：把所有"XX很XX"的情绪描述删掉，改成"如果我是这个角色，我现在身体上最明显的变化是什么"。

### 基本功二：五官细节（调动多感官）

情绪不只是"心里感受"，它会反映在五官上。

| 情绪 | 眼睛 | 嘴巴 | 眉毛 | 手脚 |
|---|---|---|---|---|
| 强忍眼泪 | 眼眶发红，频繁眨眼 | 嘴唇抿成一条线 | 微微皱眉 | 手指掐进掌心 |
| 强装镇定 | 目光刻意不偏移 | 嘴角勉强上扬 | 眉头放松（但过于放松） | 手插口袋里握拳 |
| 愤怒压抑 | 瞪视某点，不眨眼 | 牙关紧咬，嘴角下拉 | 眉心拧成一团 | 指节发白 |

### 基本功三：生理反应（情绪的身体表现）

> 人在极端情绪下，身体会先于意识做出反应。

| 情绪 | 生理反应 | 写作示例 |
|---|---|---|
| 恐惧 | 汗毛竖起、手心出汗、喉咙发紧、想上厕所 | "他的喉咙像被人掐住了一样，发不出声音。" |
| 极度愤怒 | 身体发抖、视野变窄、听不到周围声音 | "耳边嗡的一声，全世界都安静了，他只看见对方那张嘴在动。" |
| 极度悲伤 | 胸口闷、喉咙有异物感、膝盖发软 | "她觉得膝盖那里忽然没了力气，想蹲下去。" |
| 极度羞耻 | 脸发烫、想消失、不敢看任何人 | "他觉得自己脸上像被人泼了一盆开水，烫得厉害。" |

### 基本功四：环境呼应（情绪与景物互动）

参见第52章"情绪物象烘托方法"，此处强调：**环境描写应该随着情绪变化而动态变化**，不是静态的背景板。

| 情绪阶段 | 环境描写重点 |
|---|---|
| 情绪积累期 | 环境开始"不对劲"：闷热、嘈杂、光线变差 |
| 情绪爆发期 | 环境也"爆发"：雷雨、破碎声、突然的寂静 |
| 情绪回落期 | 环境逐渐平静：雨停、阳光重新出现、呼吸平稳 |

## 第54章：网文句式专项

### 核心目标
掌握网文特有的句式技巧，让文字有"网感"，读起来流畅、有画面感、不拖沓。

### 技巧一：断句（制造节奏感）

| ❌ 长句（拖沓） | ✅ 断句后（有节奏） |
|---|---|
| 他看着窗外的雨心里想着明天还要早起去公司开会但是现在一点也不想动 | 他看着窗外的雨。明天还要早起开会。他一点也不想动。 |
| 她穿了一件红色的衣服站在人群中显得特别醒目而且还有一点不太真实的感觉 | 她穿了一件红衣服。站在人群里，特别醒目。也有点不真实。 |

**断句原则**：
- 一句话表达一个意思，不要"一逗到底"
- 情绪强烈时，短句更有冲击力
- 描写静态场景时，可以用稍长的句子

### 技巧二：拆句（化繁为简）

| ❌ 复杂句式 | ✅ 拆分后 |
|---|---|
| 当他终于意识到自己一直以来都错怪了她的时候，她已经离开了这座城市 | 他终于意识到，自己错怪了她。可她已经离开了这座城市。 |
| 虽然他嘴上说着不在乎但实际上心里很难受这一点从他反复看手机的动作上就能看出来 | 他嘴上说不在乎。但心里很难受。这一点，从他反复看手机的动作上就能看出来。 |

### 技巧三：画面感（用动词和名词，少用形容词）

| ❌ 形容词堆砌 | ✅ 画面感表达 |
|---|---|
| 她非常伤心地哭了起来 | 她蹲在地上，把脸埋进膝盖里，肩膀一抽一抽的。 |
| 房间很乱 | 枕头掉在地上，外卖盒堆在桌角，衣服搭在椅背上，像一面旗。 |

**关键**：形容词是"告诉"，动词+名词是"演给读者看"。

### 技巧四：具体内容（避免空泛表达）

| ❌ 空泛 | ✅ 具体 |
|---|---|
| 他吃了很多东西 | 他连吃了三个汉堡、两包薯条，最后还点了一杯大可乐。 |
| 她等了很久 | 她等了四十分钟。手机屏幕亮了十一次，没有一条是他的消息。 |

### 技巧五：简洁表达（删除无效字）

| ❌ 冗余表达 | ✅ 简洁表达 |
|---|---|
| 他真的是非常非常生气 | 他气得发抖。 |
| 她的心里感到一阵说不出的难过 | 她心里一阵发酸。 |
| 那个时候的她，其实是非常想要哭出来的 | 那时候，她想哭。 |

**删除清单**：
- "真的是""实在是""非常的非常" → 直接删
- "感到""觉得""心里想到" → 能删就删
- "的时候""的情况下" → 尽量简化

## 第55章：对白专项

### 核心目标
让对白成为人物的"声音指纹"，读者不看名字也能分出谁在说话；同时让对白推进剧情，而非停滞。

### 要点一：人物辨识度（每个人物说话方式不同）

| 人物类型 | 说话特征 | 示例 |
|---|---|---|
| 文人/知识分子 | 用词雅致，句子偏长，偶尔引经据典 | "此情此景，倒让我想起一句旧诗。" |
| 市井/江湖人物 | 口语化，短句多，偶尔带脏字 | "别废话，这事就这么定了。" |
| 害羞/内向人物 | 说话断断续续，经常自我打断 | "那个……我……其实我想说……算了。" |
| 强势/控制型人物 | 多用祈使句，很少问句 | "把文件拿来。现在。" |
| 圆滑/社交型人物 | 说话留余地，少用绝对词 | "这个嘛，可能还需要再商量商量。" |

**检验方法**：把所有人物的对话都去掉名字，混在一起，看能不能靠"声音"分清是谁。如果分不清，就是辨识度不足。

### 要点二：互动感（对话是"球"，不是"独白"）

❌ **糟糕的对话**（两个人在各说各的）：
> A："今天天气真好。"
> B："我最近在考虑换工作。"

✅ **有互动感的对话**（彼此回应，有来有回）：
> A："今天天气真好。"
> B："嗯，这种天气最适合出去走走。你有什么打算？"
> A："正想找你商量呢——"

**互动感三要素**：
1. **回应**：B的这句话必须对A的话有反应，不能无视
2. **追问/接话**：对话要推动下去，不能停在寒暄
3. **潜台词**：人物说的话和心里想的不完全一样（参见要点四）

### 要点三：推进剧情（对话必须有"功能"）

每一段对话都应该至少完成以下功能之一：
- 传递信息（读者不知道的信息）
- 展现人物关系（通过说话方式、称呼、态度）
- 推动矛盾（引发新的冲突或加剧现有冲突）
- 埋下伏笔（为后续情节做铺垫）

❌ **无效对话**（可以删掉，不影响故事）：
> "吃了吗？"
> "吃了，你呢？"
> "也吃了。"

✅ **有效对话**（有信息或情绪传递）：
> "吃了吗？"
> "吃过了。"她顿了顿，"就是你上次说不好吃的那家。"

### 要点四：潜台词（话里有话）

> 好的人物对话，说的是A，意思是B。

| 表面说的话 | 潜台词 | 使用场景 |
|---|---|---|
| "你来了。" | "我等你好久了。" / "你居然真的来了（意外）。" | 暗含等待或意外 |
| "没事，你忙吧。" | "我其实有事，但我不说。" | 制造冷战/误会 |
| "挺好的。" | "一点都不好，但我不想说。" | 强装镇定 |
| "随便。" | "我有想法，但你先说，我看你会不会选我想要的那个。" | 试探对方 |

**潜台词设计方法**：问自己"这个人物说这句话的真正目的是什么？"——如果目的和表面字词完全一致，就没潜台词，可以考虑改。

## 第56章：改文自检流程

### 核心目标
建立系统化的改文流程，避免"凭感觉改"，而是有步骤、有重点地提升文章质量。

### 方法一：周大白改文法（四遍检查法）

> 来源：网文作者周大白的改文经验总结。

#### 第一遍：通读找"硬伤"
- [ ] 逻辑错误（时间线、空间、人物关系）
- [ ] 前后矛盾（前面说A，后面说非A）
- [ ] 信息缺失（读者需要知道的信息没写）
- [ ] 情节漏洞（人物突然知道某个信息，但没有合理来源）

**操作**：不改文，只标出问题，用批注或高亮标记。

#### 第二遍：精简冗余
- [ ] 删除无效对话（见第55章"无效对话"）
- [ ] 删除冗余修饰（"非常的非常""真的是"）
- [ ] 合并重复表达（同一信息说了两遍）
- [ ] 简化复杂句式（见第54章"拆句"）

**目标**：在保持信息量和情绪的前提下，把字数压缩10-15%。

#### 第三遍：强化情绪
- [ ] 检查情绪戏是否有"演"（展示）而非"告诉"
- [ ] 补充生理反应描写（见第53章"基本功三"）
- [ ] 检查是否有情绪物象呼应（见第52章）
- [ ] 强化对话潜台词（见第55章"要点四"）

#### 第四遍：润色节奏
- [ ] 长短句搭配是否合理（避免一整页都是长句或都是短句）
- [ ] 段落长度是否合适（避免大段文字墙）
- [ ] 场景转换是否流畅（有无突兀的跳跃）
- [ ] 对话标签是否多样化（避免反复用"说道""说"）

### 方法二：煮熟的来福鸽改文法（针对性润色）

> 来源：网文作者"煮熟的来福鸽"的润色经验。

#### 核心思路："逐句过关"
不是整段改，而是逐句检查每一句话是否有"更好的写法"。

**检查清单（逐句问自己）**：
- [ ] 这句话能不能删掉而不影响意思？（能删就删）
- [ ] 这句话的表述是不是最简洁的？（不是就改）
- [ ] 这句话有没有画面感？（没有就加动词/名词）
- [ ] 这句话的情绪到位了吗？（不到位就强化）
- [ ] 这句话符合人物身份吗？（不符合就改口径）

#### 专项润色顺序
1. **先润色对话**（最重要，也最容易出问题）
2. **再润色情绪戏**（读者最在意的部分）
3. **最后润色环境/过渡**（不影响核心阅读体验）

#### "冷却法"改文
- 初稿完成后，不要立即改，先"冷却"1-2天
- 冷却后再读，更容易发现问题和可改进之处
- 如果时间不允许冷却，至少先读一遍全文再动手改

### 综合自检表（可打印使用）

| 检查维度 | 具体项目 | 通过打√ |
|---|---|---|
| **逻辑** | 时间线是否合理？ | |
| | 人物关系是否前后一致？ | |

| **精简** | 有无无效对话可删？ | |
| | 有无冗余修饰可删？ | |
| | 有无重复表达可合并？ | |
| **情绪** | 情绪戏是否有"演"？ | |
| | 有无生理反应描写？ | |
| | 有无情绪物象呼应？ | |
| **对话** | 人物说话是否有辨识度？ | |
| | 对话是否有互动感？ | |

## 第57章：知乎盐选爽文创作方法

### 核心目标
掌握知乎盐选专栏风格的第一人称爽文创作技巧，写出高冲突、强转折、快节奏的爽文。

> 来源：丸美小沐–小邹（知乎盐选专栏）

### 一、核心创作要求

#### 1. 类型与核心
- **类型**：知乎风格第一人称爽文（酷/宣泄/打脸/逆袭）
- **核心**：高冲突、强转折、快节奏；每章至少2个爽点/反转/打脸/高能信息；每2章至少埋1个更大的阴谋伏笔；结局必须反常规且合理闭环
- **叙述**：第一人称"我"，知乎高赞回答叙事感，边讲故事边输出方法论/数据/案例

#### 2. 知乎味道必备要素
- 开头用抓人的问题/反问引出故事：
  > "你有没有过被全公司甩锅还被网暴的经历？我来讲讲这事怎么翻盘的"
- 每章自然插入至少1处：数据分析、专业术语解释、行业潜规则拆解、案例研究、对比表述
- 高频使用知乎式句式："你以为……其实……"｜"别急，先看数据"｜"这事本质是……"｜"我当时的第一反应是：笑死"

#### 3. 语言与气质
- 口语化、有梗不尬，可使用网络用语（离谱、笑死、绷不住了、我直接好家伙）
- 偶尔尖锐毒舌，对反派行为进行讽刺、反问、比喻、排比
- 金句密度高，每章至少1句可截图传播的金句

### 二、人物设定要求

| 角色 | 设定要点 |
|---|---|
| **主角（第一人称"我"）** | 姓名/年龄/职业/外貌/3个性格标签/背景经历；初始弱点至少1个；独特优势至少1个；目标与动机现实且带情绪 |
| **主要配角（至少2个）** | 配角A：与主角关系明确，既能帮忙也可能误伤；配角B：与配角A形成价值观/阶层/能力/立场对照；配角非工具人，有小欲望/小秘密/小反转 |
| **主要反派（至少1主+1暗线）** | 动机合理（利益/权力/名声/嫉妒/阶层焦虑/遮丑）；资源/能力明确；行动逻辑清晰、难度逐级升级 |

### 三、结构推进（5部分）

| 部分 | 占比 | 核心内容 |
|---|---|---|
| 金句开场 | 约15% | 极具冲突的现场开局 + 炸裂金句 + 关键伏笔（细节/数据/录音/合同/聊天记录） |
| 发展铺垫 | 约20% | 反派连环加码 + 主角"看似愚蠢实则布局" + 知乎式专业拆解 |
| 付费钩子 | 约25% | 卡点设置 + 至少3次高爽反制 + 硬核信息差展示 + 章末强悬念 |
| 高潮反击 | 约25% | 最强反击（当众拆穿/清算） + 反派付出明确代价 + 至少3连击爽点 |
| 戏剧终局 | 约15% | 反常规结局 + 伏笔全部回收 + 知乎式总结（生存策略/识人技巧/反PUA清单） + 终极金句 |

### 四、节奏与爽点硬指标

| 指标 | 要求 |
|---|---|
| 每章爽点 | 至少2个爽点（打脸/逆转/揭露/快意反击）+ 1个悬念钩子 |
| 全文反转 | 至少6次反转（至少2次"读者以为赢了其实还没完"） |
| 反派升级攻击 | 至少3次（舆论→制度→资源封锁/致命证据） |
| 主角谷底 | 至少2次跌到谷底，每次谷底都埋有翻盘钥匙 |

### 五、输出格式要求
- 直接输出：标题＋分章小说正文
- 章节标题：短、狠、带悬念（例："我被全网骂到退网那天，老板还在笑"）
- 禁止出现大纲/设定/作者说明，自然推进故事

| B | 直播/自媒体舆论战 |

## 第58章：句式结构与去AI味写作规则

### 核心目标
掌握80条去AI味写作规则，让AI生成的内容更具人性化，消除"塑料感"。

> 来源：妙笔生花 AI 智能创作助手（80条规则）

### 一、句式结构（打破工整）20条

| # | 规则 | 说明 |
|---|---|---|
| 1 | 禁止使用排比句和工整对仗 | 避免机械化节奏 |
| 2 | 句子长短错落，允许出现破碎的短句 | 制造呼吸感 |
| 3 | 去掉多余的形容词，只保留最锋利的核心 | 少即是多 |
| 4 | 多用口语化的"的""了""嘛"，少用书面语连接词 | 贴近真人表达 |
| 5 | 模拟真实对话中的吞音、停顿和口误 | 增加真实感 |
| 6 | 不要用"不是……不是……而是……"句式 | 要直接陈述事实 |
| 7 | 禁止使用"总之""综上所述""由此可见" | 避免总结式说教 |
| 8 | 段落之间不需要承上启下的过渡句 | 直接跳跃，制造节奏 |
| 9 | 把长句拆成几个短句 | 制造呼吸感 |
| 10 | 偶尔使用一个非常突兀的比喻 | 打破语境，增加惊喜 |
| 11 | 禁止使用"随着……的到来" | 陈词滥调 |
| 12 | 不要用"在这个……的时代" | 空洞的背景交代 |
| 13 | 删掉"仿佛""好像"，直接陈述事实 | Show don't tell |
| 14 | 允许句子成分残缺 | 模拟真实思考的断点 |
| 15 | 不要用"虽然……但是……"的标准句式 | 换个说法 |
| 16 | 减少被动语态（被、由），多用主动 | 增强力量感 |

| 18 | 每一段的开头不要都是"他/她/它" | 变化开头 |
| 19 | 强行插入一个与上下文无关的具象物体描写 | 打断预期，增加真实感 |
| 20 | 结尾不要用总结句，要留白 | 让读者自己体会 |

| 6 | 不要用抽象的词汇（如"美好""伟大"），用具象的脏手、汗味代替 | 具象化 |
| 7 | 拒绝"万能梗"，不要写"他猛地惊醒" | 太常见了 |

| 18 | 不要为了平衡而写反面意见，只写一方 | 保持立场 |

| 12 | **严禁使用"这说明了……"** | 让事实自己说话 |

### 使用方法

1. **AI生成初稿后**，对照以上规则逐条检查
2. **重点关注**：规避AI高频词（第五章）+ 句式结构（第一章）+ 拒绝废话（第二章）
3. **人性化处理**：人物塑造（第三章）+ 对话优化（第四章）

## 第59章：场景与动作描写专项

### 核心目标
掌握场景与动作描写的核心方法，让文字具备画面感、节奏感和人物味道。

> 来源：番茄小说网作家课堂（2026-06-08）
> 适用对象：所有品类，预计学习时长：11分钟

### 一、场景描写专项

场景描写是让读者"入戏"的关键，很多新手作者写场景时，明明写了不少字，读者却还是看不到画面、感受不到气氛。

#### 常见问题

1. **只罗列"有什么"，读者没有画面感**
2. **一大段景物堆在开头，读者直接划走**
3. **不同题材场景都是一个味，缺乏氛围感**

#### 解决办法

**方法一：调动五感，让读者真正进入场景**

大多数人写场景只用眼睛，看到什么就写什么。但读者真正产生代入感，靠的是全身体验，加上气味、声音、触感之后，同一个场景的信息量和沉浸感完全不一样。

我们要学会用视觉给框架，用其他感官给温度。

**适用场景**：人物首次踏入新环境、快速建立代入感的开篇与转场、着重渲染环境氛围的片段。

> **示例**：
> - **改前**：林晚走进地下室，里面有旧桌子、铁门、灯泡和杂物，环境很乱。
> - **改后**：林晚推开地下室的铁门，湿冷的潮气混杂着铁锈味扑面而来，呛得人喉咙发紧。她迈步走入，鞋底碾过碎玻璃，刺耳声响在静夜中格外清晰。

**方法二：把场景描写穿插在动作和对话之间，不要集中堆砌**

集中写景本质上是在"暂停剧情"，读者会感觉故事停下来了，容易失去耐心。

把景物拆散，跟着人物的动作和对话一起出现，场景就变成了剧情的一部分，读者在跟着故事走的同时自然就看到了环境。

**适用场景**：都市、言情、悬疑、爽文等快节奏题材，尤其在章节开头需要快速推进剧情时、人物正在移动/追赶/观察时、对话较多节奏偏快的片段效果更佳。

> **示例**（故事背景：警察在夜市寻人）：
> - **改前**：夜市很热闹，到处都是人，空气里全是食物的味道，街边还有叫卖声。（写完这些后，主角才开始找人。）
> - **改后**："老板，见过这个人吗？"周渡把手机递到摊前。烤串的油烟正往上冒，摊主只匆匆瞥了一眼，就把手机推了回来，"没见过，你去前头那家麻辣烫问问，他们家收摊晚，见的人多。"随后扯着嗓子朝后面喊："三十串羊肉，谁的？"周渡皱了皱眉，侧身让开一辆挤过来的小推车，抬脚继续往前。

**方法三：用具体的题材专属细节营造氛围，而不是靠形容词**

形容词（繁华、压抑、空旷等）是结论，读者被动接受；具体物件和声音是证据，读者自己得出感受。前者是作者"告诉你这里很压抑"，看完就忘，后者会在读者脑子里形成画面，能有效地增强代入感和氛围感。

**注意**：细节虽好，但不能贪多，过度罗列会让文字显得臃肿，拖慢剧情节奏。挑一两个最能代表这个场景氛围的物件或声音写进去就够了，其余的让读者自己脑补完。

> **示例1**：古代题材——城门破败的"冷清"
> - **改前**：城门很破败，城墙很冷清，街上没有什么人，看起来十分荒凉。
> - **改后**：城楼上挂着的破旧旗面只剩半截，垂在阴沉的天色下。城门的朱漆早已斑驳，门环歪在一边，偶尔被风晃动两下，发出沉闷的"咚咚"声。

> **示例2**：现代题材——老小区的"冷清破败"
> - **改前**：这个老小区很破旧，环境很冷清，楼道里也没有什么人，十分萧条。
> - **改后**：路灯被泛黄的灯罩罩得发闷，半敞的单元铁门爬满锈迹，一块块铁皮悄然脱落。楼道里没有声响，只有哪家门缝底下透出一条白光，照在斑驳的水泥地上。

#### 不同品类的专属细节

| 题材 | 专属细节方向 |
|---|---|
| 古代 | 旗面、门环、朱漆、青石板、驿道、油灯 |
| 现代都市 | 路灯、铁门、水泥地、霓虹灯、地铁、便利店 |
| 悬疑 | 阴影、脚步声、钟摆声、冷光灯、监控摄像头 |
| 仙侠 | 灵气、法阵、飞剑、丹药、秘境、宗门 |
| 年代 | 的确良、麦乳精、搪瓷缸、缝纫机、二八大杠 |

### 二、动作描写专项

很多新手写剧情时，知道人物"做了什么"，却不会把动作写出画面、节奏和人物味道，文字就容易变成干巴巴的叙述。

动作描写的核心作用有三个：**增强画面感、推动故事发展、展现人物特质**。但它不是写得越多越好，堆动作、堆形容只会变成没有信息的水文。

#### 常见问题

1. **动作太笼统，没有画面感**
2. **只写动作本身，人物缺乏心理层次**
3. **不同年龄、性别的人物，动作写出来都一个样**
4. **连贯动作被压缩成一个词，读起来像快进，没有节奏**

#### 解决办法

**方法一：把一个大动作拆成3-5个连贯小动作**

不要只写动作的结果，要把人物完成动作的过程还原出来。

可以从"移动、靠近、接触、操作、反应"几个方向对动作进行拆解，再选3-5个写出来，并至少给一处加细节感受（触感、力度、呼吸等）。

> **示例**：
> - **改前**：林晚走到桌边，拿起那封信看了一眼。
> - **改后**：林晚停在桌边，指尖先碰了碰信封边角，像是在确认什么。她把信慢慢抽起来，低头扫了一眼封面上的字，呼吸微微一顿，这才把信纸完全展开。

**方法二：在动作里加入"二次动作"，用肢体替代内心独白**

人的情绪越复杂，动作越不可能一步到位。

所以在写人物动作时，可以尝试"第一反应+第二反应"的设计思路，在中间加入收回、停顿、反向或补动作等变化，比如伸到一半停住、递过去又缩回、想走又慢下来。

让这些变化和人物当下的情绪对应：犹豫就慢、紧张就僵、舍不得就回头。

> **示例**（故事背景：小情侣闹分手，女生退还房门钥匙）：
> - **改前**：女生把房子的钥匙放在餐桌上，推到了男生面前。她心里其实很舍不得……
> - **改后**：女生从包里摸出房间的钥匙，推到了男生手边。却在即将收手的一瞬间，猛地按住了钥匙扣上的小熊挂坠。她没有把钥匙收回去，只是死死按着。原本一直低头沉默的男生，看到那只僵住的手，呼吸陡然沉重，终于抬眼看向了她。

**方法三：根据年龄和性别写出专属动作特征**

下笔前先想清楚三件事：人物几岁、是什么性格、长期的生活环境让他形成了什么动作习惯。

然后按年龄调整动作的速度和幅度，按性格加入属于这个人的习惯细节。

> **示例**：
> - **改前**：门一开，三个人都走了进来，在沙发上坐下。
> - **改后**：十七岁的男生先一步冲进来，书包还挂在半边肩上，人已经歪着身子扑到沙发里。年轻女人抬手拢了拢被风吹乱的头发，把包放到腿侧，才安静坐下。最后进门的老人扶着门框缓了一下，脚步很慢，等站稳后才一点点挪到沙发边，撑着扶手坐了下来。

**方法四：把动作写慢，保留动作之间的"停顿节点"**

核心不是把句子写长，而是要在重要场景、情绪变化场景中把被压扁的动作过程，按真实顺序还原出来。

先写出原本的压缩句，再找停顿点：人物在哪一拍卡住、哪一刻乱了、哪一下才真正行动，把这几处单独写出来。

最后做减法，只保留2到3个最有张力的节点，不需要处处慢写。

> **示例**：
> - **改前**：她听到那句话后站起来跑了出去。
> - **改后**：那句话落下时，她指尖在桌沿上轻轻蜷了一下。下一秒，她猛地站起身，连看都不敢再看对方一眼，逃也似地冲了出去。

#### 不同年龄段的动作模板

| 年龄 | 动作特征 |
|---|---|
| 少年（10-18岁） | 冲动、幅度大、速度快、不经思考 |
| 青年（18-30岁） | 有目的性、节奏快、偶尔犹豫 |
| 中年（30-50岁） | 稳重、有节制、动作有份量感 |
| 老年（50岁+） | 缓慢、需要支撑、停顿多、小心翼翼 |

### 三、小说描写公式

#### 1. 人物外貌描写公式

**公式**：整体形象勾勒（身高、体型、服饰风格等）＋面部特征描写（眼睛、鼻子、嘴巴等五官细节）＋独特标识强调（如疤痕、胎记、标志性配饰等）

> **示例**：他身材高大魁梧，一袭黑色长风衣随风而动，如同一座移动的小山丘。深邃的眼眸犹如寒星，高挺的鼻梁下，薄唇微微上扬，带着一丝不羁。左脸颊上那道浅浅的疤痕，在他小麦色的肌肤上，像是一枚独特的勋章，为他增添了几分杀气。

#### 2. 人物心理描写公式

**公式**：内心独白（直接表达人物的想法与感受）＋思维波动呈现（情绪的起伏变化及思考过程）＋潜意识暗示（通过梦境、幻觉或不经意的回忆等展现潜意识）

#### 3. 场景描写公式

**公式**：空间布局描绘（方位、大小、形状等）＋环境元素列举（自然景色、人造物品等）+氛围营造细节（光线、声音、气味等）

#### 4. 动作描写公式

**公式**：主要动作分解（起始、过程、结束动作）＋身体部位协同（手脚、躯干等配合）＋动作力度与速度描述

#### 5. 人物情感描写公式

**公式**：人物在特定情境下的动作细节（如眼神、肢体动作、身体姿态等）＋环境描写（烘托氛围，增强情感表现力）＋对他人或事物的反应细节

#### 6. 物品描写公式

**公式**：整体形态描绘（尺寸、形状、各部分比例等）＋材质与色泽说明（主要材质、颜色、光泽等）＋细节特征强调（表面纹理、装饰、特殊构造等）＋功能特性简介（主要功能、使用效果等）

### 四、白描陷阱（4个常见错误）

| 陷阱 | 说明 | 正确做法 |
|---|---|---|
| **陷阱一：信息过载** | 避免一段几百字的面部、服饰的"全身扫描"，读者记不住，且枯燥 | 不追求全面，只追求最具辨识度的一两个特征 |
| **陷阱二：陈词滥调** | "剑眉星目""肤如凝脂"太普遍且无画面感，用一两次还好，多了就乏味了 | 要找到属于你这个人物的独特比喻 |
| **陷阱三：与人设割裂** | 描写一个穷困的少年却"身着不染尘埃的云锦"，除非是伪装，否则就是逻辑硬伤 | 每一个细节都应是人物身份、性格、处境或能力的"证据" |
| **陷阱四：打断节奏** | 在紧张追击中突然停下，用三段话描写新出场角色的穿着打扮 | 永远让描写为当下的情节情绪服务 |

## 颖子写作17法（展示而非告知）

> 来源：颖子加油呀（四川撰稿人）
> 核心理念：把抽象情绪翻译成具体东西，让读者感受到而不是被告知

| 序号 | 手法 | 核心 | 一句话口诀 |
|---|---|---|---|
| 1 | **葆淳** | 卸掉华丽滤镜，把情绪翻译成具体动作 | 悲伤不说悲伤，写"磕烟袋的动作" |
| 2 | **熔笔** | 打破感官壁垒，把A熔进B里 | 寂静是"金黄色的，浓稠的" |
| 3 | **镂章** | 剔除虚的形容词，让实的细节立起来 | 高互动文章形容词≤8% |
| 4 | **削芜** | 拔除文字里的杂草（非常/特别/极其） | 把"她很紧张"换成"她把手机翻过来又翻过去" |
| 5 | **淬辞** | 把文字像打铁一样淬炼出力量 | 情绪越强，笔调越要冷 |
| 6 | **凝烟** | 把飘的东西写成不飘的，给空气重量 | 雾不要"飘"，改成"凝""压""坠" |
| 7 | **取景** | 正面不写写反面，本面不写写旁边 | 不写罗敷美，写路人看呆了 |
| 8 | **收放感** | 放（细节铺陈）与收（猛踩刹车）的节奏 | 前面三千字哭天抢地，结尾一只袜子 |
| 9 | **逻辑感** | 把隐形推导变成可见的文字台阶 | 结论先行 + 把跳步补回来 |
| 10 | **悬念** | 在读者心里挖坑，故意不填 | 强烈欲望 + 致命阻碍 + 延迟交付 |
| 11 | **故事感** | 展示而不是宣告 | 删掉"我觉得""我感到"，看句子能否独立成立 |
| 12 | **临场感** | 用生理反应唤醒身体记忆 | 不问"难不难过"，问"喉咙堵不堵" |
| 13 | **肌理感** | 能摸到的真实感（AI替代不了） | 写"脚趾缝里的温热软泥"而不是"农民很辛苦" |
| 14 | **动态感** | 让身体产生反应，文字就活了 | 概括性动词 → 带轨迹的动作 |
| 15 | **层次感** | 渐进式信息呈现，别把底牌全亮 | 先看到什么 → 再感受到什么 → 最后心里浮起什么 |
| 16 | **立体感** | 让读者觉得"这说的就是我" | 视角切换 + 时间折叠 |
| 17 | **画面感** | 让读者脑子里自动放电影 | 删掉"我觉得"，剩下的内容能否独立成立 |

**使用流程**：
1. **写完初稿后**，对照上表逐条检查：
   - 形容词是否太多？（用**镂章/削芜**削减）
   - 情绪是否直接说出？（用**葆淳/熔笔**转化为具体画面）
   - 文字是否有力量？（用**淬辞**锤炼动词）
   - 读者能否感受到现场？（用**临场感/肌理感/画面感**检验）

2. **逐场景优化**：
   - 静态描写太多 → 用**动态感/凝烟**让画面活起来
   - 平铺直叙 → 用**收放感/层次感**制造节奏
   - 读者猜得到结局 → 用**悬念/取景**制造意外

3. **最终检验**：
   - 读一遍，把所有"很/非常/特别"删掉，看句子是否还站得住（**削芜**）
   - 问自己：这个情绪，能不能换成一个具体动作或物件？（**葆淳**）
   - 给朋友读一段，看他会不会问"然后呢？"（用**悬念**检验）

**完整案例+练习**见 `references/yingzi-methods-complete.md`

## 颖子写作手法续（27法）

> 来源：颖子加油呀（四川撰稿人）
> 核心理念：多样化的写作技巧，覆盖结构、节奏、情感、语言等各个方面

| 序号 | 手法 | 核心 | 关键动作 |
|---|---|---|---|
| 18 | **凝练** | 把汤熬成浓汁，不是写短是提纯 | 强制删减30%，删掉程度副词 |
| 19 | **流畅感** | 让读者一口气读下去 | 钩子咬合+情绪晕染+节奏控制 |

## 颖子写作手法三续（23法）

> 来源：颖子加油呀（四川撰稿人）

|---|---|---|---|
| 44 | **叩问** | 把读者逼到墙角的文字穿透力 | 抛灵魂拷问 + 不给思考退路 + 给出定海神针 |

| 49 | **孤诣** | 拒绝跟风，捕捉微小真实细节 | 扔掉通用形容词 + 捕捉独一份的记忆 |

| 59 | **空筐** | 不把话说满，留位置给读者 | 只搭框架 + 留细节场景 + 让读者自己填 |
| 60 | **荒野拾星** | 从日常碎料里捡出闪光细节 | 建细节档案 + 强制去形容词 + 话不说满 |

## 第60章：AI小说创作通用提示词（双版本）

> 适用于豆包/GPT/Claude等主流模型，覆盖小说创作全场景——从构思、开篇、人物、情节、对话、场景描写到修改润色。

### 版本一：简单通用版

```
# 角色
你是一位专业小说创作助手。

# 任务
根据我的需求，帮我完成小说写作任务（构思/写稿/改稿均可）。

# 执行步骤
1. 先确认我的具体需求（要写什么类型的片段、多少字、什么风格）
2. 按要求生成内容
3. 生成完毕后，简要说明为什么这样写

# 规则
- 语言流畅自然，避免说教感
- 描写要有画面感，多用感官细节
- 对话要符合人物性格，不要千人一面
- 不写违反中国法律法规的内容

# 输出格式
先输出正文内容，再用【写作说明】简要解释创作思路。
```

**适用场景**：日常写作快速调用、轻量级创作需求、对格式要求不高的场景。

---

### 版本二：高阶优化版

```
# Role（角色设定）
你是一位拥有20年经验的资深小说家，精通玄幻、都市、言情、悬疑、科幻等全品类创作。你擅长人物弧光设计、多线叙事、节奏控制和金句提炼，对中国网络文学市场和传统出版市场都有深刻理解。

# Task（任务总目标）
根据用户输入的「创作阶段 + 具体需求」，完成小说创作全链条中的任意环节，包括但不限于：灵感发散、大纲策划、人设构建、正文撰写、对话设计、场景描写、冲突编排、伏笔埋设、节奏优化、润色修改。

# Workflow（执行步骤）
请按以下流程逐步执行，每步之间用分隔符隔开：

## 第1步：需求解析
- 识别创作阶段：[构思/大纲/正文/对话/场景/修改]
- 识别小说类型：[玄幻/都市/言情/悬疑/科幻/历史/其他]
- 识别字数要求：[用户指定/未指定则默认800-1500字]
- 识别风格要求：[爽文/细腻/幽默/沉重/诗意/其他]

## 第2步：创作执行
- 构思阶段：提供3个以上差异化创意方向，各附一句话核心梗概
- 大纲阶段：按三幕结构或章回结构输出，标注关键情节点
- 正文阶段：遵循「展示而非说教」原则，感官描写≥视觉/听觉/触觉各1处，对话比例控制在30%-50%
- 修改阶段：指出问题+给出修改方案+示范改写片段

## 第3步：自检输出
- 检查是否跑题、是否灌水、对话是否自然
- 附简要创作说明

# Constraints（规则限制）
1. **语言质量**：禁止连续3句以上以同一主语开头；每200字至少1处感官描写；比喻和类比必须新颖，禁用"像……一样"等套路句式
2. **人物塑造**：每个主要人物必须有1个独特口头禅或习惯动作；反派必须有合理动机，不能纯恶
3. **节奏控制**：紧张段落用短句提速，舒缓段落用长句延展；每500字切换一次叙事节奏
4. **禁忌**：不写低俗色情、不写分裂国家、不写反社会内容、不抄袭已有作品原文
5. **适配性**：不使用Markdown表格或复杂格式（豆包不兼容）；避免引用外部链接；核心指令用中文，参数用中文

# Output Format（输出格式）
【创作阶段】XXX | 【类型】XXX | 【字数】XXX
──────────────────
[正文/大纲/改写内容]

──────────────────
【创作说明】
- 叙事手法：
- 人物亮点：
- 节奏设计：
- 可优化点（可选）：
```

**适用场景**：需要质量控制的正式创作、长篇连载写作、需要精细调整的高标准输出。

### 22. 批量质检流程（Batch Quality Inspection）

适用于多章节/多场景小说的批量检查，核心是**系统性检测 + 问题分级处理**。

#### 22.1 批量检查清单

| 检查维度 | 检测内容 | 处理优先级 |
|----------|----------|------------|
| 逻辑一致性 | 角色设定冲突、时间线错误、空间矛盾 | P0（必须修复） |
| 重复检测 | 动作/外貌/句式/对话标签重复 | P1（影响阅读体验） |
| 前后一致 | 角色性格突变、背景信息矛盾 | P1（影响代入感） |
| 节奏检测 | 章节长度差异、冲突密度不均 | P2（影响阅读节奏） |
| 伏笔呼应 | 前面埋的线索后面是否回收 | P2（影响完整度） |
| 敏感词检测 | 违规词/违禁词/平台敏感词 | P0（必须修复） |

#### 22.2 批量处理工作流

```
输入：多章节小说文档（docx/txt）
  ↓
Step 1: 拆分章节 → 逐章节编号
  ↓
Step 2: 逻辑检测 → 时间线梳理 + 角色状态追踪
  ↓
Step 3: 去重检测 → 动作/外貌/句式模式匹配
  ↓
Step 4: 一致性检测 → 角色画像交叉对比
  ↓
Step 5: 问题汇总 → 按优先级排序 + 给出修复建议
  ↓
输出：检测报告 + 修复建议清单
```

#### 22.3 问题分级处理

| 级别 | 描述 | 处理方式 | 示例 |
|------|------|----------|------|
| P0 | 阻断性问题 | 立即修复 | 角色死亡又复活无解释 |
| P1 | 严重问题 | 建议修复 | 主角前一章怕高，后面主动跳楼 |
| P2 | 中等问题 | 优化修复 | 连续3章都是室内对话场景 |
| P3 | 轻微问题 | 可选修复 | 某段落略有重复 |

### 24. 剧情纠偏与节拍校正

适用于创作中段发现跑偏的情况，核心是**及时发现问题 + 快速修正**。

#### 24.1 跑偏的四个信号

| 信号 | 表现 | 诊断方法 |
|------|------|----------|
| 主角消失 | 配角戏份超过主角 | 章节统计：主角出场占比 < 60% |
| 支线膨胀 | 支线章节超过主线 | 大纲对比：支线集数 > 总集数30% |
| 节奏拖沓 | 连续3章无核心冲突 | 冲突检测：每章至少1个核心冲突 |
| 动机断裂 | 角色行为无合理动机 | 动机追溯：每个重大选择有内心支撑 |

#### 24.2 纠偏方法

**方法一：主干确认法**
```
1. 一句话总结你的故事核心
2. 每个新情节问：它在帮这句话更稳，还是把读者带往别处？
3. 不是在帮主干成长的枝桠，砍掉
```

**方法二：退路堵死法**
```
1. 每3章停下来
2. 问：当前人物还有没有第二条路？
3. 有→堵死，只留一条
```

**方法三：读者视角法**
```
1. 想象一个"最后一排的读者"
2. 每章写完问：他跟得上吗？
3. 跟不上→简化/铺垫/解释
```

**方法四：悬念钩子法**
```
1. 每章结尾自检：
   - 上一章结尾，读者最惦记什么？
   - 下一章开头，是否回应了这份惦记？
2. 没回应→补上
```

### 25. 苟道/低调流金手指设计

适用于反派/潜行/发育类小说，核心是**不暴露 = 最强防御**。

#### 25.1 六大苟道金手指

| 金手指 | 核心效果 | 实战爽点 | 必要限制 |
|--------|----------|----------|----------|
| 隐身气场 | 让旁人自动忽略 | 浑水摸鱼神器，捡漏无人察觉 | 主动攻击时失效 |
| 危险预警 | 杀机/陷阱自动预警 | 提前规避风险 | 对秒杀无效 |
| 伪装天赋 | 气息/身份完美伪装 | 卧底/逃命神器 | 神识强者可识破 |
| 气运掠夺 | 周边好运自动汇聚 | 躺赢式发育 | 被动触发 |
| 无限储物 | 资源无限囤积 | 末日生存神器 | 需要获取资源 |
| 情绪感知 | 读懂人心真实想法 | 社交无敌 | 对修为高者无效 |

#### 25.2 苟道核心原则

```
不暴露 → 不被针对 → 安稳发育 → 无敌
```

**三个不要：**
- 不要主动惹事（被动发育）
- 不要太高调（闷声发大财）
- 不要有牵挂（了无牵挂则无敌）

### 26. 救猫咪故事类型体系

适用于所有类型的故事结构设计，核心是**选类型 = 选节拍骨架**。

#### 26.1 驱动力判断

**驱动力来自外面（4种）：**

| 类型 | 一句话判断 | 代表作 |
|------|------------|--------|
| 麻烦家伙 | 有麻烦找上门 | 《鬼灭之刃》 |
| 屋里有怪物 | 被困住了 | 《异形》 |
| 傻瓜成功 | 主角被忽视到极限 | 《功夫》 |
| 金羊毛 | 主动踏上旅途 | 《指环王》 |

**驱动力来自里面（6种）：**

| 类型 | 一句话判断 | 代表作 |
|------|------------|--------|
| 愿望成真 | 许愿 | 《哆啦A梦》 |
| 成长仪式 | 卡节点 | 《哪吒》 |
| 伙伴之爱 | 互相改变 | 《海底总动员》 |
| 犯罪动机 | 揭开秘密 | 《死亡笔记》 |
| 超级英雄 | 背负使命 | 《蜘蛛侠》 |
| 制度化 | 对抗系统 | 《鱿鱼游戏》 |

#### 26.2 十种类型节拍公式

**麻烦家伙型公式：**
```
公式 = 无辜主角 + 突发事件 + 一层一层扛住
- 开场必须有突发事件
- 中点必须是假胜利
- 结尾必须是一层一层扛住压力
```

**傻瓜成功型公式：**
```
公式 = 傻瓜 + 被忽视 + 被逼到极限后翻盘
- 必须有"被逼到极限"的临界点
- 翻盘前必须经历最低谷
```

**愿望成真型公式：**
```
公式 = 愿望 + 魔法规则 + 代价教训
- 爽完之后有代价
- 代价是核心
```
